# 网络结构、公式与参数

## 1. 上下文向量

使用前 \(n-1\) 个词，拼接 embedding：

\[
x=
[C(w_{t-1});C(w_{t-2});\ldots;C(w_{t-n+1})].
\]

## 2. 隐藏层

\[
h=\tanh(d+Hx).
\]

## 3. 输出与直接连接

\[
y=b+Wx+Uh.
\]

\(Wx\) 是可选的输入到输出直接连接，\(Uh\) 是非线性隐藏路径。对每个候选词 \(i\)：

\[
P(w_t=i\mid context)
=
\frac{\exp(y_i)}
{\sum_{j\in V}\exp(y_j)}.
\]

## 4. 参数

- \(C\)：词 embedding 表；
- \(H,d\)：上下文到隐藏层；
- \(U,b\)：隐藏到词表输出；
- \(W\)：可选直接连接。

输出矩阵随 \(|V|\) 增长，是主要参数与计算瓶颈。

## 5. 最大似然

\[
\max_\theta
\sum_t
\log P_\theta(w_t\mid w_{t-n+1:t-1})
-R(\theta).
\]

论文用随机梯度更新，词 embedding 只更新当前上下文涉及的行；输出归一化仍需遍历整个词表。

## 6. 计算挑战

AP News 模型训练 5 epochs 约耗时三周、40 个 CPU。论文也讨论并行计算和后续能量/采样方向，显示全词表 softmax 在当时非常昂贵。

## 7. 直接连接的作用

直接路径可快速学习近似线性的 n-gram 模式，隐藏层学习非线性共享结构。Brown 实验中去掉直接连接收敛更慢，但某些配置泛化略好，结果不足以断言直接连接必然有效。
