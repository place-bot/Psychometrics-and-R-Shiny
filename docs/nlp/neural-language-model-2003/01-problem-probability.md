# 语言模型、维数灾难与分布式表示

## 1. 语言模型

\[
P(w_1,\ldots,w_T)
=
\prod_{t=1}^{T}
P(w_t\mid w_{<t}).
\]

n-gram 用有限上下文近似：

\[
P(w_t\mid w_{<t})
\approx
P(w_t\mid w_{t-n+1:t-1}).
\]

## 2. 维数灾难

词表大小为 \(|V|\)，长度 \(n\) 的离散组合有 \(|V|^n\) 种。绝大多数组合在训练中没出现，计数模型需依靠 back-off、插值和类别平滑。

## 3. 分布式表示

为每个词学习

\[
C(w)\in\mathbb R^m.
\]

相似词可在向量空间邻近。训练句子会同时塑造词向量和条件概率函数，因此一个未见序列也能因其组成词与已见序列相似而获得合理概率。

## 4. 三个联合学习部分

论文明确列出：

1. 词到向量的映射 \(C\)；
2. 用上下文向量预测下一个词的概率函数 \(g\)；
3. 同时优化 \(C\) 与 \(g\) 的参数。

这使 embedding 成为任务训练的一部分，而非先验手工类别。

## 5. 与 Word2Vec、BERT

- NPLM：词向量服务于 next-word likelihood；
- Word2Vec：简化目标与网络，扩大训练规模；
- BERT：用 Transformer 与 MLM 学习上下文化 token 表示。

三者都利用分布假设，但输出表示和预训练目标不同。
