# 算术、词操作、新闻生成等能力

## 1. 为什么加入合成任务

自然语言 benchmark 的训练污染和潜在任务示范难以完全测量。作者另外构造可控任务，研究模型能否从 prompt 中识别新规则：

- 两位到六位加减法；
- 两位乘法；
- 多步一位数运算；
- 单词倒序、字母循环与 anagram；
- 在单词中插入符号；
- 使用一个新造词；
- 修正语法、类比和常识式任务。

## 2. 算术

prompt 提供若干算式与结果：

```text
48 + 76 = 124
34 + 58 = 92
27 + 86 =
```

few-shot 3 位加减法表现可很强；位数增加后准确率下降，尤其六位运算和两位乘法。错误常包含：

- 某一位进位失败；
- 输出接近正确数；
- 对常见数字组合更熟；
- 示例格式变化导致表现变化。

这显示模型学到部分数字模式，却没有形成稳定、位数无关的精确算法。

## 3. 词操作

对单词倒序：

```text
hello = olleh
world = dlrow
model =
```

模型要从示例推断字符级变换。byte-level BPE 的 token 边界可能把一个词拆成非字符粒度片段，因此 Transformer 需要跨 token 恢复字符结构。规模增大通常改善表现，但不同任务仍有明显失败。

## 4. 新词造句

论文给模型一个新造词及其定义，再要求在句子中使用。这类任务测试：

1. 从当前上下文临时绑定新词语义；
2. 生成语法正确的句子；
3. 保持定义一致。

结果主要是定性样例，说明模型可组合利用上下文定义，但不能给出稳定总体成功率保证。

## 5. 新闻生成实验

作者给出新闻标题与副标题，让不同规模模型续写约 200 或 500 词文章，再让人类判断真伪。对于约 200 词样本，识别 175B GPT-3 文本的 accuracy 约为 52%，接近随机猜测；对约 500 词样本仍约 52%。

论文还报告控制模型的人类识别率明显更高，模型越大越难辨认。这个实验衡量的是特定提示、抽样设置与众包判断下的可辨别性，不等于模型生成新闻都可靠或不可检测。

## 6. 生成流畅性与真实性

一个文本可以满足：

\[
\text{风格像新闻}
\]

却不满足：

\[
\text{事件真实}
\quad\land\quad
\text{细节一致}
\quad\land\quad
\text{来源可核验}.
\]

人类难以辨认生成来源反而强化误用风险，因为语言模型优化的是续写概率，不是事实验证。

## 7. 能力出现与稳健能力

合成任务展示了模型能从少量示例临时归纳模式。但要称为稳健算法，还需检查：

- 输入长度外推；
- 反事实数字与罕见字符串；
- prompt 改写；
- 示例顺序与错误示例；
- 分布外规则组合；
- 多次采样方差。

GPT-3 论文提供了能力出现的强迹象，也清楚展示了算法可靠性仍不足。
