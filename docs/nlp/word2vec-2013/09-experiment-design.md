# 实验设计、数据与比较框架

## 1. 实验问题地图

论文的实验可分成六组：

| 研究问题 | 对应证据 |
|---|---|
| 数据量和维度怎样共同影响准确率？ | Table 2 |
| CBOW、Skip-gram、NNLM、RNNLM 谁更强？ | Table 3 |
| 新模型能否超过公开词向量？ | Table 4 |
| 多看新数据与重复 epoch 如何权衡？ | Table 5 |
| 分布式大规模训练能达到什么水平？ | Table 6 |
| 词向量能否帮助句子补全任务？ | Table 7 |

Table 8 展示若干关系输出，用于定性观察。

## 2. 主要评价集

Semantic-Syntactic Word Relationship 数据集包含：

- 5 类语义问题，共 8,869 题；
- 9 类句法问题，共 10,675 题；
- 合计 19,544 题。

每题使用向量差值构造查询，按全词表余弦 top-1 精确命中计算准确率。Table 3 还报告 Microsoft Research 的 syntactic word relatedness test set。

## 3. Google News 语料

论文用于主要训练的 Google News corpus 约含

\[
6\text{B tokens}.
\]

最大词表限制为最常见的

\[
1\text{M words}.
\]

Table 2、4、5 使用该语料的不同子集；Table 6 使用完整 6B 数据。

## 4. Table 2：数据量 × 维度

### 4.1 模型

- 架构：CBOW；
- 词表：30K 高频词；
- 维度：50、100、300、600；
- 训练词元：24M、49M、98M、196M、391M、783M；
- epoch：3；
- 优化：SGD + backpropagation；
- 初始学习率：0.025，线性下降到接近 0。

### 4.2 评价范围

只保留四个词都属于 30K 高频词表的类比问题。这样可以比较模型能力，同时固定小词表下的可计算题目集合。

### 4.3 实验设计

这是 \(4\times6\) 的网格实验，用于观察：

\[
\text{Accuracy}=f(D,T).
\]

作者关注数据量和维度各自的边际收益，以及二者同时扩张的效果。

## 5. Table 3：同数据同维度架构比较

### 5.1 训练数据

训练集由若干 LDC corpora 组成：

\[
T=320\text{M words},
\qquad V=82\text{K}.
\]

### 5.2 共同维度

所有模型使用 640 维词向量，以减少表示容量差异。

### 5.3 模型

- RNNLM：此前训练的循环神经语言模型，单 CPU 约训练 8 周；
- NNLM：640 个隐藏单元，历史长度 8，通过 DistBelief 训练；
- CBOW；
- Skip-gram。

### 5.4 指标

- 新建类比集的语义准确率；
- 新建类比集的句法准确率；
- MSR syntactic relatedness test set。

这个比较最接近架构消融，因为数据和维度被固定。模型参数量、优化方式和历史结构仍不完全相同。

## 6. Table 4：公开向量与新模型

比较对象包括：

- Collobert–Weston NNLM；
- Turian NNLM；
- Mnih NNLM；
- Mikolov RNNLM；
- Huang NNLM；
- 作者训练的 NNLM；
- CBOW；
- Skip-gram。

这些模型的训练语料从 37M 到 6B 不等，维度从 20 到 640 不等。Table 4 展示实际可获得模型的综合性能，但模型结构、语料、维度和训练预算同时变化，不能视为单因素因果比较。

CBOW 与 Skip-gram 均使用 300 维、783M 词，训练 3 epoch。作者报告单 CPU 训练时间分别约 1 天和 3 天。

## 7. Table 5：epoch、数据与维度

作者比较：

1. 783M 词训练 3 epoch；
2. 783M 词训练 1 epoch；
3. 1.6B 词训练 1 epoch；
4. 783M 词、600 维、训练 1 epoch。

目标是判断固定时间附近：

- 重复同一数据；
- 看更多不同数据；
- 扩大表示维度；

哪种方式更有效。

所有 1-epoch 实验同样把学习率线性下降到接近 0。

## 8. Table 6：DistBelief 分布式训练

### 8.1 设置

- 语料：Google News 6B；
- CBOW / Skip-gram 维度：1,000；
- NNLM 维度：100；
- 训练框架：DistBelief；
- 优化：mini-batch asynchronous gradient descent + AdaGrad；
- 模型副本：50–100；
- CPU 核数：约 125–180，使用量会浮动。

### 8.2 时间记录

论文以“天数 × CPU 核数”报告近似资源。数据中心机器同时承担其他任务，核数是估计值，分布式开销也让 CBOW 与 Skip-gram 的 CPU 使用差异缩小。

## 9. Table 7：Microsoft Sentence Completion Challenge

任务包含 1,040 个句子，每句缺一个词，并给出 5 个合理候选。模型需要选择与整句最连贯的候选。

Skip-gram 设置：

- 维度：640；
- 训练语料：任务提供的 50M 词；
- 对每个候选，把候选置于缺失位置；
- 用候选作为输入预测句中周围词；
- 把各个预测分数相加作为句子得分。

最终比较 4-gram、LSA、log-bilinear、RNNLM、Skip-gram，以及 Skip-gram 与 RNNLM 的加权组合。

## 10. Table 8：关系示例

作者使用 Table 4 中 300 维、783M 词的最佳 Skip-gram 模型展示：

- 国家—首都；
- 形容词比较级；
- 城市—州；
- 人物—职业；
- 政治人物—国家；
- 元素—符号；
- 公司—产品；
- 公司—人物；
- 国家—食物。

作者指出这些例子按严格精确匹配只约有 60% 会得分，展示表包含若干语义相关但不符合唯一目标的输出。

## 11. 实验中的主要控制与混杂

| 比较 | 控制较好 | 仍然变化的因素 |
|---|---|---|
| Table 2 | 架构、词表、epoch | 数据量、维度 |
| Table 3 | 训练数据、维度 | 架构、优化与参数规模 |
| Table 4 | 同一评价集 | 几乎所有训练因素 |
| Table 5 | 架构与评价集 | 数据量、维度、epoch、时间 |
| Table 6 | 语料与框架 | 架构、维度、资源 |

因此，论文最强的证据来自一致趋势与数量级差异，而非现代意义上的严格随机对照或统计显著性分析。
