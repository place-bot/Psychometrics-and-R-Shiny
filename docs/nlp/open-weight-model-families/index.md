# 开放权重模型家族：Command R、Mistral、Phi 与 Llama

这组专题解释四个经常并列出现的模型家族：Cohere 的 Command R、Mistral AI 的 Mistral、Microsoft 的 Phi，以及 Meta 的 Llama。它们都允许开发者以某种形式接触模型，但公开范围、许可证、模型规模和产品定位并不相同。

!!! warning "先修正一句常见表述"
    “Command R、Mistral、Phi 和 Llama 都是开源模型”过于笼统。更稳妥的说法是：**这四个家族都出现过可下载权重的版本，但每个具体检查点的许可证与开放程度必须分别核对。**

    - Command R 的 Cohere Labs 研究权重采用 CC-BY-NC，并附有可接受使用要求，商业使用受限；
    - Mistral 同一家族中既有 Apache 2.0 检查点，也有研究许可或仅通过 API 提供的模型；
    - Phi 的多个官方检查点采用 MIT 许可证，开放范围相对宽松；
    - Llama 发布权重和代码，但使用 Meta 自定义社区许可证，并非标准 OSI 开源许可证。

## 这四个家族分别在解决什么问题

| 家族 | 最鲜明的设计取向 | 代表能力 | 先核对的风险点 |
|---|---|---|---|
| Command R | 面向企业检索与工具调用 | RAG、引用、长上下文、多步工具使用 | 非商业权重许可与 API 版本差异 |
| Mistral | 以高效架构覆盖从小型 dense 到稀疏 MoE | 本地部署、MoE、代码与多模态分支 | 不同型号许可证差异很大 |
| Phi | 用高质量和合成数据提升小模型能力密度 | 小型部署、推理、端侧应用 | 小模型的知识覆盖与可靠性边界 |
| Llama | 形成通用基础模型、指令模型与生态工具链 | 多尺寸、多语言、微调与部署生态 | 自定义社区许可证及代际差异 |
