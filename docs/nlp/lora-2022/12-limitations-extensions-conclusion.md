# 局限、现代扩展与结论

## 1. 局限

- rank 与 target modules 依赖任务；
- 基座权重仍需驻留内存；
- 激活和长上下文 attention 成本仍在；
- 合并模式不便在同一 batch 混用多个任务；
- 小 rank 可能无法表达强领域迁移；
- 低秩因子存在优化、学习率和缩放敏感性；
- 原论文主要研究语言 Transformer 的 attention 权重。

## 2. 常见误解

### LoRA 会压缩基座

LoRA 压缩任务更新 checkpoint。未量化的基座仍保持原大小。

### 可训练参数少等于显存按同倍数下降

激活、基座权重、临时张量和框架开销仍存在。论文 GPT-3 的参数降低约 10,000 倍，训练显存约降 3 倍，已经说明两者比例不同。

### 合并后无法切换

保留 \(A,B\) 时可以减去旧增量并加入新增量；需要正确管理精度与并发。

## 3. 后续扩展

- QLoRA：量化冻结基座并训练 LoRA；
- AdaLoRA：动态分配 rank；
- DoRA：分解权重幅度与方向；
- LoRA+：为 A/B 使用不同学习率；
- rsLoRA：调整 rank scaling；
- 多 adapter 合成、路由与加权融合。

这些方法不是原论文组成，应独立核对各自假设与证据。

## 4. 何时考虑全量微调

当任务与预训练分布差异极大、数据充足、追求极限性能且能够承担完整训练/部署资源时，全量微调仍可能更合适。LoRA 提供一种强资源—质量折中，并未从理论上支配全量微调。

## 5. 结论

LoRA 将

\[
W_0+\Delta W
\]

重参数化为

\[
W_0+\frac{\alpha}{r}BA,
\]

把每任务存储和 optimizer state 从大矩阵降到两个窄矩阵。它能在推理前合并，避免额外网络深度，并以多组实验和子空间分析支持“下游适配更新具有低内在秩”的经验假设。
