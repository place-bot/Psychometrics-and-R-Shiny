# 低秩更新为什么有效：论文的子空间分析

## 1. 三个问题

论文在 GPT-3 上研究：

1. 适配哪些矩阵；
2. 多小的 rank 足够；
3. \(\Delta W\) 与预训练 \(W\) 有什么关系。

## 2. 子空间相似度

对 rank 8 与 rank 64 学到的 \(A\) 做 SVD，取前 \(i,j\) 个右奇异方向，定义

\[
\phi(A_8,A_{64},i,j)
=
\frac{
\|U_{A_8,i}^\top U_{A_{64},j}\|_F^2
}{
\min(i,j)
}
\in[0,1].
\]

1 表示子空间完全包含，0 表示正交。

## 3. 观察

rank 8 与 rank 64 的最强奇异方向有明显重合，其他方向重合较弱；不同随机种子也能学习一些共同方向。作者据此认为有效任务更新的内在秩很低，较大 rank 的额外方向可能包含更多训练噪声。

## 4. 与 \(W\) 的关系

论文把预训练 \(W_q\) 投影到 \(\Delta W_q\) 的左右奇异子空间，比较 Frobenius 范数。rank 4 时：

\[
\|W_q\|_F=61.95,\qquad
\|\Delta W_q\|_F=6.91,
\]

沿 \(\Delta W\) 子空间投影的 \(W_q\) 范数为 0.32，而沿 \(W_q\) 自身顶尖方向为 21.67，随机方向为 0.02。

作者解释为：\(\Delta W\) 与 \(W\) 比随机方向更相关，却没有简单重复 \(W\) 的主奇异方向；它可能放大预训练已存在但未被强调的任务特征。

## 5. 解释限制

- 分析集中于 GPT-3 某些层与任务；
- 因子 \(A,B\) 不唯一；
- 子空间重合是经验相关，尚非因果机制证明；
- “低内在 rank”取决于精度阈值、任务、目标模块和优化过程；
- rank 1 表现好不表示完整全量微调更新本身严格 rank 1。

## 6. 实践结论

先用小 rank、覆盖关键模块，再通过验证集增加 rank 或模块，通常比默认使用很大 rank 更符合论文证据。需要同时记录参数预算与 target modules。
