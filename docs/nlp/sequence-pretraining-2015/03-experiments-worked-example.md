# 实验结果与迁移手算

## 1. 汇总

| 数据集 | SA-LSTM error | 此前最佳 |
|---|---:|---:|
| IMDB | 7.24% | 7.42% |
| Rotten Tomatoes | 16.7% | 18.5%（同类无额外短语标签比较） |
| 20 Newsgroups | 15.6% | 17.1% |
| DBpedia | 1.19% | 1.74% |

## 2. IMDB

| 模型 | Test error |
|---|---:|
| LSTM + tuning/dropout | 13.50% |
| word2vec 初始化 | 10.00% |
| LM-LSTM | 7.64% |
| SA-LSTM | **7.24%** |
| SA-LSTM joint training | 14.70% |

预训练递归参数显著优于只迁移词向量。

## 3. 外部无标注数据

Rotten Tomatoes 上，使用 IMDB 无标注文本预训练 SA 的 error 18.6%，使用 Amazon reviews 降到 16.7%。领域相关的更多无标注数据可以补偿标签不足。

## 4. 一个两参数迁移例子

设监督最优附近损失：

\[
L(\theta_1,\theta_2)
=(\theta_1-2)^2+10(\theta_2-1)^2.
\]

随机起点 \((0,0)\) 的梯度为

\[
(-4,-20).
\]

预训练起点 \((1.8,0.9)\) 的梯度为

\[
(-0.4,-2).
\]

预训练没有改变监督目标，只改变初始化，使优化从更有利区域开始。真实深网损失远更复杂，这个例子只说明参数初始化机制。

## 5. 证据边界

不同数据集此前最佳来自不同方法；论文未构造统一大规模多种子比较。SA 的优势也与 LSTM 长文档优化困难密切相关。
