# 从语言模型到隐式多任务学习

## 1. 自回归语言模型

给定 token 序列

\[
x=(x_1,x_2,\ldots,x_T),
\]

联合概率按链式法则写成

\[
p_\theta(x)
=
\prod_{t=1}^{T}p_\theta(x_t\mid x_1,\ldots,x_{t-1}).
\]

最大似然训练等价于最小化 token 级交叉熵：

\[
\mathcal L(\theta)
=
-\sum_{t=1}^{T}\log p_\theta(x_t\mid x_{<t}).
\]

同一目标既训练普通续写，也训练任何能被写成文本续写的任务。

## 2. 单任务条件分布

一个监督任务通常估计

\[
p(y\mid x),
\]

其中 \(x\) 是输入，\(y\) 是标签或输出。若同一个输入可能对应不同任务，模型还需要知道任务 \(z\)：

\[
p(y\mid x,z).
\]

传统多任务系统常用任务 ID、任务专用头或不同 encoder/decoder 表示 \(z\)。GPT-2 的思路是让任务本身也成为语言：

\[
z=\text{“translate to French”},
\]

然后把任务、输入与输出串成一段 token：

\[
[z;x;y].
\]

## 3. 为什么一个 LM 可能学会条件任务

在训练序列 \([z;x;y]\) 上，模型必须预测输出部分：

\[
p_\theta(y\mid z,x).
\]

假如类似结构在语料中反复出现，降低整体语言模型损失就要求模型利用任务提示和输入来预测答案。于是任务行为可以成为语言建模的副产品。

需要注意两个条件：

1. 训练语料中确实存在可辨认的任务示范；
2. 模型有足够容量和优化能力，从复杂分布中提取这些结构。

作者强调，在人为构造的清晰多任务序列上，这个逻辑容易成立；从这个玩具情形跨到开放网页文本，是论文真正要检验的经验问题。

## 4. “监督目标是语言模型目标的一部分”

设一条样本由提示 \(c=[z;x]\) 和输出 \(y=(y_1,\ldots,y_m)\) 构成。任务损失可以写成

\[
\mathcal L_{\mathrm{task}}
=
-\sum_{r=1}^{m}\log p_\theta(y_r\mid c,y_{<r}).
\]

完整语言模型还会预测提示 token：

\[
\mathcal L_{\mathrm{LM}}
=
\mathcal L_{\mathrm{prompt}}
+
\mathcal L_{\mathrm{task}}.
\]

因此在格式明确的训练分布里，输出条件似然已经包含在统一 LM 目标中。真正困难的是：自然网页没有统一分隔符、任务说明可能省略、错误答案也会出现，模型还要自己识别结构。

## 5. 推理阶段发生了什么

给定 prompt token \(c\)，模型逐步生成：

\[
\hat y_r
\sim
p_\theta(\cdot\mid c,\hat y_{<r}).
\]

这里的 \(\theta\) 在整个下游任务中保持不变。任务适配发生在：

- prompt 改变了条件分布；
- self-attention 从上下文读取任务提示、示例和输入；
- 隐藏状态随上下文变化；
- 生成策略决定选择哪个 token。

## 6. 与微调的对照

| 维度 | 任务微调 | GPT-2 式上下文调用 |
|---|---|---|
| 任务信息 | 有标签训练集、任务头 | 文本提示和上下文格式 |
| 是否反向传播 | 是 | 否 |
| 参数是否改变 | 是 | 否 |
| 每个任务的持久状态 | 新参数或 adapter | 没有，离开上下文即消失 |
| 适配成本 | 多个优化步骤 | 一次前向与自回归生成 |
| 典型风险 | 过拟合、灾难性遗忘 | prompt 敏感、输出难约束 |

## 7. 与 GPT-3 的术语接口

GPT-2 报告把没有参数更新的迁移广泛称为 zero-shot。部分实验却在上下文中提供了问答对或翻译对。GPT-3 后来将这些情况重新划分：

- 只有自然语言任务说明：zero-shot；
- 一个示例：one-shot；
- 多个示例：few-shot。

因此阅读 GPT-2 结果时，必须同时看清是否使用了上下文示例，不能只看论文使用的总标签。
