# 研究问题、创新与证据边界

## 1. 论文想解决什么

2019 年主流 NLP 流程已经大量采用预训练与微调：

1. 在大语料上学习语言表示；
2. 为情感分类、问答或翻译分别准备有标签数据；
3. 为每个任务更新模型参数。

这套流程在单个 benchmark 上很强，但仍依赖任务定义、标注集和任务专用训练。GPT-2 报告提出更激进的问题：

> 一个模型能否仅通过学习自然文本的分布，自己发现文本中反复出现的任务，并在没有任务专用参数更新的情况下执行它们？

## 2. 三层研究假设

### 2.1 自然文本里含有任务示范

网页中天然存在大量结构：

- 英文句子后跟法文翻译；
- 文章末尾出现摘要；
- 问题后跟答案；
- 文档、对话历史和回答连续出现；
- 标题后跟正文，代码注释后跟代码。

作者把这些模式视为自然发生的 demonstrations。

### 2.2 语言模型目标能够吸收这些示范

若一段序列包含任务说明 \(d\)、输入 \(u\) 与输出 \(v\)，自回归训练会优化：

\[
\log p_\theta(d,u,v)
=
\log p_\theta(d)
+\log p_\theta(u\mid d)
+\log p_\theta(v\mid d,u).
\]

最后一项正是“给定任务与输入，预测输出”的形式。训练数据没有显式标出哪部分是任务、哪部分是答案，但预测目标覆盖了所有 token。

### 2.3 容量与数据多样性是关键变量

作者训练四种规模的模型，观察到多项迁移任务随参数量增大而改善。论文因此把模型容量视为隐式任务学习能否出现的重要条件。

## 3. 主要贡献

### 3.1 WebText

论文构造了一个跨领域网页语料集：从 Reddit 上至少获得 3 karma 的外链出发，抽取链接页面正文。清洗后的实验版本约有 800 多万篇文档、40 GB 文本。

### 3.2 可逆的 byte-level BPE

输入先映射到 UTF-8 字节，再进行 BPE 合并，使词表基础符号只需覆盖 256 个字节，并能编码任意 Unicode 字符串。

### 3.3 更大的 decoder-only Transformer

最大模型在报告中记为 1542M 参数，48 层、隐藏宽度 1600、上下文长度 1024。官方仓库后来说明早期参数统计有误，发布模型通常写作 1.5B；其余检查点则写作 124M、355M 和 774M。

### 3.4 不进行下游参数更新的任务迁移

作者在语言建模、cloze、阅读理解、摘要、翻译和事实问答上，直接改变输入格式与提示，不训练新任务头，也不微调 Transformer。

### 3.5 初步的数据重叠审计

论文使用 token 8-gram Bloom filter 检查 WebText 与评测集重叠，并分别报告重叠比例与结果变化。这一步预示了后来大模型 benchmark contamination 的核心方法问题。

## 4. 论文标题需要怎样理解

“Unsupervised Multitask Learners”表达的是作者的解释框架：

- 显式训练信号只有原始文本的 next-token prediction；
- 文本中存在许多没有单独标注的任务实例；
- 模型通过统一目标学到多种行为。

这里的 “unsupervised” 沿用当时语言模型文献的用法。按今天更精确的术语，训练目标来自数据自身，通常称为 self-supervised learning。

## 5. 证据边界

论文证明了多项能力可以在没有下游梯度更新时出现，但不能据此推出：

- 模型掌握了稳定、可组合的任务规则；
- 所有下游任务都会随规模单调改善；
- 生成内容具有事实保证；
- benchmark 提升完全来自抽象泛化；
- 自回归语言建模足以覆盖所有智能目标。

论文自己承认，摘要、问答与翻译的零样本表现仍很初步；自然任务示范的具体数量与分布也没有被直接测量。
