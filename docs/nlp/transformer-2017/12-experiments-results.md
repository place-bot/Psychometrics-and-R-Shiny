# 实验设计、结果与消融

## 1. WMT14 主结果

| 模型 | EN-DE BLEU | EN-FR BLEU | 训练成本 |
|---|---:|---:|---:|
| ConvS2S | 25.16 | 40.46 | \(9.6\times10^{18}\) / \(1.5\times10^{20}\) FLOPs |
| MoE | 26.03 | 40.56 | \(2.0\times10^{19}\) / \(1.2\times10^{20}\) |
| ConvS2S Ensemble | 26.36 | 41.29 | \(7.7\times10^{19}\) / \(1.2\times10^{21}\) |
| Transformer base | 27.3 | 38.1 | \(3.3\times10^{18}\) |
| Transformer big | **28.4** | **41.0** | \(2.3\times10^{19}\) |

big 在英德任务上超过当时列出的 ensemble 两个以上 BLEU；英法 41.0 是当时强单模型结果，但低于表中 ConvS2S ensemble 41.29。

## 2. 正式版与后续 arXiv 摘要

NeurIPS 正式版报告英法 41.0。较晚 arXiv 版本摘要出现 41.8。专题主结果采用正式 proceedings 的表 2 数字，避免混用版本。

## 3. Base 与 big

| 配置 | base | big |
|---|---:|---:|
| \(N\) | 6 | 6 |
| \(d_{\text{model}}\) | 512 | 1024 |
| \(d_{\text{ff}}\) | 2048 | 4096 |
| heads | 8 | 16 |
| dropout | 0.1 | 0.3（英法 big 为 0.1） |
| steps | 100k | 300k |
| params | 65M | 213M |

## 4. 头数消融

| 头数 | \(d_k=d_v\) | dev BLEU |
|---:|---:|---:|
| 1 | 512 | 24.9 |
| 4 | 128 | 25.5 |
| 8 | 64 | 25.8 |
| 16 | 32 | 25.8 |
| 32 | 16 | 25.4 |

结果支持多头，但没有呈现“越多越好”的单调关系。

## 5. 宽度、深度与正则

- 2 层开发 BLEU 23.7，4 层 25.3，base 6 层 25.8，8 层 25.5；
- \(d_{\text{model}}=1024\) 的变体达到 26.0；
- \(d_{\text{ff}}=4096\) 的变体达到 26.2；
- 无 dropout 为 24.6，base 0.1 为 25.8；
- 无 label smoothing 为 25.3，0.1 为 25.8。

这些是单因素附近的开发集消融，无法独立证明所有现代规模下的最优配置。

## 6. 位置编码

正弦位置 25.8，学习位置 25.7，差异很小。论文选择正弦方案主要基于潜在长度外推考虑。

## 7. 额外任务

论文还把 Transformer 应用于英语 constituency parsing，在大数据和有限数据设置中展示泛化。主要论证仍以机器翻译质量、成本和并行性为中心。

## 8. 证据边界

- 训练成本依据时间、GPU 数与估计持续 FLOPs 计算；
- 不同文献的数据处理、硬件和代码不同；
- 主表未报告多随机种子置信区间；
- BLEU 不覆盖全部语义和人工质量；
- 论文证明的是当时任务上的 encoder–decoder Transformer，不能直接等同于后来所有大语言模型现象。
