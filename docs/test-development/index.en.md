# Psychological Measurement and Test Development

This topic follows the complete path from writing an item to obtaining an interpretable score in psychological and educational testing. The goal is not to memorize isolated definitions, but to learn how to decide whether an item measures its intended construct, how to define transparent scoring rules, and how to handle response bias in sensitive questions.

## Learning objectives

After completing this topic, you should be able to:

1. Evaluate item quality in terms of purpose, target population, construct, item format, response scale, fairness, and response bias.
2. Identify ambiguous wording, multiple negatives, double-barreled items, missing time frames, and social-desirability bias.
3. Distinguish holistic scoring from analytic scoring and construct a rubric with behavioral anchors.
4. Compare scoring algorithms for Mark-M items and explain which response behaviors each algorithm rewards or penalizes.
5. Formulate a probability model for a randomized response scheme (RRS) and derive its prevalence estimator, standard error, and sample-size requirement.
