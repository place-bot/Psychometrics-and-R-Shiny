# 心理测量与 Test Development

本专题围绕心理与教育测验从“写出一道题”到“得到一个可解释分数”的完整链条展开。重点不是背诵孤立定义，而是学习如何判断一个项目（item）是否测到了目标构念、如何建立透明的评分规则，以及如何处理敏感问题中的反应偏差。

## 学习目标

完成本专题后，应当能够：

1. 使用目的、目标群体、构念、题型、反应量表、公平性与反应偏差等维度批判项目质量。
2. 识别含糊措辞、多重否定、双重问题、时间框架缺失和社会赞许性偏差。
3. 区分整体式评分（holistic scoring）与分析式评分（analytic scoring），并写出带行为锚点的 rubric。
4. 比较 Mark-M 多选题的不同计分算法，说明每种算法奖励或惩罚了什么作答行为。
5. 建立随机化反应方案（randomized response scheme, RRS）的概率模型，并推导比例估计量、标准误和样本量要求。
