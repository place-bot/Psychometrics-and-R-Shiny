# Table 1 完整手算与原文排版错误

## 设定

\[
K=4,
\qquad
\boldsymbol q^*=1110.
\]

题目真正需要前三个属性。只有前三个属性全掌握时成功概率为 \(.725\)，其余为 \(.225\)。

Table 1 给出 16 个完整模式的权重。将属性 4 折叠掉后：

| \(\boldsymbol\alpha_{1:3}\) | 权重 | 成功概率 |
| --- | ---: | ---: |
| \(000-\) | .090 | .225 |
| \(100-\) | .157 | .225 |
| \(010-\) | .112 | .225 |
| \(001-\) | .112 | .225 |
| \(110-\) | .125 | .225 |
| \(101-\) | .130 | .225 |
| \(011-\) | .137 | .225 |
| \(111-\) | .137 | .725 |

## 折叠一个组

模式 \(000-\) 合并 \(0000\) 与 \(0001\)：

\[
w(000-)
=
.053+.037
=
.090.
\]

\[
\begin{aligned}
p(000-)
&=
\frac{.053(.225)+.037(.225)}
{.053+.037}\\
&=.225.
\end{aligned}
\]

## 原文排版错误

正式 PDF 第 259 页该式分母印成

\[
.225+.225.
\]

分母应由两个模式权重组成：

\[
.053+.037.
\]

表内合并权重 \(.090\) 和最终概率 \(.225\) 都支持这个修正。

## 正确 q-vector 的 GDI

总体平均成功率：

\[
\bar p
=
.225(1-.137)+.725(.137)
=
.2935
\approx .294.
\]

\[
\begin{aligned}
\varsigma^2_{1:3}
&=
\sum w(\boldsymbol\alpha_{1:3})
p^2(\boldsymbol\alpha_{1:3})
-\bar p^2\\
&\approx .116-.294^2\\
&=.030.
\end{aligned}
\]

使用原表未四舍五入的逐格计算，本站脚本得到：

\[
\varsigma^2_{1:3}=0.029558.
\]

## 增设属性

候选 \(1111\) 将每个同质组按属性 4 再切成两组。子组成功概率保持相同，所以

\[
\varsigma^2_{1:4}
=
\varsigma^2_{1:3}
=
0.029558.
\]

最大 GDI 本身无法区分 \(1110\) 和 \(1111\)，最简性规则选择 \(1110\)。

## 同时漏设与增设

候选 \(0111\) 遗漏真正需要的属性 1，并加入无关属性 4。Table 1 给出折叠成功概率：

\[
.225,\ .225,\ .225,\ .225,\ .492,\ .225,\ .225,\ .456.
\]

本站逐格计算：

\[
\varsigma^2_{2:4}=0.012524\approx .013.
\]

遗漏属性将若干 \(.225\) 与 \(.725\) 类别平均，组间差异明显减少。
