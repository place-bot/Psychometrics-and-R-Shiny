# 模拟实验设计

## 研究问题

作者要检查在理想条件下，sequential EM-based \(\delta\)-method 能否：

1. 保留原本正确的 q-vector；
2. 找到单个错误行；
3. 处理漏标、多标和替换；
4. 同时修复三道题的错误；
5. 通过 \(\varepsilon\) 和更新后的项目参数选出正确 Q。

## 固定设计

| 条件 | 原文取值 |
| --- | ---: |
| 学生数 \(N\) | 5,000 |
| 题目数 \(J\) | 30 |
| 属性数 \(K\) | 5 |
| 属性模式 | 32 个模式等概率 |
| guessing | 所有题 .20 |
| slipping | 所有题 .20 |
| DINA 收敛标准 | .001 |
| 初始估计 | empirical Bayesian EM |
| 程序 | Ox |

## 12 个分析条件

Condition 0 使用正确 Q。Conditions 1--10 每次只改题 1、11 或 21 的一行，覆盖单、双、三属性题。Condition 11 同时改三行。

| 条件 | 题号 | 原 Q | 分析用 Q | 加入 | 删除 | 总改格数 |

| 1 | 1 | 10000 | 01000 | 1 | 1 | 2 |

## 阈值与更新

作者使用：

\[
\varepsilon\in\{.00,.01,.05,.10,.20\}.
\]

每个阈值产生候选 Q 后，再运行 5 个 EM cycles，比较：

- 改动 q-vector 的数量；
- 被改题目的推荐 q-vector；
- 全测验 \(\bar g+\bar s\)。

## 设计强项

- Q 结构完全平衡；
- 单、双、三属性题都有专门错误条件；
- 错误类型覆盖增、删与替换；
- Condition 11 检查多个错误对后验的共同污染；
- 阈值从极宽松到极严格。

## 设计限制

原文没有形成样本量、题长、属性相关、参数质量和 Q 错误比例的全因子实验；报告的是一组大样本、高区分度、均匀属性模式条件下的可行性检查。
