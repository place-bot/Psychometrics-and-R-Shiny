# 阈值与最终决策

## 为什么需要阈值

理想假想题中，正确 q-vector 后继续加无关属性会令 \(\delta\) 下降。真实数据中会受到：

- 抽样误差；
- 后验估计误差；
- DINA 近似误差；
- 属性模式比例不均衡；
- 题目内部多种解题策略；
- 初始 Q 错误传播。

因此新增无关属性也可能带来很小的正增量。若只要求

\[
\widehat\delta^{(s)}
>
\widehat\delta^{(s-1)},
\]

顺序搜索容易继续加属性。

## 原文停止准则

新增属性被接受需满足

\[
\widehat\delta_j^{(s)}
-
\widehat\delta_j^{(s-1)}
>
\varepsilon.
\]

\(\varepsilon\) 表示新增属性至少要贡献多少区分度。

## 阈值方向

| \(\varepsilon\) | 搜索行为 | 主要风险 |
| ---: | --- | --- |
| 0 或很小 | 微小改善也接受 | q-vector 过密 |
| 中等 | 忽略小幅随机波动 | 可能较好平衡 |
| 很大 | 只有强改善才接受 | q-vector 过稀 |

论文把小 \(\varepsilon\) 称为 liberal，把大 \(\varepsilon\) 称为 stringent。

## 原文怎样选阈值

作者没有给出一个对所有数据固定的 \(\varepsilon\)。流程是：

1. 取一串阈值；
2. 每个阈值生成一套候选 Q；
3. 在候选 Q 下追加 EM；
4. 比较 \(\bar g+\bar s\)；
5. 比较与原 Q 的格子、整行一致率；
6. 审查修改的内容解释。

原文三个实验使用：

| 实验 | 阈值 |
| --- | --- |
| 模拟 | .00、.01、.05、.10、.20 |
| 分数减法 | .000 到 .050，步长 .001 |
| NAEP | .000 到 .100，步长 .001 |

## 保守性原则

作者提出两点实践约束：

1. 当前 Q 只是许多可能拟合数据的 Q 之一；拟合更好的 Q 可能缺乏可解释性。
2. 建立 Q 通常投入大量内容分析和专家工作；没有强证据时，应对原规范采取较保守态度。

这意味着一个小幅降低 \(\bar g+\bar s\) 的候选，不应自动覆盖已有内容证据。

## 建议的现代决策表

| 统计改善 | 内容证据 | 建议 |
| --- | --- | --- |
| 大 | 支持修改 | 修改并交叉验证 |
| 大 | 反对修改 | 检查遗漏属性、题目线索和模型失配 |
| 小 | 支持修改 | 收集更多样本或过程数据 |
| 小 | 反对修改 | 保留原 Q |
| 恶化 | 任意 | 通常保留原 Q，并检查估计稳定性 |

## 需要额外报告

为了防止只在训练样本上追求更低 \(s+g\)，后续研究可增加：

- 留出样本的 log-likelihood；
- attribute classification 稳定性；
- bootstrap 中 Q 行被推荐的频率；
- 多起点和不同初始 Q 的一致性；
- 专家间一致度；
- 修改前后的外部效标关系。

这些项目超出 2008 年原文实验，但能把阈值选择从单样本拟合扩展到稳定性与效度。
