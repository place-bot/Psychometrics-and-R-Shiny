# 分数减法数据与设计

## 数据来源

论文使用 Tatsuoka 收集并多次分析的分数减法数据子集：

| 项目 | 数值 |
| --- | ---: |
| 学生 | 2,144 名中学生 |
| 题目 | 15 道分数减法题 |
| 属性 | 5 个 |
| 反应 | 二分 |
| 初始 Q 来源 | Mislevy (1996) 对同一数据的 Q |

## 五个属性

1. 执行基本分数减法运算；
2. 化简或约分；
3. 把整数部分和分数部分分开；
4. 从整数部分借 1 到分数部分；
5. 把整数转换为分数。

## 验证设置

\[
\varepsilon=.000,.001,\ldots,.050.
\]

每套候选 Q 下追加 100 个 EM cycles，获得最终项目参数。程序仍由作者用 Ox 实现。

## 这项应用检查什么

分数减法 Q 已有明确的认知分析传统。此处重点是：

- 数据驱动程序会不会无故改动一个成熟 Q；
- 哪些 \(\varepsilon\) 能完整保留原 Q；
- 单看统计指标会不会提出内容上荒谬的属性要求。

## 与常见 536 人版本的区别

CDM 文献常见的 fraction subtraction 数据有不同子集和不同 Q。本文明确报告：

\[
N=2144,\quad J=15,\quad K=5.
\]

后续软件示例或其他论文可能使用 536 人、12 题、4 属性版本。复现与引用时需要按论文版本核对，不能把不同子集混成同一个实验。
