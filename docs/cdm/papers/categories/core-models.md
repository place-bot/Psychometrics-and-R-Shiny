# CDM 核心模型：10 篇

## 已完成

- [de la Torre (2009)：DINA 模型与参数估计](../de-la-torre-2009/index.md)

  已制作 16 个页面，覆盖 Q 矩阵、理想反应、guess/slip、边际似然、EM、标准误、HO-DINA、MCMC 边界、模拟实验、真实数据和可运行复现。

- [de la Torre (2011)：G-DINA 模型框架](../de-la-torre-2011/index.md)

  已制作 21 个页面，覆盖约化属性模式、identity/logit/log link、design/weight/restriction matrix、MMLE、Wald 检验、模拟、两组真实数据、勘误、后续官方代码和可运行复现。
