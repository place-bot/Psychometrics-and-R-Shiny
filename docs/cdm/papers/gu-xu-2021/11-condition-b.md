# Condition B：\(Q^\star\) 的列互异

## 1. 定义

将完整 Q 写成

\[
Q=
\begin{pmatrix}
I_K\\
Q^\star
\end{pmatrix}.
\]

Condition B 要求

\[
Q^\star_{\cdot k}\ne Q^\star_{\cdot\ell}
\qquad
\text{对所有 }k\ne\ell.
\]

比较的是删除一套单位阵之后的列。

## 2. 为什么只比较 \(Q^\star\)

\(I_K\) 的列天然互异，但这种差异来自属性标签本身。若其余题对属性 \(k\) 和 \(\ell\) 的使用方式完全一致，连续参数可能吸收两列的结构差异。

\(Q^\star\) 的互异性给每个属性增加一段独立结构编码：

\[
k
\longmapsto
Q^\star_{\cdot k}.
\]

恢复这些编码后，属性列只能整体置换，无法形成更复杂的替代结构。

## 3. 二进制编码直觉

若 \(Q^\star\) 有 \(m\) 行，最多可提供

\[
2^m
\]

个不同列码。要编码 \(K\) 个属性，至少需要

\[
m\ge\lceil\log_2K\rceil.
\]

这正是最少题数公式中对数项的来源。

## 4. \(K=2\) 的失败结构

在完整性和每列三次测量成立时，若 Condition B 失败，\(K=2\) 的 Q 只能具有如下形状，允许行置换：

\[
Q=
\begin{pmatrix}
1&0\\
0&1\\
1&1\\
\vdots&\vdots\\
1&1
\end{pmatrix}.
\]

删除 \(I_2\) 后，两列均为全 1。已有结果证明，对任意合法 DINA 参数都存在无穷多组替代参数给出相同反应分布，所以此结构连泛识别也不成立。

## 5. 与“列重复”的区别

Condition B 不要求整张 Q 的列互异。整张 Q 含 \(I_K\) 后，各列当然不同。它要求锚题之外的测量结构也能区分属性。

检查步骤为：

1. 每个属性选出一行单位向量；
2. 删除这些行；
3. 把剩余矩阵按列读取；
4. 计算不同列向量的数量；
5. 数量等于 \(K\) 时通过。

## 6. 多套单位阵

若 Q 含两套 \(I_K\)，删除其中一套后，另一套仍留在 \(Q^\star\)，所以 B 自动成立。

这说明早期“双完整”条件为何安全，也说明它包含多余结构：B 只需要 \(K\) 个互异列码，并未限定列码必须形成另一套单位阵。
