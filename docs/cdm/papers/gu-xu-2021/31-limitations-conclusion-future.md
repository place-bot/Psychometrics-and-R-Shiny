# 局限、结论与未来工作

## 1. 结论

论文建立了未知 Q 场景下的联合识别框架。

### DINA

\[
A+B+C
\]

是严格联合识别的必要充分条件：

- A：含 \(I_K\)；
- B：\(Q^\star\) 列互异；
- C：每属性至少三题。

### DINA 泛识别

属性只由两题测量时，Q 的局部结构和潜类依赖决定能否泛识别。\(K=2\) 得到完整必要充分刻画。

### 一般 RLCM

- C 是泛识别必要条件；
- 泛完整性是必要条件；
- D/E 是充分条件；
- \(K=2\) 时 D/E 必要且充分。

## 2. 理论局限

### 高维泛识别仍未完全刻画

当 \(K>2\) 时，一般 RLCM 的 D/E 是否可以进一步放松，本文没有给出完整结论。DINA 的 Theorem 2 也未覆盖所有高维 Q 结构。

### 全正潜类比例

主结果假设

\[
p_{\boldsymbol\alpha}>0
\]

对全部 \(2^K\) 潜类成立。真实教育数据可能只支持少量属性模式，属性层级还会强制部分模式概率为 0。

### 二元属性与二元反应

主框架聚焦二元属性、二元题目。多级属性、多分题目和连续潜在能力需要新的参数空间和等价关系。

## 3. 实验局限

- 没有真实数据；
- 主要穷举场景为 \(K=2,J=5\)；
- 样本量常设为 \(10^5\)，弱化了小样本问题；
- 似然图多为单个模拟数据集；
- 没有系统报告 Q 恢复率、运行时间或算法比较；
- G-DINA 图会过滤未通过强单调检查的候选。

## 4. 代码局限

- MATLAB 驱动脚本依赖当前目录和预计算 `.mat`；
- 部分预计算结果未收入仓库；
- 若干注释、Theorem 编号和输出文字与最终论文不一致；
- 条件搜索和 Hall 枚举随 \(K\) 或组合数快速增长；
- 个别函数签名或早退路径需要修正后才能稳健复用。

## 5. 原文未来工作

论文提出：

1. 将理论扩展到有序多级属性；
2. 研究同时含离散与连续潜变量的模型；
3. 在满足识别条件的 Q 集合上开发似然或 Bayesian 估计；
4. 对不完整 Q 研究 \(p\)-partial identifiability；
5. 处理属性层级导致的禁止模式。

## 6. 对当前 CAT/生成式选题方向的接口

这篇论文没有研究自适应选题序列。它提供的是题库测量设计的先决约束：

\[
\text{题目选择策略}
\]

无论由信息量、强化学习或生成模型给出，都应避免让实际施测长期缺少：

- 属性锚点；
- 属性列区分；
- 足够重复测量。

对 CAT，完整题库满足识别条件仍不够。每名学生实际走过的自适应路径也需要保留足够的局部识别信息。把 A/B/C 或 D/E 转化为在线序列约束，是一个可以继续发展的研究问题。

## 7. 一个值得延伸的方向

可以把在线选题写成带结构安全约束的策略：

\[
j_{t+1}
\sim
\pi_\phi\!\left(
j\mid
\boldsymbol R_{1:t},
Q_{\mathrm{remain}},
\mathcal I_t
\right),
\]

并要求每个时点的可达未来题集仍能完成某种识别覆盖。这样，生成式策略负责长期效用，识别约束负责测量有效性。

这项延伸属于本站研究推导，未在 Gu 与 Xu（2021）中实现。
