# Condition C：每个属性至少三次

## 1. 定义

\[
\sum_{j=1}^{J}q_{jk}\ge3,
\qquad
k=1,\ldots,K.
\]

每个属性至少被三道题要求。

## 2. 一次测量

若属性 \(k\) 只出现在一题中，和它相关的信息集中在单个 Bernoulli 指标。题目参数、属性比例和 Q 结构可以连续补偿，模型无法局部泛识别。

Theorem 2 首先给出：

\[
\exists k:\sum_jq_{jk}=1
\quad\Longrightarrow\quad
\text{DINA 不具有泛识别}.
\]

## 3. 两次测量

两题对应的二指标混合分布有时能借助其他属性的依赖结构得到识别，有时仍存在连续替代参数。因此：

- 两次测量无法保证严格识别；
- 两次测量在特定 Q 结构下可达到泛识别；
- 参数越接近属性独立的零测集，有限样本估计越不稳定。

四题两属性例子完整展示了这个边界。

## 4. 三次测量的直觉

潜类模型中，一个二元潜变量通常需要至少三个条件独立指标来稳定分离：

```text
属性 k
 ├── 题 a
 ├── 题 b
 └── 题 c
```

三组响应概率提供足够的高阶联合矩，使题目参数与混合比例无法任意互换。

## 5. DINA 与一般 RLCM 的差异

在 DINA：

- C 是严格识别的必要条件；
- C 在泛识别中可按 Theorem 2 局部放松。

在一般 RLCM：

- Theorem 3 证明 C 是泛识别的必要条件；
- 任一属性只出现一题或两题时，对任意参数都能构造无穷多替代对象。

一般 RLCM 的题目参数更自由，DINA 中由合取结构带来的特殊补充信息不再足以保证识别。

## 6. 官方代码中的命名偏差

论文主文固定使用：

- A = completeness；
- B = distinctness；
- C = repetition。

官方 `check_Theorem1.m` 的注释把“至少三题”标成 Condition B，把“\(Q^\star\) 列互异”标成 Condition C。实际布尔计算同时检查两项，最终合取值仍对应 Theorem 1。

阅读输出时应以论文定理的 A/B/C 名称为准。
