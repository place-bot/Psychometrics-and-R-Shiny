# 泛完整性与二分图匹配

## 1. 定义

一个 \(J\times K\) Q 泛完整，指它含某个 \(K\times K\) 子矩阵，经行列置换后对角线全为 1：

\[
\begin{pmatrix}
1&*&\cdots&*\\
*&1&\cdots&*\\
\vdots&\vdots&\ddots&\vdots\\
*&*&\cdots&1
\end{pmatrix}.
\]

星号可以是 0 或 1。

## 2. 与完整性的关系

完整性要求子矩阵恰为 \(I_K\)。泛完整性只要求每个属性能匹配到一道人各不同的相关题。

\[
\text{完整}
\Longrightarrow
\text{泛完整}.
\]

反向关系不成立。例如

\[
\begin{pmatrix}
1&1\\
1&1
\end{pmatrix}
\]

泛完整，同时没有单属性题。

## 3. 二分图表示

构造二分图：

- 左侧节点：\(K\) 个属性；
- 右侧节点：\(J\) 道题；
- \(q_{jk}=1\) 时连接属性 \(k\) 与题 \(j\)。

Q 泛完整，当且仅当存在一个覆盖全部属性的匹配，每个属性匹配到不同题。

```text
属性 1 ───── 题 a
属性 2 ───── 题 c
属性 3 ───── 题 b
```

## 4. Hall 条件

对任意属性子集 \(S\)，令 \(N(S)\) 为至少测量 \(S\) 中一个属性的题目集合。Hall 婚配定理给出：

\[
|N(S)|\ge|S|
\quad
\text{对所有 }S\subseteq\{1,\ldots,K\}
\]

当且仅当存在覆盖全部属性的匹配。

## 5. 官方实现

`check_generic_complete.m` 枚举全部

\[
2^K-1
\]

个非空属性子集，对每个子集计算邻居题数并检查 Hall 条件。

时间复杂度至少随 \(2^K\) 增长。对较大 \(K\)，可以直接运行二分图最大匹配，在多项式时间内判断是否存在大小为 \(K\) 的匹配。

本站脚本使用直接匹配搜索来保持零依赖和易读性；生产实现可换成 Hopcroft--Karp 算法。

## 6. 统计含义

泛完整性允许每个锚题同时依赖其他属性。一般 RLCM 的多参数反应面能利用这些交叉题分离属性方向，因而泛识别无需强制单属性锚题。

这项放松只对应泛识别。严格联合识别仍需更强结构。
