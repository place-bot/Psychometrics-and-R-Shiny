# 一般 RLCM 中重复性的必要性

## 1. Theorem 3

在一般 RLCM 中，Condition C 是联合泛识别的必要条件：

\[
\sum_{j=1}^{J}q_{jk}\ge3
\quad
\text{对每个 }k.
\]

若某属性只被一题或两题要求，则对任意合法

\[
(\Theta,\boldsymbol p)
\]

都存在无穷多组

\[
(\bar Q,\bar\Theta,\bar{\boldsymbol p})
\nsim
(Q,\Theta,\boldsymbol p)
\]

给出同一反应分布。

## 2. 为什么结论强

它说明失识别覆盖整个参数空间，而非一个零测集。增加样本量不会解决结构歧义。

## 3. 两题情形的构造思路

经行列置换，把只出现两次的属性放在第 1 列，相关题放在前两行：

\[
Q=
\begin{pmatrix}
1&\boldsymbol v_1^\top\\
1&\boldsymbol v_2^\top\\
\boldsymbol0&Q^\star
\end{pmatrix}.
\]

构造替代矩阵时，扩大前两题的属性要求，例如把部分 0 改为 1。随后：

1. 保持第 3 到 \(J\) 题参数不变；
2. 在前两题的一部分 \(\bar\theta_{j,\alpha}\) 上选择小扰动；
3. 用线性方程解出其余前两题参数；
4. 同步解出 \(\bar{\boldsymbol p}\)；
5. 扰动足够小时，概率范围和单调性仍成立。

自由扰动可以连续取值，所以得到无穷多等价模型。

## 4. DINA 为何有例外

DINA 每题只有两个概率 \(c_j,g_j\)，参数限制很强。属性间依赖有时能补足两题测量的信息，因此 Theorem 2 存在泛识别情形。

一般 RLCM 允许所需属性的主效应和交互效应自由变化。额外自由度足以吸收结构变化，导致两题测量对泛识别也不够。

## 5. Study VII 的数值构造

作者分别设置：

\[
(K,J)=(3,20)
\quad\text{和}\quad
(5,20),
\]

每个场景构造 70 组替代参数。全部替代模型与真模型的反应概率最大差为

\[
1.30\times10^{-18}
\quad\text{和}\quad
5.42\times10^{-19},
\]

均低于 MATLAB 双精度机器误差量级。

## 6. 测验设计含义

若计划使用 G-DINA、LCDM 等一般模型并联合学习 Q，每个属性至少安排三道相关题是底线。单属性题可以缺少，但测量次数不能降到两次。
