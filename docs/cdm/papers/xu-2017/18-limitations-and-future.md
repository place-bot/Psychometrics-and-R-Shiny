# 局限、后续修正与未来工作

## 1. C1、C2 偏强

三套 \(I_K\) 是清晰且易检查的充分设计，但实际题库常有多属性题，单属性题可能难以编制。主定理没有声称一般 RLCM 只有满足该设计才能识别。

后续工作继续寻找：

- 更弱的 Q 结构条件；
- partial identifiability；
- generic identifiability；
- 针对具体模型的必要充分条件。

## 2. Q 被视为已知且正确

论文固定 Q，并依赖 Q 给潜在类列赋予属性语义。若 Q 错设：

- 强制相等的项目概率可能错误；
- C1/C2 的审查对象也可能错误；
- 固定标签下的 strict identifiability 结论不能直接移植。

Xu 与 Shang (2018) 将问题推进到 latent structure matrix 的识别和估计，并提供 likelihood-based 方法、模拟与教育数据例子。

## 3. 全部属性类具有正比例

原文假设

\[
p_{\boldsymbol\alpha}>0
\quad\forall\boldsymbol\alpha.
\]

属性层级会令某些组合不可能，产生结构零。原文在 Remark 3 中明确把层级属性下的扩展列为未来方向。

后续理论需要在缩小后的 latent class space 上重新定义可区分列和锚定条件。

## 4. 二分响应

模型假设 \(R_j\in\{0,1\}\)。多项、名义或连续反应需要不同的条件概率张量和识别条件，不能由二分定理直接推出。

本站索引中的 Lin 与 Xu、Liu 与 Culpepper 等论文沿多项和名义反应方向扩展。

## 5. C2 含未知参数

一般 RLCM 中，C2 写成

\[
\left(
\theta_{j,\boldsymbol e_k}:j>2K
\right)
\ne
\left(
\theta_{j,\boldsymbol0}:j>2K
\right).
\]

设计阶段还不知道真 \(\Theta\)。三套 \(I_K\) 提供纯结构充分条件；只用两个单位块时，论文建议在收集数据后经验检查 C2。此时还需考虑估计误差，接近相等与严格相等在有限样本中很难区分。

## 6. 理论识别与弱识别

只要差异非零，C2 在数学上成立：

\[
\theta_{j,\boldsymbol e_k}
-
\theta_{j,\boldsymbol0}
\ne0.
\]

差异非常小时，有限样本仍会出现高相关、巨大标准误和多起点不稳定。论文没有给出 separation margin 或误差界。

## 7. 没有有限样本实验

原文没有检验：

- C2 差异逐渐趋近 0 时的 RMSE；
- 类比例稀疏时的估计；
- 三单位块条件下不同 \(N\) 的恢复表现；
- 不满足条件时软件会呈现何种症状。

这些问题需要专门的模拟研究。

## 8. 没有自适应数据机制

定理针对固定 \(J\) 维观测向量的群体分布。CAT 中：

1. 每个学生只作答一个依赖历史的题目子集；
2. 不同题目的曝光概率由 policy 决定；
3. 某些 Q 行可能几乎没有观测；
4. 学生级后验在每次作答后更新。

要把 Xu 的识别思想用于 CAT，需要把题库结构条件与动态探索覆盖连接起来。一个可能的研究问题是：

> 自适应 policy 需要对哪些锚定题和 Q 结构保持正曝光概率，才能在群体累计数据中继续识别反应模型？

这与生成整套固定序列的研究有直接区别：CAT 的下一题条件于刚收到的反应，序列分布本身由闭环交互产生。

## 后续阅读的分工

| 文献 | 相对 Xu (2017) 推进的方向 |
| --- | --- |
| Xu & Zhang (2016) | DINA 的专门识别条件 |
| Xu & Shang (2018) | latent structure / Q 型结构的识别与估计 |
| Gu & Xu (2020) | 一般 RLCM 的 strict 与 partial identifiability 框架 |
| Culpepper (2023) | 二分 RLCM 的更弱识别条件 |
| Lin & Xu (2024) | 多项反应 DINA |
| Liu & Culpepper (2024) | 名义反应 RLCM |

这些后续结果不会使 Xu (2017) 失去价值：它首次把 Q 限制、边际矩阵消元和严格识别系统连接起来，并提供了可直接解释为测验设计的充分条件。
