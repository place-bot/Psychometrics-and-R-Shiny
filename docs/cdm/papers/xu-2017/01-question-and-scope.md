# 问题、贡献与证据边界

## 研究问题

学生的属性模式不可直接观测，研究者只看到 \(J\) 道二分题的作答。论文追问：

> 已知 Q 矩阵与模型限制时，观测反应分布能否唯一确定全部项目成功概率和全部属性模式比例？

写成映射就是

\[
(\Theta,\boldsymbol p)
\longmapsto
\left\{
P(\boldsymbol R=\boldsymbol r\mid Q,\Theta,\boldsymbol p):
\boldsymbol r\in\{0,1\}^J
\right\}.
\]

若这个映射一对一，参数可识别；若两组不同参数产生完全相同的观测分布，即使样本量趋于无穷也无法由数据判断哪一组正确。

## 为什么一般 latent class 结果不够

无约束 Bernoulli latent class model 的识别理论常用代数几何或 Kruskal 三路分解。此类结果往往给出 generic identifiability：除去一个 Lebesgue 测度为零的异常集合，参数通常可以识别。

RLCM 的许多项目概率被 Q 矩阵强制相等。受约束参数空间本身可能落在无约束空间中的低维集合里。因此，无约束模型中“几乎处处成立”的结论不能自动覆盖这一整块受约束空间。

Xu 的目标是利用限制结构本身，证明严格意义上的唯一性。

## 两项主要贡献

### 统一的充分条件

论文给出一组适用于多种二分反应诊断模型的充分条件：

\[
Q=
\begin{pmatrix}
I_K\\
I_K\\
Q'
\end{pmatrix}
\quad\text{并满足 C2}.
\]

这些条件把抽象的参数识别问题转成测验设计规则。

### 边际矩阵证明技术

论文把完整反应模式概率改写成 \(T\)-矩阵边际：

\[
T(Q,\Theta)\boldsymbol p.
\]

再通过

\[
T(Q,\Theta-\boldsymbol\theta^*\boldsymbol 1^\top)
=
D(\boldsymbol\theta^*)T(Q,\Theta)
\]

构造大量零元素，逐列隔离待识别参数。这套方法能够直接利用 Q 限制带来的相等关系。

## 原文提供了哪些证据

| 证据类型 | 原文是否提供 | 内容 |
| --- | :---: | --- |
| 严格定理 | 是 | C1、C2 \(\Rightarrow(\Theta,\boldsymbol p)\) 可识别 |
| 完整证明 | 是 | 主定理、两个命题、两个引理 |
| 非识别构造 | 是 | C1 成立而 C2 失败时的 DINA 参数族 |
| 大样本推论 | 是 | MLE 一致性与渐近正态性的论述 |
| 模拟实验 | 否 | 没有样本量、重复次数或结果表 |
| 真实数据分析 | 否 | 没有数据集 |
| 软件实现 | 否 | 没有公开代码地址 |

## 论文没有直接解决的问题

- C1、C2 在一般 RLCM 中是否必要；
- Q 不完整时，受约束参数空间上的 generic identifiability；
- 属性层级导致部分 \(p_{\boldsymbol\alpha}=0\) 时的识别；
- Q 矩阵未知或错误时的联合识别；
- 有限样本下参数估计的数值稳定性；
- 题目按 CAT 规则动态选择后的可识别性与一致性。

这些边界决定了本站后面的“实验”页面会报告理论证据和计算核验，不会给论文补上一组并不存在的真实数据结果。
