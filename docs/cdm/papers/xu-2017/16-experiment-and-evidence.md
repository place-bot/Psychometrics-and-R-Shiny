# 原文证据与 Experiment 边界

## 原文没有经验实验

这是一篇理论论文。全文结构为：

1. 模型与应用背景；
2. 可识别性定义和 \(T\)-矩阵；
3. C1、C2 与主定理；
4. 主定理、命题和引理的证明。

原文没有：

- 模拟数据集；
- 真实教育数据；
- 样本量条件表；
- 重复次数；
- 参数恢复误差；
- 与其他方法的 empirical comparison；
- 运行时间；
- 消融实验。

因此无法报告“用了哪个数据集、怎样划分、指标多少”。把原文证明写成实验结果会混淆证据类型。

## 原文的理论实验设计

论文实际比较了三种设计层次：

| 设计 | 可识别结论 | 原文证据 |
| --- | --- | --- |
| Q 不完整 | 理想 DINA 中已有属性类不可区分 | 相同理想反应列 |
| 只有 C1 | 一般情形不能保证识别 | 命题 2 的显式等价参数族 |
| C1 + C2 | \((\Theta,\boldsymbol p)\) 严格可识别 | 定理 1 与五步证明 |

这相当于结构层面的对照：

\[
\text{缺少锚点}
\;\to\;
\text{两套锚点}
\;\to\;
\text{两套锚点 + 额外区分}.
\]

## 本站计算核验的目的

本站脚本针对原文代数做四项有限检查：

1. 自动判断 complete、C1 与 DINA 下可由 Q 保证的 C2；
2. 从完整反应模式分布求边际，并与
   \(T(Q,\Theta)\boldsymbol p\) 比较；
3. 精确验证命题 3 的变换等式；
4. 验证 C1 成立而 C2 失败时的两套参数碰撞。

命题 3 的核验对象为

\[
T(Q,\Theta-\boldsymbol\theta^*\boldsymbol1^\top)
=
D(\boldsymbol\theta^*)T(Q,\Theta).
\]

## 这些计算不能替代什么

\(T\)-矩阵在某个给定 \(\Theta\) 下满列秩，只说明**已知 \(\Theta\)** 时可以从边际识别
\(\boldsymbol p\)。主定理还要求当 \(\Theta\) 未知时排除另一套
\(\bar\Theta\) 同时补偿 \(\bar{\boldsymbol p}\) 的可能。

因此：

- 单次秩检查没有证明完整主定理；
- 有限枚举没有覆盖任意 \(K,J\)；
- 计算结果用于核对公式、维数和反例；
- 一般结论仍来自原文的符号证明。

## 若要补做真正模拟

合理的后续模拟可操纵：

- C2 对比
  \(\min_j|\theta_{j,\boldsymbol e_k}-\theta_{j,\boldsymbol0}|\)；
- 类比例最小值；
- \(N\)；
- 两个、三个或非纯题块设计；
- Q 错设；
- EM 初值。

指标可包括参数 RMSE、属性分类误差、信息矩阵条件数、多起点解差异和覆盖率。此类结果属于后续研究，不能归入 Xu (2017) 原文实验。
