# Experiment：模拟设计

## 因素设计

模拟交叉以下条件：

| 因素 | 水平 |
| --- | --- |
| 样本量 \(N\) | 500、1000、2000、4000 |
| 属性数 \(K\) | 3、4 |
| 属性相关 \(\rho\) | 0、0.05、0.15、0.25 |
| 每个条件重复 | 100 |

总计

\[
4\times2\times4\times100
=
3200
\]

个数据集，每个数据集拟合三种 MCMC 方法。

## 属性模式生成

当 \(\rho=0\) 时，从 \(2^K\) 种模式均匀生成。

当 \(\rho>0\) 时，先生成

\[
\boldsymbol\theta_i
\sim
N(\boldsymbol0,\Sigma),
\]

其中

\[
\Sigma
=(1-\rho)I_K+\rho\boldsymbol1\boldsymbol1^{\mathsf T},
\]

再二值化：

\[
\alpha_{ik}
=
I(\theta_{ik}\ge0).
\]

各属性边际掌握率为 0.5，依赖由潜在正态相关引入。

## \(K=3\) 的真 Q

共有 \(J=18\) 题：

- \((100),(010),(001)\) 各重复 3 次；
- \((110),(101),(011)\) 各重复 2 次；
- \((111)\) 重复 3 次。

## \(K=4\) 的真 Q

同样有 \(J=18\) 题：

- 四个单位向量各重复 2 次；
- 六个二属性组合各出现 1 次；
- 四个三属性组合各出现 1 次。

两个 Q 均满足论文的可识别限制。

## 比较方法

| 缩写 | 方法 | Q 更新 |
| --- | --- | --- |
| MH | 本文受限 Metropolis | DS2，\(B=2K\) |
| CGibbs | 本文受限 Gibbs | 顺序更新每个元素 |
| Gibbs | Chung（2014） | 无约束 Gibbs |

## MCMC 设置

每次拟合：

\[
\text{chain length}=30{,}000,
\qquad
\text{burn-in}=15{,}000.
\]

\(s,g,\pi\) 从先验抽初值，Q 从 \(\mathcal Q\) 随机抽初值。

## 评估指标

### 整张 Q 恢复

100 次重复中满足

\[
\widehat Q=Q
\]

的次数；比较前允许属性列置换。

### 逐元素准确率

\[
\frac{1}{JK}
\sum_{j=1}^{J}\sum_{k=1}^{K}
I(\widehat q_{jk}=q_{jk}),
\]

再对 100 次重复平均并换算为百分比。

### 题目参数 MSE

分别对 \(\widehat s_j\) 和 \(\widehat g_j\) 计算均方误差，原文用 Figures 1--2 按题目 q-vector 展示。

## 可复现性缺口

正文没有报告模拟中真 \(s_j,g_j\) 的具体生成值或分布；公开 R 文件只复现实证分析，公开 C++ 提供 `sim_Y_dina()`，没有附上生成 Table 1 与 Figures 1--2 的完整模拟驱动脚本和随机种子。

因此可以精确复核设计因素、Q、链设置和表中结果，无法仅凭随文材料逐位重建所有模拟数据。
