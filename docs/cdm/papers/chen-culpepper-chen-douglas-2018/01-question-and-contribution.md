# 研究问题、贡献与证据边界

## 研究问题

DINA 的应用通常从一张专家指定的 Q 开始。若第 \(j\) 题需要第 \(k\) 个属性，就令 \(q_{jk}=1\)。Q 一旦错置，理想反应分组会改变，失误率、猜测率和学生属性分类都会跟着偏移。

论文处理的问题是：

> 已知二元作答矩阵 \(\boldsymbol Y\) 和属性数 \(K\)，怎样同时估计 Q、题目参数、学生属性模式与潜在类比例，并保证估计过程中访问的 Q 均满足可识别条件？

这是**探索性 DINA**问题。专家 Q 可以在解释阶段参与比较，算法启动时不需要它。

## 四项实质贡献

### 贡献一：Q 进入完整贝叶斯模型

论文为 Q 指定

\[
p(Q)\propto I(Q\in\mathcal Q),
\]

把 Q 与

\[
\boldsymbol s,\quad
\boldsymbol g,\quad
\boldsymbol\alpha,\quad
\boldsymbol\pi
\]

一起采样。\(\mathcal Q\) 是满足论文三条限制的有限集合。

### 贡献二：构造受限的 Q 提议

论文研究三个提议分布：

- 独立提议；
- 依赖提议 DS1；
- 可调块大小的依赖提议 DS2。

DS2 每次选择一列中的 \(B\) 个位置，在更新前锁定维持单位行、列覆盖和非零行所必需的元素。

### 贡献三：证明提议链可用于正确的 MCMC

当 \(J-2K\ge2\) 时，Theorem 1 证明 DS2 在 \(B=1\) 下可以在有限步内从任意 \(Q\in\mathcal Q\) 到达任意其他状态。Theorem 2 证明 DS2 的转移提议对称，因此 MH 接受概率只需后验比。

### 贡献四：提出受限 Gibbs

论文观察到 \(B=1\) 时可以逐元素直接按完整条件分布更新 \(q_{jk}\)。若翻转会破坏可识别性，就保持原值；若 0 和 1 都合法，就按二者的条件似然归一化抽样。

## 原文证据

| 证据 | 内容 |
| --- | --- |
| 理论 | DS2 不可约性；DS2 对称性 |
| 模拟 | \(N=500,1000,2000,4000\)，\(K=3,4\)，\(\rho=0,.05,.15,.25\)，每条件 100 次 |
| 算法比较 | 受限 MH、受限 Gibbs、Chung（2014）无约束 Gibbs |
| 实证 | 536 名学生、20 道分数减法题；分别拟合 \(K=3,4\) |
| 代码 | 随文 C++/R；后续 `edina` R 包 |

## 证据边界

论文的理论证明针对提议链的不可约性与对称性，并引用 Chen et al.（2015）的 DINA Q 可识别条件。它没有证明：

- 任意有限长度链都已充分混合；
- 后验众数在小样本必然恢复真 Q；
- 属性数 \(K\) 可由该论文算法自动识别；
- 约束条件对 DINA Q 可识别是必要条件；
- 算法可直接扩展到任意一般 CDM；
- \(K\) 很大时计算仍然可行。

论文也明确把 \(N,J,K\) 增长下的计算复杂度、Q 后验汇总方式和 DINA 之外的扩展留给后续研究。

## 对当前 Q 学习主线的意义

前两篇 Liu、Xu 与 Ying 的方法把 Q 学习写成矩匹配和离散优化；本文改用后验采样搜索可识别 Q 空间。关键变化体现在搜索机制和不确定性表达：

\[
\text{单个最优化解}
\quad\longrightarrow\quad
\text{Q 的后验样本}.
\]

后验样本允许计算逐元素包含概率、整张矩阵众数和题目参数的不确定性。论文实际报告的 Q 点估计仍是整张矩阵的后验众数。
