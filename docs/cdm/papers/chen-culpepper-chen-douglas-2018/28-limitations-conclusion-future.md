# 局限、结论与未来工作

## 论文结论

本文把 DINA Q 的探索性估计写成受限贝叶斯问题：

\[
p(Q\mid-)
\propto
p(\boldsymbol Y\mid Q,-)I(Q\in\mathcal Q).
\]

主要成果包括：

- DS2 在合法 Q 空间中的不可约性与对称性；
- 可调块大小的受限 MH；
- 逐元素受限 Gibbs；
- 模拟中较高的 Q 和题目参数恢复精度；
- 分数减法数据上的低维探索性 Q。

## 论文确认的局限

### 计算扩展

状态空间仍然巨大，且学生属性更新含 \(2^K\) 个类别。作者把复杂度随

\[
N,\quad J,\quad K
\]

增长的规律列为开放问题，特别强调 \(K\)。

### Q 后验的汇总

整张矩阵众数在大空间中可能需要很长链才能稳定。逐元素众数值得研究，但还需要考虑结构约束和列对齐。

### 模型范围

正文聚焦 DINA。作者指出 DINA/DINO 对偶性允许直接转换，并建议未来为更一般 CDM 寻找相应可识别限制。

### 专家知识的整合

作者支持把统计 Q 与专家 Q 比较，寻求拟合与可解释性的折中。若部分题目的 Q 已知，可以固定这些行并只校准其余题目，尤其适合向题库加入新题。

## 本站补充的局限

### 强识别条件可能错设支持集

真 Q 若不在 \(\mathcal Q\)，受限后验永远无法恢复它。后续更弱条件与部分已知 Q 方法值得结合。

### 属性数由外部给定

原文分别拟合 \(K=3,4\)，没有在论文算法中选择 \(K\)。当前软件的多 \(K\) 比较属于扩展，仍需验证准则、链长和解释稳定性。

### 模拟复现材料不完整

随文材料缺少真 \(s,g\)、完整模拟脚本和随机种子，Table 1 无法逐数据集完全重跑。

### 固定链长与后验集中

CGibbs 在若干大样本条件下降低恢复率，提示 MCMC 误差需要与统计误差分开。后续实验应按 ESS 或模式稳定性决定链长。

### 当前软件的 Q 摘要

逐元素 0.5 阈值可能产生不可识别 Q。软件应保留整张矩阵模式频数或增加受限投影。

## 建议的后续研究

### 1. 受限后验摘要

求解

\[
\widehat Q
=
\arg\min_{Q\in\mathcal Q}
\sum_{j,k}
w_{jk}|q_{jk}-\overline q_{jk}|,
\]

把逐元素后验信息投影到合法空间。

### 2. 多尺度转移核

混合：

- 单元素受限 Gibbs；
- DS2 块移动；
- 列交换；
- 整行 q-vector 更新；
- tempering 或并行链。

这有助于跨越相隔较远的 Q 模式。

### 3. 可扩展后验近似

可研究随机梯度、变分推断、连续松弛和组合优化。后续 Oka 与 Okada（2023）正沿这条路线发展。

### 4. 属性数与 Q 联合推断

对 \(K\) 使用模型比较、可逆跳跃、稀疏潜在类或非参数先验，同时处理列标签和可识别设计。

### 5. 专家—数据协同先验

对专家确认的元素赋较强先验，对争议元素保留较大不确定性：

\[
q_{jk}\sim\operatorname{Bernoulli}(\omega_{jk}),
\]

再把联合先验截断到可识别空间。这样可以量化专家结构被数据修订的程度。

### 6. 与 CAT 的接口

本文估计的是题目—属性结构，可为认知诊断 CAT 提供校准后的题库。它没有研究实时选题策略。若用于 CAT，还需要另建：

- 学生当前属性后验更新；
- 下一题效用；
- 内容与曝光约束；
- 每次作答后的在线重规划。

## 最终评价

本文的关键价值在于把可识别性从事后检查推进到采样状态空间。受限 Gibbs 的模拟优势说明结构理论可以直接改善计算估计；强条件、计算扩展和后验摘要则构成后续工作的主要空间。
