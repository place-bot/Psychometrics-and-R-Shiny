# 中文分词与 \(n\)-gram 特征

## 1. 分词

原始题干是中文字符串。论文使用 `jieba` 把字符串切成词：

```text
小明有十二本书
        ↓
小明 / 有 / 十二 / 本 / 书
```

分词结果决定后续特征边界。同一句文本在不同词典和 `jieba` 版本下可能产生不同切分。

## 2. unigram

设分词结果为

\[
(w_1,w_2,\ldots,w_L).
\]

unigram 集合为

\[
\{w_1,w_2,\ldots,w_L\}.
\]

它可以抓住：

- 数字与运算术语；
- “和”“差”“整数”等直接提示；
- 人物、图形和情境词；
- 题干长度所带来的间接信号。

## 3. bigram

bigram 为相邻两词：

\[
(w_1,w_2),(w_2,w_3),\ldots,(w_{L-1},w_L).
\]

它能区分同一词在不同搭配中的作用，例如：

```text
求 和
一 共
根据 图
说法 正确
```

## 4. trigram

trigram 为连续三词：

\[
(w_1,w_2,w_3),\ldots,(w_{L-2},w_{L-1},w_L).
\]

它保留更多局部语序，也更容易稀疏。

## 5. 三种实验表征

论文依次比较：

\[
(1,1),\quad(1,2),\quad(1,3)
\]

三个 \(n\)-gram 范围：

| 名称 | 包含特征 |
| --- | --- |
| unigram | 只含一词 |
| unigram+bigram | 一词与相邻两词 |
| unigram+bigram+trigram | 一词、相邻两词与相邻三词 |

## 6. 特征稀疏性

unigram 共生成 2,943 个特征，其中超过 80% 在少于 5 道题中出现。

加入 bigram/trigram 后，论文没有报告词表总数，只说明超过 90% 的特征属于同样的低频特征。

若把“少于 5 次”记为 rare，则 unigram 至少有

\[
0.8\times2943\approx2355
\]

个低频词。

## 7. 稀疏为何影响 Gaussian NB

大量低频特征会产生：

- 许多几乎全为 0 的维度；
- 类内均值和方差估计不稳定；
- 条件独立似然中大量弱特征累乘；
- 训练样本有限时噪声累积。

这解释了 NB 在“全部 unigram”下 accuracy 只有 21.3%，而信息增益筛选后升到 84.0%。

## 8. 复现需要固定的细节

至少应记录：

- `jieba` 版本；
- 自定义词典；
- 停用词表；
- 数字是否归一化；
- 标点、单位和公式怎样处理；
- 最小文档频率；
- 相同题型模板是否分组划分。

原文没有给出这些设置。
