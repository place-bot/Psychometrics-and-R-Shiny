# Experiment：Table 1 的 unigram 结果

## 1. 特征规模

unigram 生成

\[
p=2943
\]

个特征，超过 80% 在少于 5 道题中出现。

## 2. 完整结果

| 模型 | IG top-\(k\) accuracy | IG top-\(k\) F1 | 全特征 accuracy | 全特征 F1 |
| --- | ---: | ---: | ---: | ---: |
| LR | 74.1% | 73.5% | 72.5% | 69.5% |
| SVM | 74.3% | 72.8% | 71.1% | 68.1% |
| NB | **84.0%** | **84.7%** | 21.3% | 22.4% |

## 3. 特征选择增益

| 模型 | accuracy 增益 | F1 增益 |
| --- | ---: | ---: |
| LR | +1.6 pp | +4.0 pp |
| SVM | +3.2 pp | +4.7 pp |
| NB | **+62.7 pp** | **+62.3 pp** |

这里 `pp` 表示百分点。

## 4. 最醒目的现象

Gaussian NB 对高维噪声极度敏感：

\[
21.3\%
\xrightarrow{\text{IG}}
84.0\%.
\]

LR 和 SVM 有正向提升，幅度温和。

## 5. 为什么 NB 的全特征结果会低于随机直觉

二分类随机猜测常让人想到 50%，但模型可以系统性偏向错误类别。Gaussian NB 在稀疏 TF--IDF 上使用 2,943 个正态条件密度，每个低频维度都可能贡献不稳定的 log likelihood。多个微小偏差累积后，决策可以大面积翻转。

论文没有给出混淆矩阵，所以无法确定 21.3% 的错误方向。

## 6. 与多数类基线比较

O 类占

\[
82.7\%.
\]

因此：

- LR 74.1% 低于多数类 accuracy；
- SVM 74.3% 低于多数类 accuracy；
- NB 84.0% 高出约 1.3 个百分点。

单看 accuracy，unigram 下只有筛选后的 NB 超过 all-O。

## 7. F1 的补充信息

NB 的 F1 84.7% 高于 accuracy 84.0%，说明它可能识别出一部分少数类 M。精确判断仍需每类 precision/recall。

## 8. 论文结论

作者据此认为：

1. 信息增益对三类模型均有帮助；
2. 全部稀疏特征严重损害 NB；
3. 有限训练数据下 NB 优于 LR 与 SVM。

前两点由表格直接支持。第三点只在该数据划分和所用参数下成立。
