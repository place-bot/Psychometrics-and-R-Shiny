# CDM、Q 矩阵与文本分类的接口

## 1. Q 矩阵的常规定义

设有 \(J\) 道题与 \(K\) 个属性。二元 \(Q\) 矩阵为

\[
Q=(q_{jk})\in\{0,1\}^{J\times K},
\]

其中

\[
q_{jk}=1
\]

表示第 \(j\) 道题需要属性 \(k\)。

一般情况下，一行可以包含多个 1：

\[
\boldsymbol q_j=(1,0,1,0)
\]

表示题 \(j\) 同时需要属性 1 与属性 3。

## 2. Q 在 CDM 中的角色

以 DINA 为例，学生 \(i\) 的掌握向量为

\[
\boldsymbol\alpha_i=(\alpha_{i1},\ldots,\alpha_{iK}).
\]

题 \(j\) 的理想作答指标是

\[
\eta_{ij}
=
\prod_{k=1}^{K}
\alpha_{ik}^{q_{jk}}.
\]

\(\boldsymbol q_j\) 改变时，\(\eta_{ij}\) 的含义也改变，进而影响失误、猜测参数和学生属性分类。

## 3. 论文使用的特殊 Q

论文请专家为每道题指定“最突出的一个认知属性”。于是每一行满足

\[
\sum_{k=1}^{9}q_{jk}=1.
\]

这样的 \(Q\) 是 one-hot 矩阵。其每一行和多类别标签完全等价：

\[
\boldsymbol q_j=\boldsymbol e_{y_j},
\]

其中 \(y_j\in\{1,\ldots,9\}\)。

## 4. one-hot 情形为何能转成文本分类

记题干为 \(d_j\)，分类器为 \(f_\theta\)。多类别预测可以写为

\[
\widehat y_j=f_\theta(d_j),
\qquad
\widehat{\boldsymbol q}_j=\boldsymbol e_{\widehat y_j}.
\]

若一行允许多个 1，则需要输出 \(K\) 个二元判断：

\[
\widehat q_{jk}
=
\mathbb I\left\{
p_\theta(q_{jk}=1\mid d_j)>\tau_k
\right\}.
\]

这已经是 multi-label 分类，损失函数、阈值、评测与数据要求都会变化。

## 5. 与数据驱动 Q 估计的区别

两类方法使用不同证据：

| 路线 | 输入 | 学习信号 | 典型输出 |
| --- | --- | --- | --- |
| 文本语义标注 | 题干与专家标签 | 已标注 Q 行 | 新题 Q 行初稿 |
| CDM 统计校准 | 学生题目反应 | 反应似然或拟合指标 | 对现有 Q 的修改 |

文本模型可以处理没有学生反应的新题。反应数据方法可以发现题干语义与实际解题过程之间的偏差。实践中更合理的组合是：

\[
\text{文本先验}
\longrightarrow
\text{专家复核}
\longrightarrow
\text{反应数据校准}.
\]

## 6. 本文和前六篇 Q 矩阵论文的关系

前面的专题研究：

- 如何用反应数据验证或修正 Q；
- 在什么条件下 Q 与模型参数可识别；
- Bayesian 或频率学派算法怎样估计 Q。
