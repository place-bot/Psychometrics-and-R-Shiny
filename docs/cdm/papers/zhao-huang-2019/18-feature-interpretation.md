# 关键词结果与教育语义解释

## 1. unigram 的高频入选词

论文列举：

- “a bunch of”；
- “figure”；
- “integers”；
- “sum”。

原始题目为中文，论文以英文说明关键词。作者指出翻译困难，因此没有列出 bigram/trigram 的完整关键词表。

## 2. 作者的解释

“a bunch of” 与 “figure” 更常出现在描述较长、需要理解情境的 Mathematical thinking 题。

“integers” 与 “sum” 更常出现在直接执行加减运算的 Operations of integers 题。

可以写成：

\[
\text{长情境/图形提示}
\Rightarrow M,
\]

\[
\text{直接运算术语}
\Rightarrow O.
\]

## 3. 模型可能学到两类信号

### 3.1 目标构念信号

词语确实指向所需认知活动，例如整数、求和、关系和图形。

### 3.2 题型或写作风格信号

长题更可能被专家归为 M，短题更可能被归为 O。分类器可能主要识别：

- 文本长度；
- 模板句式；
- 出题人的用词；
- 题型来源。

这类信号能提高同题库随机划分分数，跨题库时未必稳定。

## 4. 关键词解释不能自动建立构念效度

高互信息说明：

\[
I(X_r;Y)>0.
\]

它没有说明该词与属性之间存在因果关系，也没有证明学生解题时真正使用相应技能。

## 5. 模板泄漏

若同一模板只替换数字：

```text
小明有 12 本书，又买 5 本，一共有多少本？
小红有 18 支笔，又买 7 支，一共有多少支？
```

随机按题划分会把近重复模板同时放入训练和测试。模型可能记住 `又买/一共有`，测试分数因此偏高。

更严格的方法是按模板或题族分组划分。

## 6. 应怎样检查特征有效性

建议同时做：

1. 列出每类 top 正负特征；
2. 报告词频与互信息；
3. 由专家标记“构念相关/模板相关/潜在泄漏”；
4. 删除明显标签词后重训；
5. 控制题干长度；
6. 在新来源题库上评估。

## 7. 对今天的启发

现代语言模型可以编码更长语义和上下文。关键词分析仍有价值，因为它提供了一个低成本审计层：

```text
语言模型预测
      │
      ├── 属性概率
      └── 可解释词组/证据片段
```

专家可据此判断模型是否依赖合理证据。
