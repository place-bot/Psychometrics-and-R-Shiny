# 原始数据：1,069 道题与九个属性

## 1. 数据来源与标注

论文使用 1,069 道三年级数学题。学科专家小组为每道题指定一个最突出的认知属性，得到

\[
Q\in\{0,1\}^{1069\times9}.
\]

每行恰有一个 1。

论文没有提供：

- 题目来源、年份与地区；
- 选择题、填空题等题型比例；
- 专家人数和专业背景；
- 标注手册；
- 独立标注与讨论流程；
- 专家一致性；
- 题干和 Q 数据文件。

## 2. 九类题量

Figure 1 给出以下精确计数：

| 属性 | 题量 | 占 1,069 的比例 |
| --- | ---: | ---: |
| Using calculators | 3 | 0.28% |
| Statistics | 10 | 0.94% |
| Large integers | 25 | 2.34% |
| Logic | 32 | 2.99% |
| Operations of fractions | 46 | 4.30% |

| Measurement | 83 | 7.76% |
| Mathematical thinking | 139 | 13.00% |
| Operations of integers | 666 | 62.30% |
| **合计** | **1,069** | **100%** |

本站程序核对：

\[
3+10+25+32+46+65+83+139+666=1069.
\]

## 3. 分布高度不平衡

最大的 `Operations of integers` 一类有 666 题，最小的 `Using calculators` 只有 3 题：

\[
\frac{666}{3}=222.
\]

若直接训练九分类模型，最小类几乎没有可用于训练、调参和测试的独立样本。

## 4. 论文为什么裁剪数据

作者认为低频属性容易造成过拟合，于是保留两类：

- `O`：Operations of integers，666 题；
- `M`：Mathematical thinking，139 题。

两类合计

\[
666+139=805.
\]

其余 264 道题完全退出实验：

\[
1069-805=264.
\]

## 5. 数据层面的含义

裁剪解决了极小类别无法训练的问题，也改变了研究任务：

```text
原始数据目标：九个认知属性
                  │
             删除七类题
                  ▼
实际实验目标：O 与 M 的二分类
```

因此，实验结果可以评价 O/M 辨别，无法直接评价完整九列 Q 的恢复。

## 6. 题库代表性的未知项

三年级数学题的语言结构、课程术语和题型可能具有强烈本地特征。没有公开数据时，下列问题无法核验：

- 同一道题是否含图形；
- 图形信息是否被转写进文本；
- 题干中是否直接出现属性名称；
- 同一题型模板是否同时进入训练集和测试集；
- 近重复题是否造成文本泄漏。

这些信息会直接影响 85.2% 的外部效度。
