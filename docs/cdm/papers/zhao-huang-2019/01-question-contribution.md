# 研究问题、贡献与证据边界

## 1. 研究问题

认知诊断应用通常先完成两件事：

1. 规定待诊断的属性；
2. 为每道题指定其所需属性，形成 \(Q\) 矩阵。

第二步依赖测量专家、学科专家和教师协作。大题库会带来明显的人力成本。Zhao 与 Huang 提出：

> 已经由专家标注的一批题能否作为训练集，让文本分类器学习“题干 \(\rightarrow\) 属性”的映射，再自动标注新题？

## 2. 三项主要贡献

### 2.1 把 Q 行预测写成文本监督分类

每道题的题干视为一篇短文，属性视为类别。已有专家 \(Q\) 标签成为监督信号。

### 2.2 给出三阶段管线

论文把实现拆为：

\[
\text{特征抽取与选择}
\longrightarrow
\text{题目向量化}
\longrightarrow
\text{属性分类}.
\]

具体组件为：

- `jieba` 中文分词；
- unigram、bigram、trigram；
- 信息增益排序与 top-\(k\) 筛选；
- TF--IDF；
- Logistic Regression、C-SVM、Gaussian Naive Bayes。

### 2.3 用真实小学数学题比较三类分类器

实验报告三种 \(n\)-gram 组合、三种算法、有无特征选择的完整 \(3\times3\times2\) 对照。最佳组合是：

\[
\text{unigram+bigram+trigram}
+\text{IG}
+\text{Gaussian NB}.
\]

## 3. 论文证据覆盖到哪里

实验直接支持的命题为：

> 在该三年级数学题库的两个高频、互斥属性之间，题干词汇能够提供可学习的分类信号。

实验尚未直接检验：

- 九属性联合分类；
- 一题对应多个属性的 multi-label Q 行；
- 新知识点或新课程中的跨域迁移；
- 自动标签进入 CDM 后的参数估计与学生分类质量；
- 自动标签进入 CAT 后的选题效率；
- 专家复核成本究竟减少多少。

## 4. 创新应怎样理解

论文发表于传统文本分类技术已经成熟的时期。算法组件本身都很常见，贡献集中在**任务迁移**：

\[
\text{短文本分类技术}
\quad\Rightarrow\quad
\text{Q 矩阵语义标注}.
\]

这一步打开了“题目内容可直接进入 Q 构建”的路线。今天使用预训练语言模型或多模态模型自动生成 Q 行，可以看作沿着这条路线继续发展。

## 5. 最重要的阅读提醒

论文在标题和结论中使用 automated Q-matrix identification。实验中的输出实际是每道题在 `O` 与 `M` 之间的单一类别。更准确的任务名称是：

\[
\text{binary cognitive-attribute classification from item text}.
\]

因此，阅读时要把“原始目标”和“实际验证任务”分开。
