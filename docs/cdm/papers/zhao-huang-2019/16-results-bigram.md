# Experiment：Table 2 的 unigram+bigram 结果

## 1. 特征变化

加入相邻两词后，候选词表显著扩大。论文没有报告确切维度，只说明超过 90% 的特征在少于 5 道题中出现。

## 2. 完整结果

| 模型 | IG top-\(k\) accuracy | IG top-\(k\) F1 | 全特征 accuracy | 全特征 F1 |
| --- | ---: | ---: | ---: | ---: |
| LR | 74.6% | 72.5% | 72.7% | 69.7% |
| SVM | 74.9% | 72.0% | 71.1% | 68.1% |
| NB | **84.6%** | **85.2%** | 69.1% | 67.3% |

## 3. 特征选择增益

| 模型 | accuracy 增益 | F1 增益 |
| --- | ---: | ---: |
| LR | +1.9 pp | +2.8 pp |
| SVM | +3.8 pp | +3.9 pp |
| NB | **+15.5 pp** | **+17.9 pp** |

## 4. 与 unigram 比较

### 有特征选择

| 模型 | unigram accuracy | +bigram accuracy | 变化 |
| --- | ---: | ---: | ---: |
| LR | 74.1% | 74.6% | +0.5 pp |
| SVM | 74.3% | 74.9% | +0.6 pp |
| NB | 84.0% | 84.6% | +0.6 pp |

三类模型均提高 0.5--0.6 个百分点。

### 无特征选择

- LR：72.5% \(\rightarrow\) 72.7%；
- SVM：71.1% \(\rightarrow\) 71.1%；
- NB：21.3% \(\rightarrow\) 69.1%。

NB 的大幅回升说明特征空间改变了 Gaussian 密度估计的行为，但 69.1% 仍低于多数类基线。

## 5. bigram 带来的信息

相邻词组可以表达：

- 运算动作；
- 数量关系；
- 图表阅读提示；
- 推理句式；
- 题型模板。

这些局部短语对 O/M 有额外区分力。

## 6. 结果差异的尺度

若测试集约 81 题，0.6 个百分点小于一道题对应的

\[
\frac{1}{81}\times100\%=1.23\%.
\]

由于表格可能来自同一个测试集但不同错误组合，0.6 pp 仍可能由四舍五入产生。论文没有 paired test，无法确认 bigram 的小幅增益具有稳定性。

## 7. 结论

Table 2 支持：

- bigram 可能带来少量增益；
- 信息增益继续有效；
- NB 仍是三个模型中最优。

它没有提供跨随机划分的稳健性证据。
