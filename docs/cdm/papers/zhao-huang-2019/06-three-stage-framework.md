# 三阶段框架总览

## 1. 论文 Figure 2 的流程

```text
题干文本
   │
   ▼
中文分词与 1/2/3-gram 候选
   │
   ▼
信息增益排序，保留 top-k
   │
   ▼
TF--IDF 题目向量
   │
   ├──────────┬──────────┐
   ▼          ▼          ▼
 C-SVM       LR      Gaussian NB
   └──────────┴──────────┘
              │
              ▼
        O/M 属性标签
              │
              ▼
        两列 one-hot Q 行
```

## 2. 第一阶段：特征选择

目标是从大词表中找出对类别最有区分力的词或词组。

候选特征来自：

- unigram；
- unigram+bigram；
- unigram+bigram+trigram。

每个特征根据与类别的互信息排序，保留 top-\(k\)。

## 3. 第二阶段：题目表征

每道题被转成实值向量：

\[
\boldsymbol x_j
=
(x_{j1},\ldots,x_{jk}),
\]

其中 \(x_{jr}\) 为第 \(r\) 个保留特征的 TF--IDF 权重。

## 4. 第三阶段：分类

三种算法学习

\[
\boldsymbol x_j\mapsto y_j.
\]

论文比较它们在相同特征方案下的 accuracy 与 weighted F1。

## 5. 三阶段之间的依赖

三个阶段应按训练数据拟合：

```text
训练集：拟合分词后的词表、IDF、IG 排序、模型参数
验证集：选择 k
测试集：只做最终评估
```

若先在全部 805 道题上计算词表、IDF 或信息增益，再划分测试集，测试信息会进入模型选择过程。论文没有明确报告拟合顺序，因此复现时需要主动采用严格分离。

## 6. 框架的优点

- 组件简单，计算成本低；
- 关键词可被专家阅读；
- 少量标注数据即可训练；
- 新题无需等待学生作答；
- 能与人工复核流程组合。

## 7. 框架的边界

- 只使用题干文本；
- 不处理图片、表格和公式结构；
- 不使用选项与解析；
- 不使用学生反应；
- 不表达属性层级；
- 实验输出单一类别；
- 概率校准和不确定性分流没有展开。

这些边界决定了它更适合做入库初筛，而非直接成为最终 Q 的唯一来源。
