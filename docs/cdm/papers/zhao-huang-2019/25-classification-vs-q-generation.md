# 文本分类与完整 Q 矩阵生成的差距

## 1. 论文实际输出

实验类别为：

\[
y_j\in\{O,M\}.
\]

输出 Q 行为：

\[
(1,0)
\quad\text{或}\quad
(0,1).
\]

这等价于二分类。

## 2. 完整 Q 行的空间

若有 \(K\) 个属性，一般非零 Q 行空间为

\[
\mathcal Q
=
\{0,1\}^K\setminus\{\boldsymbol0\}.
\]

规模为

\[
|\mathcal Q|=2^K-1.
\]

当 \(K=9\)：

\[
2^9-1=511.
\]

one-hot 限制只保留其中 9 种。

## 3. 三种不同任务

### 3.1 单标签多分类

\[
\sum_k q_{jk}=1.
\]

模型在 \(K\) 类中选一个。

### 3.2 多标签分类

\[
\sum_k q_{jk}\ge1.
\]

每列独立或联合输出二元标签。

### 3.3 结构化 Q 生成

除预测各列，还加入：

- 属性层级；
- 允许/禁止组合；
- 题型规则；
- Q 可识别性条件；
- 题库覆盖约束；
- CDM 拟合反馈。

## 4. 为什么“分类准确率”不等于“Q 可用”

即使单元格准确率很高，少数关键错误仍可能破坏：

- 某属性的完整性；
- 每个属性的测量次数；
- 属性列的区分；
- 学生掌握模式识别；
- CAT 的内容覆盖。

因此需要矩阵级评估。

## 5. 推荐的评估层次

```text
第 1 层：文本标签
  precision / recall / macro-F1 / exact match
          │
第 2 层：Q 结构
  完整性、重复性、列区分、属性覆盖
          │
第 3 层：CDM 拟合
  log-likelihood / AIC / BIC / item fit
          │
第 4 层：诊断结果
  属性分类一致率、可靠性、校准
          │
第 5 层：CAT
  测试长度、诊断精度、内容覆盖、曝光
```

## 6. 文本模型的合理输出

比硬标签更有用的是：

\[
p_\psi(\boldsymbol q_j\mid d_j)
\]

或每列概率

\[
p_\psi(q_{jk}=1\mid d_j).
\]

下游模块可以保留不确定性，决定：

- 自动接受；
- 专家快速确认；
- 完整讨论；
- 优先收集反应数据。

## 7. 这篇论文的历史价值

它验证了题干词汇确实能预测部分认知属性，为后续深度学习、预训练语言模型和多模态 Q 生成提供了早期任务范式。

## 8. 标题应怎样精确解读

文中的 automated Q-matrix identification 可以理解为：

> 利用已标注题目训练文本分类器，对新题产生 one-hot Q 行候选。

它没有估计未知属性数，也没有从学生反应中识别统计意义上的 Q。
