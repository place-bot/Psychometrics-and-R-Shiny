# 信息增益特征选择

## 1. 定义

设随机变量 \(X\) 表示一个文本特征，\(Y\) 表示认知属性。信息增益写为

\[
IG(X;Y)
=
H(Y)-H(Y\mid X).
\]

它也等于互信息：

\[
I(X;Y)
=
\sum_{x,y}
p(x,y)
\log
\frac{p(x,y)}{p(x)p(y)}.
\]

论文公式写成

\[
IG(X;Y)=H(X)-H(X\mid Y),
\]

两种写法因互信息对称性而相等。

## 2. 熵

对离散类别 \(Y\)：

\[
H(Y)
=
-\sum_y p(y)\log p(y).
\]

若观察特征 \(X\) 后类别更确定，则

\[
H(Y\mid X)<H(Y),
\]

所以信息增益为正。

## 3. 二元出现变量

文本特征选择中常把词是否出现写为

\[
X_r=
\mathbb I\{\text{特征 }r\text{ 出现在该题}\}.
\]

对二分类 \(Y\in\{O,M\}\)，每个特征形成一个 \(2\times2\) 频数表：

| | \(Y=O\) | \(Y=M\) |
| --- | ---: | ---: |
| \(X_r=1\) | \(n_{1O}\) | \(n_{1M}\) |
| \(X_r=0\) | \(n_{0O}\) | \(n_{0M}\) |

由四个频数即可计算 \(I(X_r;Y)\)。

## 4. 一个直观例子

若“整数”频繁出现在 O 类，且很少出现在 M 类，则：

\[
p(Y=O\mid X_{\text{整数}}=1)
\gg
p(Y=O).
\]

观察到该词显著减少类别不确定性，信息增益较大。

## 5. top-\(k\) 选择

对 \(p\) 个候选特征计算

\[
IG_1,\ldots,IG_p,
\]

并排序：

\[
IG_{(1)}\ge IG_{(2)}\ge\cdots\ge IG_{(p)}.
\]

给定 \(k\)，选择

\[
\mathcal S_k
=
\{(1),\ldots,(k)\}.
\]

论文令

\[
k=5,10,\ldots,300.
\]

共有 60 个候选值。

## 6. filter 方法的优点

信息增益在模型训练前计算：

- 速度快；
- 与分类器解耦；
- 同一排序可供三个算法使用；
- 选出的词可由专家解释。

## 7. 原文中的实现歧义

论文文字说“把特征在题目中的频率视为一个变量”，没有说明计算 IG 时采用：

- 二元出现；
- 原始词频；
- 离散化后的词频；
- TF--IDF 连续值。

这些定义会给出不同排序。

本站独立重构采用更常见且与离散互信息定义一致的二元出现变量：

\[
X_r=\mathbb I(\operatorname{TF}_{jr}>0).
\]

## 8. 防止信息泄漏

IG 使用标签，因此必须只在训练集上估计：

\[
\widehat{IG}_r
=
\widehat I_{\mathcal T}(X_r;Y).
\]

若包含测试集标签，选择出的词已经利用了测试信息，最终分数会偏乐观。
