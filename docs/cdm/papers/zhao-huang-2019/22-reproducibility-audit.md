# 复现性审计：论文没有报告的实现选择

## 1. 公开材料

可获得：

- ACM 5 页正式 PDF；
- 论文中的 Figure 1、Figure 2 与 Tables 1--3；
- 算法公式与总体流程。

未获得：

- 1,069 道题文本；
- 805 道实验题文本；
- Q 标签；
- 训练/验证/测试索引；
- 源代码；
- 补充材料；
- 逐题预测。

论文和 ACM 页面均没有给出 code/data availability。

## 2. 数据处理缺口

- `jieba` 版本；
- 用户词典；
- 停用词；
- 标点与数字处理；
- 图形题怎样转成文本；
- 公式、单位和特殊字符处理；
- 近重复题处理。

## 3. 特征工程缺口

- IG 的特征变量是二元出现、词频还是 TF--IDF；
- IG 是否只在训练集计算；
- 词表和 IDF 的拟合范围；
- TF--IDF 公式；
- 归一化；
- bigram/trigram 词表规模；
- 各配置最终选择的 \(k\)。

## 4. 模型缺口

- `SVC` 或 `LinearSVC`；
- SVM kernel；
- LR solver；
- Gaussian NB 的 `var_smoothing`；
- 类别权重；
- sklearn 版本；
- 收敛状态。

## 5. 实验缺口

- 随机种子；
- 三个子集的精确题数；
- 每类在各子集的计数；
- 选择 \(k\) 时使用 accuracy 还是 F1；
- 是否对每个模型分别选 \(k\)；
- 同一测试集是否用于所有表；
- 是否重复随机划分。

## 6. 结果缺口

- 混淆矩阵；
- 每类 precision/recall/F1；
- macro-F1；
- 置信区间；
- \(k\) 的验证曲线；
- 特征完整清单；
- 逐题错误分析。

## 7. 潜在信息泄漏点

若执行顺序为：

```text
全部 805 题上建词表和计算 IG
            ↓
再划分 train/validation/test
```

测试标签会参与特征选择。

严格顺序应为：

```text
先划分
   ↓
仅训练集拟合词表、IDF、IG 与模型
   ↓
验证集选 k
   ↓
测试集最终评估
```

原文无法确认作者采用哪一种顺序。
