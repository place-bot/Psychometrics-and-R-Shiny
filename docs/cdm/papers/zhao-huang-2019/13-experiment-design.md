# Experiment：数据划分、\(k\) 调参与算法选择

## 1. 划分比例

805 道题随机分为：

\[
80\%\text{ train},
\qquad
10\%\text{ validation},
\qquad
10\%\text{ test}.
\]

每一部分保持 O/M 比例。

按整数样本量，最自然的规模接近：

| 子集 | 规模 |
| --- | ---: |
| 训练 | 644 |
| 验证 | 80 |
| 测试 | 81 |

论文没有报告实际整数规模和随机种子。

## 2. 三种特征范围

\[
\mathcal G

(1,1),(1,2),(1,3)
\}.
\]

分别对应三张结果表。

## 3. 三种算法

\[
\mathcal A

## 4. \(k\) 的搜索

\[
\mathcal K
=
\{5,10,15,\ldots,300\}.
\]

\[
|\mathcal K|
=
\frac{300-5}{5}+1
=60.
\]

每个“特征范围×算法”组合都在训练集拟合，并在验证集上选择表现最好的 \(k\)。

特征选择分支至少包含

\[
3\times3\times60=540
\]

次候选拟合。

## 5. 全特征对照

每个特征范围和算法还训练一个 no feature selection 版本：

\[
3\times3=9
\]

个对照。

## 6. 最终测试

对每个组合固定验证集选出的 \(\widehat k\)，再在测试集报告：

- accuracy；
- weighted F1。

## 8. 没有控制的因素

论文没有系统调节：

- 分词方式；
- TF--IDF 定义；
- LR 正则强度；
- SVM 的 \(C\) 与 kernel；
- NB 变体；
- 类别权重；
- 随机划分；
- 题型模板分组。

## 9. 单次划分的风险

10% 测试集很小。更稳妥的设计可以使用：

- repeated stratified \(K\)-fold；
- nested cross-validation；
- 按题型模板 group split；
- 按年份、学校或题库 source split；
- bootstrap 置信区间。

论文没有重复划分，也没有显著性检验。
