# 局限、结论与未来工作

## 1. 作者报告的结论

三阶段文本分类管线可以利用题干自动预测认知属性。信息增益特征选择提高三类算法表现，Gaussian NB 在三阶 \(n\)-gram 组合下达到：

\[
85.2\%\text{ accuracy},
\qquad
85.6\%\text{ weighted F1}.
\]

作者据此认为文本分类有潜力降低大题库 Q 标注成本。

## 2. 作者明确提出的局限

### 2.1 专家标签也有误差

内容专家可能对同一道题需要哪些属性产生分歧，通常需要多轮讨论。机器学习只能逼近训练标签所提供的标准。

### 2.2 数据规模有限

实验只保留两个属性。作者计划在更大数据上扩展到多个认知属性。

### 2.3 方法较传统

作者提出未来使用深度神经网络，让模型自动抽取文本特征并提高精度。

## 3. 本站补充的局限

### 3.1 任务范围

实验是两个互斥属性的短文本二分类，和一般 multi-hot Q 行之间仍有距离。

### 3.2 类别不平衡

82.7% 的多数类 accuracy 使 85.2% 的绝对增益缩小到约 2.5 个百分点。

### 3.3 小测试集

测试集很可能只有 81 题，一题约等于 1.24 个百分点。

### 3.4 单次随机划分

没有 repeated split、交叉验证、误差区间或显著性检验。

### 3.5 复现信息

数据、代码、最终 \(k\)、随机种子、软件版本和大量预处理细节缺失。

### 3.6 指标公式

Equation (9) 按预测类别规模加权，与 sklearn weighted F1 不一致。

### 3.7 下游效度

论文没有把预测 Q 放入 CDM 或 CAT，因而没有检验学生诊断、拟合与自适应选题效果。

## 4. 更强的未来实验

### 数据

- 多年级、多学科、多来源题库；
- 题干、选项、图片、公式和解析；
- 多位专家独立标注；
- 公开去标识数据与划分索引。

### 模型

- multi-label encoder；
- 预训练中文语言模型；
- 多模态模型；
- 属性描述与题干联合编码；
- 层级和图结构约束；
- 文本先验与反应似然联合学习。

### 评测

- macro-F1、balanced accuracy、每类 recall；
- row exact match 与 Hamming loss；
- calibration；
- 专家时间节省；
- CDM item fit 与学生分类；
- CAT 测试长度、内容覆盖与曝光。

## 5. 面向人机协作的目标

自动化系统可以优化：

\[
\text{在给定人工复核预算下最小化 Q 错误}.
\]

例如按置信度分流：

| 模型状态 | 操作 |
| --- | --- |
| 高置信度、规则一致 | 快速确认 |
| 中置信度 | 单专家复核 |
| 低置信度或属性冲突 | 多专家讨论 |

这一目标比单纯最大化分类 accuracy 更贴近实际成本。

## 6. 总结

这篇 5 页会议论文的核心价值是建立一条早期路线：题干语义能够参与 Q 矩阵构建。它提供了真实数据上的初步可行性证据，也留下了多标签结构、复现性、统计不确定性与下游测量效度等关键问题。

对 CAT 研究而言，它适合成为题目内容理解模块。实时 adaptive 仍由“反应更新学生状态—重新选择下一题”的闭环保证。
