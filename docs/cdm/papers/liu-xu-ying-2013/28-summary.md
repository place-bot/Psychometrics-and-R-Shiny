# 总结与后续阅读

## 一条主线

论文把 Q 结构学习写成：

\[
\text{作答数据}
\longrightarrow
\boldsymbol\alpha
\longleftrightarrow
T_{c,g}(Q)\boldsymbol p+p_0\boldsymbol g_{\mathrm{joint}}
\longrightarrow
\widehat Q.
\]

真 Q 生成经验矩的总体极限。充分条件保证错误 Q 的列空间无法覆盖该极限，因此全局矩距离最小化估计量一致。

## 五个必须记住的结论

### 1. Q 只能恢复到列置换

\[
\widehat Q\sim Q
\]

是数据能够达到的结构分辨率。属性语义标签需要外部信息。

### 2. 满列秩与列空间分离承担不同任务

- 满列秩：给定 Q 后，\(\boldsymbol p\) 唯一；
- 列空间分离：不同 Q 无法生成相同真矩。

### 3. C4 提供区分人群

如果关键属性模式从未出现，不同 q-vector 的差异不会反映到作答中。

### 4. C5 提供结构冗余

每个属性至少出现两次，使“全部题”和“删除一道题”的能力行仍相同，进而用行比例锁定缩放参数并排除错误 Q。

### 5. 猜测可以通过中心化消去

矩阵 D 实现多元容斥：

\[
D\widetilde T_{c,g}(Q)
=(0,T_{c-g}(Q)).
\]

这把带猜测问题化回无猜测列空间问题。

## 三条定理对照

| 定理 | 参数设定 | Q 结论 | 属性分布结论 |
| --- | --- | --- | --- |
| 2.4 | 无噪声 | 一致到列置换 | 一致 |
| 3.1 | \(c,g\) 已知 | 一致到列置换 | 一致 |
| 4.2 | \(g\) 已知、\(c\) 未知 | 一致到列置换 | 另需一般 \(c\) 估计一致 |

## 原文证据边界

这是一篇纯理论论文。它有：

- 一个构造性手算例；
- 三条主定理；
- 六条关键命题与一个引理；
- 两条附录证明；
- 多个不可识别反例。

它没有：

- 模拟研究；
- 真实数据；
- 方法对比；
- 运行时间；
- 官方代码；
- 有限样本误差界。

## 与 2012 论文合读

[Liu、Xu 与 Ying（2012）](../liu-xu-ying-2012/index.md)提供逐行局部搜索和模拟结果；本文解释理想化全局估计量为何能识别 Q。合读时可按以下顺序：

1. 2012 的 \(T\)-matrix 与 Algorithm 1；
2. 本文的 C1--C5；
3. 本文的满秩与列空间分离；
4. 回看 2012 截断、初始 Q 与局部优化对理论条件的改变。

## 对现代 Q 学习的检查清单

阅读任何机器学习或生成式 Q 方法时，可以追问：

1. 输出 Q 在什么等价关系下可识别？
2. 属性模式分布是否包含足够的区分人群？
3. 项目参数能否替错误 Q 吸收差异？
4. 训练目标使用了哪些联合反应信息？
5. 全局统计目标与实际优化器之间有什么缺口？
6. 属性数量和语义标签从哪里来？
7. 预测性能与结构恢复是否分别评估？
