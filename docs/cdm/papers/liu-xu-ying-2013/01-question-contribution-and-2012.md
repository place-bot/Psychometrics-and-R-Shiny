# 问题、创新与 2012 论文的关系

## 研究问题

认知诊断模型通常把 Q 矩阵当成专家提供的已知设计。若第 \(i\) 道题需要第 \(j\) 个属性，则 \(Q_{ij}=1\)。Q 一旦错设，项目参数、属性分类和模型拟合都会受到影响。

本文追问一个更基础的问题：

> 只观察学生的二元作答，哪些条件能保证每道题所需的属性结构可以从数据中学出来？

这里的“学出来”有严格的统计含义。令样本量为 \(N\)，估计量为 \(\widehat Q\)。作者希望证明

\[
\Pr(\widehat Q\sim Q)\longrightarrow 1,
\qquad N\longrightarrow\infty,
\]

其中 \(\sim\) 表示两矩阵只差属性列的重新排列。

## 三个理论难点

原文在引言中明确列出三类困难。

### 1. Q 可能无法识别

多个 Q 可能生成完全相同的反应分布。即使数据无限多，也无法靠作答区分这些 Q。作者先定义数据能够达到的最细分辨率，再讨论估计。

### 2. Q 是离散参数

\(m\times k\) 的 Q 位于有限的二元矩阵空间。对连续参数常用的微分、Hessian 和局部展开无法直接处理 Q 的结构差异，证明需要组合论与线性代数。

### 3. 从 Q 到反应分布的映射高度非线性

潜在属性 \(\boldsymbol A\) 不可观测；Q 先通过合取规则产生理想反应，再与失误、猜测机制结合，最后对属性分布求和。观测分布对 Q 的依赖是离散且非线性的。

## 核心创新

### 创新一：把 Q 学习写成可观测矩匹配

对单题、题对和更高阶题组，计算“全部答对”的样本比例，堆叠成

\[
\boldsymbol\alpha.
\]

候选 Q 产生 \(T(Q)\)，属性模式比例为 \(\boldsymbol p\)。无噪声时有

\[
T(Q)\widehat{\boldsymbol p}=\boldsymbol\alpha.
\]

于是候选 Q 的拟合程度可写成

\[
S(Q')=
\inf_{\boldsymbol p}
\left\|T(Q')\boldsymbol p-\boldsymbol\alpha\right\|_2.
\]

### 创新二：明确可识别的等价类

属性名称本身不会进入反应概率。交换 Q 的两列，同时交换属性模式坐标，观测分布保持不变。论文由此把统计目标限定为列置换等价类 \([Q]\)。

### 创新三：用列空间分离证明一致性

真矩向量位于真 Q 的 \(T\)-matrix 列空间中。作者证明，在 C1--C5 下，任意 \(Q'\not\sim Q\) 的候选列空间都无法包含真矩向量。

\[
T_c(Q)\boldsymbol p^*
\notin
\mathcal C\!\left(T_{c'}(Q')\right).
\]

有限个候选 Q 之间因此存在统一的正距离。样本矩收敛后，错误等价类无法继续取得最小值。

### 创新四：把理论从理想模型推进到 DINA

文章依次处理：

1. 无失误、无猜测；
2. \(c_i=1-s_i\) 与 \(g_i\) 已知；
3. \(g_i\) 已知、\(c_i\) 未知。

第三层还构造了一个利用题目属性包含关系的快速矩估计量。

## 与 Liu、Xu 与 Ying（2012）的分工

两篇文章共享 \(T\)-matrix 和矩匹配思想，但承担的任务不同。

| 维度 | 2012：Data-Driven Learning | 2013：Theory of Self-Learning |
| --- | --- | --- |
| 主目标 | 给出可运行的 Q 修正算法 | 给出识别与一致性理论 |
| 搜索方式 | 从专家初始 Q 出发，逐行局部更新 | 定义对全部候选二元 Q 的全局最小化 |
| 参数处理 | 每轮用 DINA EM 估计 \(c,g,p\) | 分已知 \(c,g\) 与未知 \(c\) 建立理论 |
| \(T\)-matrix | 实用中可截断，只保留低阶题组 | 主定理要求饱和矩 |
| 证据 | 四组模拟研究 | 定理、命题、反例与证明 |
| 计算重点 | 怎样搜索得动 | 为什么真 Q 会与错误 Q 分开 |
| 初始 Q | 需要较好的 \(Q_0\) | 定义上无需 \(Q_0\)，但全空间搜索很昂贵 |

2013 论文没有证明 2012 的逐行爬山算法一定找到全局最小值。它证明的是理想化全局估计量的一致性。因此两篇合读时要分清：

- 统计目标的一致性；
- 实际优化器能否达到该目标；
- 有限样本下结果是否稳定。

三者属于不同层面的保证。

## 理论贡献的准确边界

论文建立了合取型 DINA 框架下的充分条件。它没有覆盖以下任务：

- 自动发现属性的语义名称；
- 自动选择属性数量 \(k\)；
- 给未知猜测参数建立完整一致性理论；
- 为大规模 Q 提供多项式时间的全局算法；
- 给有限样本恢复概率提供显式误差界。

这些边界也构成后续研究的直接入口。
