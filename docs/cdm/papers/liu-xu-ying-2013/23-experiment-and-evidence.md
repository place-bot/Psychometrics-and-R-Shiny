# Experiment：原文证据的完整盘点

## 先说明证据类型

这篇 *Bernoulli* 论文共 28 页，正文结构是：

1. Introduction；
2. Model specifications and basic results；
3. DINA model with known slipping and guessing parameters；
4. Extension to unknown slipping probabilities；
5. Discussion；
6. Proofs of the theorems；
7. Appendix: Technical proofs。

原文没有 Simulation、Experiment、Application 或 Real Data 章节，也没有实验表、结果图、数据集和数值比较。

因此本专题无法报告原文的：

- 样本量条件；
- 重复次数；
- 数据集名称；
- 恢复率表；
- 基线方法；
- 运行时间；
- 真实数据结论。

这些项目在论文中均未出现。

## 原文怎样提供证据

论文的证据链由四部分组成。

### 1. 构造性例子

Section 2.3 用三题两属性的加法—乘法 Q 展示：

\[
T(Q)\widehat{\boldsymbol p}
=
\boldsymbol\alpha.
\]

这个例子解释估计量怎样形成，但没有用随机数据评估性能。

### 2. 三条主定理

| 情形 | 结果 |
| --- | --- |
| 无失误、无猜测 | Theorem 2.4：Q 等价类与属性分布一致 |
| \(c,g\) 已知 | Theorem 3.1：Q 等价类与属性分布一致 |
| \(g\) 已知、\(c\) 未知 | Theorem 4.2：Q 等价类一致；\(p\) 一致另需 \(c\) 估计一致 |

### 3. 六个命题与一个引理

- Propositions 6.1--6.2：满列秩；
- Propositions 6.3--6.4：无猜测的列空间分离；
- Corollary 6.5：汇总候选 Q；
- Proposition 6.6：带猜测的增广列空间分离；
- Lemma 6.7：线性行变换保留列空间包含关系。

### 4. 反例与维数论证

原文用以下例子标出结论边界：

- 全部人均为全掌握模式时 Q 无法识别；
- 两个属性永远同步时相关列无法区分；
- \(Q=I_k\) 时，\((p,c)\) 的参数维数超过观测自由度；
- 未知 \(g_i\) 需要额外条件与分析。

## 原文结果应该怎样表述

可以准确地说：

> 在固定 \(m,k\)、C1--C5、DINA 及相应项目参数条件下，论文构造的全局矩距离最小化估计量对 Q 的列置换等价类一致。

还不能据此声称：

- 小样本恢复率很高；
- 低阶截断与饱和矩同样有效；
- 局部搜索能稳定找到全局解；
- 未知 \(c,g\) 均可可靠估计；
- 方法已在真实测验上验证；
- 计算可扩展到大规模 Q。

## 本站为什么补做数值核验

理论推导中的矩阵对象可以在小规模下直接计算。本站脚本检查：

1. 完整 Q 的饱和 \(T(Q)\) 满列秩；
2. D 变换把增广 \(T_{c,g}\) 化为 \((0,T_{c-g})\)；
3. 列置换产生相同总体矩；
4. 枚举的小例中只有真等价类取得零总体损失；
5. C4 失败时全部候选都能匹配全掌握总体；
6. 一个固定教学设定下恢复率随 \(N\) 增大。

这些核验帮助理解公式并排查实现错误。它们是本站新增内容，不能替代一般证明，也不能归入原文结果。

## 与 2012 论文的实验互补

如果需要观察有限样本表现，应转读同一作者的 2012 论文。那篇文章给出：

- 三个 Q 设计；

- 早停规则；
- 相关且不均衡属性；
- 部分已知 Q；
