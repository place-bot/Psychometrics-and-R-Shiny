# 反例、必要性与识别边界

## 反例一：所有人都掌握全部属性

设

\[
\Pr(\boldsymbol A=\boldsymbol1)=1.
\]

无噪声且每道题至少要求一个属性时，任何 Q 都给出

\[
\boldsymbol R=\boldsymbol1
\]

的概率 1。反应分布与 Q 完全无关。

因此 C4 中“全部属性模式有正概率”并非纯技术装饰。总体需要包含能够区分不同属性要求的人群。

## 反例二：两个属性在总体中永远同步

若

\[
\Pr(A^i=A^j)=1,
\]

则数据无法区分某题：

- 只要求属性 \(i\)；
- 只要求属性 \(j\)；
- 同时要求 \(i,j\)。

因为总体中从未出现 \(A^i\ne A^j\) 的学生。

## 边界三：属性列标签交换

即使全部条件成立，列置换仍无法由反应数据区分：

\[
Q\sim QP.
\]

这是模型固有对称性。若要给属性列赋予具体语义，需要结合题目内容、专家标注或其他外部变量。

## 边界四：\(c_i=g_i\)

若

\[
c_i=g_i,
\]

则

\[
\Pr(R^i=1\mid\boldsymbol A)=g_i
\]

对全部属性模式相同。这道题的反应不携带 q-vector 信息。

## 边界五：只用边际正确率

若 \(T\)-matrix 只保留单题行，不同 Q 常可通过改变 \(\boldsymbol p\) 匹配相同的边际概率。题对与高阶题组提供的联合约束是本文识别结果的重要组成部分。

原文定理要求饱和 \(T\)。低阶截断在经验算法中可行，但需要单独研究其结构条件。

## 边界六：完整性不足

若某属性没有纯题，单位阵锚点消失。本文的满列秩构造无法执行，某些设计仍可能可识别，但需依赖其他结构。本文没有声称完整性在每个具体 Q 上都逐点必要。

## 边界七：C5 的冗余不足

若某属性只被一道题要求，删除该题便失去属性覆盖，附录的行比例识别机制失效。原文说明可以构造此时 Q 无法识别的例子。

## 边界八：\((\boldsymbol p,\boldsymbol c)\) 联合识别

即使 Q 已知，属性分布和掌握者正确概率也可能参数过多。原文用 \(Q=I_k\) 展示：

\[
\text{反应自由度}=2^k-1,
\]

\[
\text{参数维数}=(2^k-1)+k.
\]

因此 Theorem 4.2 对 \(\boldsymbol p\) 的一致性额外假设 \(\widetilde{\boldsymbol c}\) 一致。

## 边界九：未知 \(g_i\)

作者指出，可以设想：

- 插入一致的 \(\widehat g_i\)；
- 对 \(g_i\) 一并剖面化。

但未知猜测参数的严格一致性需要新的技术条件，原文留作未来工作。

## 边界十：未知属性数 \(k\)

全文把 \(k\) 当作已知。若 \(k\) 错设，候选 Q 空间、属性模式数和 T 的列数都会改变。作者建议未来引入类似 BIC 的惩罚，同时选择属性维数与 Q。

## 识别、一致性与算法的区别

| 概念 | 本文处理 |
| --- | --- |
| 可识别性 | 不等价 Q 产生不同总体反应矩 |
| 一致性 | 全局矩距离估计量随 \(N\) 增大恢复真等价类 |
| 有限样本准确率 | 原文没有给出模拟或误差界 |
| 全局优化可达性 | 定义穷举估计量，未提供大规模全局求解保证 |

这四层结论不能互相替代。理论可识别也可能在有限样本中极难估；一致的目标函数也可能被局部优化器卡住。
