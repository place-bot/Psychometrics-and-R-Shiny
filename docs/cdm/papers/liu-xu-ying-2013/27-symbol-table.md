# 符号表

| 符号 | 含义 |
| --- | --- |

| \(i,h\) | 题目索引 |

| 符号 | 含义 |

## Q 与集合

| 符号 | 含义 |
| --- | --- |
| \(Q\) | 真 \(m\times k\) Q 矩阵 |

## 容易混淆的三组符号

### \(\boldsymbol A\) 与 \(\boldsymbol\alpha\)

\(\boldsymbol A\) 是单个学生的潜在属性模式；\(\boldsymbol\alpha\) 是全部样本计算出的联合答对率向量。

### \(p_{\boldsymbol0}\) 与 \(\boldsymbol p\)

\(p_{\boldsymbol0}\) 是一个标量；\(\boldsymbol p\) 堆叠全部非零属性模式概率。

### \(T_{c,g}\) 与 \(\widetilde T_{c,g}\)

\(T_{c,g}\) 只含非零模式列；\(\widetilde T_{c,g}\) 还包含全零模式猜测列和最后的全 1 约束行。
