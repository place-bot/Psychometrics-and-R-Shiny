# 饱和矩、搜索复杂度与实用截断

## 三个指数规模

### 属性模式

\[
2^k
\]

个潜在属性模式。

### 饱和题组矩

\[
2^m-1
\]

个非空题目子集。

### Q 候选

全部二元矩阵有

\[
2^{mk}
\]

个。若排除全零行，则有

\[
(2^k-1)^m
\]

个。

三者使理论估计量很快超出直接穷举能力。

## 每个候选的内层问题

给定 Q、\(\boldsymbol c,\boldsymbol g\)，属性分布通过

\[
\min_{\boldsymbol p_0}
\left\|
\overline T_{c,g}(Q)\boldsymbol p_0
-\boldsymbol\alpha
\right\|_2^2
\]

求得，约束

\[
\boldsymbol p_0\ge0,\qquad
\mathbf1^\top\boldsymbol p_0=1.
\]

这是凸二次规划。困难主要来自：

- 外层 Q 的组合搜索；
- 饱和矩的存储与计算；
- 未知 \(\boldsymbol c\) 时的额外连续优化。

## 只保留低阶题组

若最高保留到 \(d\) 阶，行数变为

\[
L_d
=
\sum_{\ell=1}^{d}
\binom m\ell.
\]

例如 \(m=20\)：

| 最高阶 \(d\) | 行数 \(L_d\) |
| ---: | ---: |
| 1 | 20 |
| 2 | 210 |
| 3 | 1,350 |
| 4 | 6,195 |
| 饱和 | 1,048,575 |

低阶截断会显著降低成本。

## 截断的统计权衡

高阶联合正确率由较少学生贡献，尤其当题目较难时：

\[
\widehat\alpha_S
=
\frac1N\sum_{r=1}^N\prod_{i\in S}R_r^i
\]

可能接近 0，抽样相对误差很大。

因此增加行数同时带来：

- 更多结构约束；
- 更高计算量；
- 更稀疏、更相关的经验矩；
- 可能更差的数值条件。

理论中的饱和矩主要服务于一般识别证明，实践中最高阶数应结合样本量和题目难度选择。

## 分块估计

原文 Remark 2.6 建议把题目拆成若干可能重叠的组：

\[
\mathcal I_1,\ldots,\mathcal I_L.
\]

对每个子题组估计对应 Q 子矩阵，再把结果拼接。重叠题目可帮助对齐属性列和检查冲突。

这一方案仍有两个实际问题：

1. 各子问题的属性列置换需要统一；
2. 分块可能丢失跨组联合矩信息。

原文只给出概念建议，没有制定完整合并算法。

## 专家 Q 作为搜索约束

Discussion 建议把专家矩阵 \(Q_0\) 纳入惩罚：

\[
S(Q)+\lambda\,d(Q,Q_0).
\]

若专家信息可靠，可只搜索 \(Q_0\) 的邻域，降低计算量并提高有限样本稳定性。2012 论文的逐行局部搜索可以看成这一实践方向的具体路线之一。

## 本文理论与可扩展算法之间的缺口

主定理要求找到全局最小化者。分块、低阶截断、邻域搜索和局部爬山都会改变估计量。若要把一致性迁移到这些算法，需要额外证明：

- 截断矩仍能分离候选 Q；
- 搜索区域包含真 Q；
- 优化器到达正确全局或等价解；
- 分块列标签能够一致对齐。

原文把高效计算明确列为未来工作。
