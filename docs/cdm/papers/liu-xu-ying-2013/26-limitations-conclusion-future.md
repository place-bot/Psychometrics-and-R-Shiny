# 局限、结论与未来工作

## 原文结论

论文为合取型认知诊断模型建立了一套 Q 自学习理论：

1. 用饱和联合正响应矩构造 \(T\)-matrix 映射；
2. 定义 Q 的列置换等价类；
3. 给出完整性、总体多样化和属性重复测量等充分条件；
4. 证明不同 Q 等价类对应的矩列空间分离；
5. 构造对无噪声、已知 \(c,g\)、未知 \(c\) 三种情形一致的估计量。

它把“Q 可以由数据修正”推进为可检验的数学命题：需要明确模型、明确结构条件，并证明错误候选无法复制真反应分布。

## 局限一：总体完全多样化

C4 要求全部属性模式有正概率。真实学习群体常有先修关系，例如掌握高阶技能的人几乎总掌握基础技能，一些模式可能结构性缺失。

原文建议此时对 Q 加入与属性层级相容的结构限制。加法—乘法例中，若掌握乘法必然伴随掌握加法，可要求所有测乘法的题也要求加法。这样 Q 可能不再完整，识别理论也需重新建立。

## 局限二：专家信息尚未系统融合

作者建议把专家 Q 作为惩罚或搜索中心：

\[
S(Q)+\lambda\,\operatorname{penalty}(Q,Q_0).
\]

可靠先验信息可以：

- 提高有限样本精度；
- 缩小候选空间；
- 给属性列提供语义标签；
- 降低属性列对齐难度。

如何选择惩罚与 \(\lambda\) 留待后续研究。

## 局限三：属性数量已知

全文固定 \(k\)。作者建议使用类似 BIC 的维数惩罚，同时估计：

\[
(k,Q).
\]

这需要处理不同 \(k\) 下潜在类别数量、参数维数和候选空间都变化的问题。

## 局限四：附加参数的识别

本文把 \(\boldsymbol p,\boldsymbol c\) 视为伴随 Q 的参数。给定 Q 后，\((\boldsymbol p,\boldsymbol c,\boldsymbol g)\) 的联合可识别性本身仍是重要问题。

尤其需要：

- 未知 \(g_i\) 的严格理论；
- \((p,c)\) 维数过多时的结构约束；
- 更一般 CDM 项目参数的识别；
- 参数估计误差对 Q 选择的传播分析。

## 局限五：没有收敛速度

定理给出

\[
\Pr(\widehat Q\sim Q)\to1,
\]

却没有给出：

- 指数误差率；
- 有限样本上界；
- 最小 \(c_i-g_i\) 的作用；
- 最小属性模式概率的作用；
- \(m,k\) 随 \(N\) 增长时的条件。

原文把收敛速度列为理论与实践都重要的方向。

## 局限六：组合优化昂贵

全空间评价需要面对

\[
2^{mk}
\]

级别候选。作者提出分块、低阶矩和专家邻域，但没有给出高效全局算法及其一致性。

后续可研究：

- 混合整数优化；
- branch-and-bound；
- 可证明的局部更新；
- 连续松弛与稀疏惩罚；
- 变分与 Bayesian 结构搜索；
- 神经或能量模型的候选生成，再用矩条件校验。

## 原文六项未来工作

Discussion 明确提出：

1. 在总体属性模式不完全多样时修改条件；
2. 融合专家 Q 信息；
3. 数据驱动估计属性维数；
4. 深入研究 \(s,g,p\) 的识别与估计；
5. 研究 \(\widehat Q\) 的收敛速度；
6. 设计更高效的 Q 搜索算法。

Remark 4.2 还单独提出未知猜测概率的严格分析。

## 今天看这篇论文的价值

这篇文章的算法形式已经显得计算密集，但它提出的判断标准仍很重要：

> 一个 Q 学习方法若要声称能恢复结构，需要说明观测分布何时区分不同 Q、属性标签有哪些固有对称性，以及 nuisance parameters 是否会替错误 Q 吸收结构差异。

对现代机器学习 Q 估计、文本到 Q、RBM 或生成模型，这三个问题依然存在。预测准确率高并不会自动给出结构可识别性。
