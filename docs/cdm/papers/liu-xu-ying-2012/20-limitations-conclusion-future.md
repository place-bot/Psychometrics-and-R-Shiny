# 局限、结论与未来工作

## 论文结论

论文建立了一条从作答数据学习 Q 的统一路线：

\[
Q
\longrightarrow
T_{\boldsymbol c,\boldsymbol g}(Q)
\longrightarrow
T_{\boldsymbol c,\boldsymbol g}(Q)\boldsymbol p
\longleftrightarrow
\boldsymbol\beta.
\]

在 DINA 模拟中，只要样本量相对 \(2^K\) 足够大、起始 Q 只错少量题，逐行搜索能以很高频率恢复真 Q。部分已知 Q 场景可以高效校准新题。

## 主要局限

### 1. 起点依赖

主模拟固定为 20 题中错 3 行。远距离起点和多起点策略未评估。

### 2. 局部最小

Algorithm 1 每次只改一行，可能无法跨越需要两行同时变化的目标障碍。

### 3. 有限样本过拟合

Figures 1--2 显示继续降低 \(S\) 可能越过真 Q。4.5% 早停缺少独立调参证据。

### 4. 计算负担

每轮 \(J2^K\) 次候选评价，每次还需 EM 和 T 构造。K 与 J 增长都很快。

### 5. 模型依赖

主要算法和实验使用 DINA、局部独立与二分反应。DINO 扩展只在讨论中说明原理。

### 6. 识别条件

参数全部未知、Q 不完整、题型不够多样时可能产生观测等价结构。

### 7. 实证缺口

全文没有真实题库、内容专家复核、运行时间或下游分类效果。

### 8. 实现信息不足

原始代码、随机种子和关键工程设置均未公开。

## 原文提出的未来方向

- 为大 Q 开发更快的优化算法；
- 用分块减少计算；
- 扩展到 DINO 和其他满足条件独立的 DCM；
- 正式研究 hypothesis testing 与 model selection；
- 把已知 Q entry、项目参数和属性分布结构加入约束；
- 用 S 框架验证现有 Q 与模型假设。

## 本站认为值得继续追的问题

这些问题是基于论文局限的延伸：

1. 用多起点、beam search 或可逆跳跃策略衡量局部解不确定性；
2. 通过 bootstrap 为 \(\Delta S\) 和结构修改提供稳定性频数；
3. 联合使用题目文本与反应数据，解决属性列的语义锚定；
4. 用交叉验证选择 T 的最高阶、行预算与早停阈值；
5. 把 Q 学习嵌入在线新题校准，并持续监控旧锚题漂移；
6. 将完整 Q 恢复率拆成 entry、row、attribute-level 与下游分类指标。

## 应用底线

数据建议应与内容分析并行。多个近优 Q、稀有属性类和模型错设都会让单一最优矩阵显得过度确定。论文自身也建议在目标值接近时检查多个候选，并从实质角度选择合理结构。
