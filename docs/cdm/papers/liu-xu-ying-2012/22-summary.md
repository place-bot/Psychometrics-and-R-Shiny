# 总结与后续阅读

## 方法压缩

整篇论文可以压成六步：

1. 给定候选 Q，写出每题在 \(2^K\) 个属性模式下的答对概率；
2. 用逐元素乘积得到多题 B-vector；
3. 堆成 \(T_{\boldsymbol c,\boldsymbol g}(Q)\)；
4. 从反应数据计算同一批联合答对率 \(\boldsymbol\beta\)；
5. 以

   \[
   \widehat S(Q)
   =
   \left\|
   T_{\widehat c,\widehat g}(Q)\widehat p-\boldsymbol\beta
   \right\|_2
   \]

   衡量候选；

6. 从 \(Q_0\) 出发，每轮只改使 \(\widehat S\) 下降最多的一道题。

## 与前两篇 Q 验证论文的关系

| 方法 | 比较单位 | 核心标准 | 搜索 |

## 可以推出的结论

- T-matrix 为 Q 学习提供了统一矩匹配框架；
- 在论文模拟条件和近邻起点下，大样本恢复表现很强；
- 部分已知 Q 的新题校准具有明确计算优势；
- 相关或稀有属性模式会显著增加样本需求。
