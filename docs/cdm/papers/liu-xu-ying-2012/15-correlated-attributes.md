# Table 3：相关且不均衡的属性

## 生成模型

先生成

\[
\boldsymbol\theta=(\theta_1,\ldots,\theta_K)
\sim N(\boldsymbol0,\Sigma),
\]

\(\Sigma\) 的对角线为 1，任意两维共同相关为

\[
\rho\in\{.05,.15,.25\}.
\]

再定义

\[
\alpha_k=
\mathbf 1\left[
\theta_k\ge
\Phi^{-1}\left(\frac{k}{K+1}\right)
\right].
\]

阈值随属性编号变化，所以各属性边际掌握率不同。继续使用 \(Q_1,K=3\)、\(s_j=g_j=.2\)，每条件 100 份数据，并采用类似早停。

## 原表恢复次数

| \(\rho\) | \(N=1000\) | \(N=2000\) | \(N=4000\) |
| ---: | ---: | ---: | ---: |
| .05 | 78 | 98 | 100 |
| .15 | 71 | 94 | 99 |
| .25 | 41 | 76 | 95 |

## 相关效应

固定 N，相关越高，完整恢复率越低。例如 \(N=1000\)：

\[
78\%\to71\%\to41\%.
\]

相关让样本集中到少数属性组合，某些模式人数很少。虽然总 N 不变，能区分特定 q-vector 的“有效样本量”下降。

## 样本量补偿

固定 \(\rho=.25\)：

\[
41\%\to76\%\to95\%.
\]

扩大 N 能部分补偿属性类不均衡。

## 表题与表头差异

Table 3 的标题写 \(N=500,1000,2000,4000\)，实际表头和数据只列 \(1000,2000,4000\)。正文也没有提供 \(N=500\) 的三个频数。本专题不补造缺失列。

## 对样本量经验式的提醒

讨论部分建议

\[
N\ge30\times2^K,
\]

含义是平均每个属性模式约有 30 人。属性分布不均匀时，平均数会掩盖稀有模式；更合理的检查是

\[
Np_{\min}
\]

以及与每个 q-vector 最相关的掌握/非掌握组实际人数。
