# 研究问题、贡献与证据边界

## 问题

CDM 通常把 Q 矩阵当成已知设计：

\[
Q_{jk}=1
\]

表示题目 \(j\) 需要属性 \(k\)。实际 Q 多由专家编码，编码误差会继续传递到：

- slipping 与 guessing 估计；
- 属性模式比例；
- 学生属性分类；
- 项目和模型拟合判断。

本文研究：已知属性数 \(K\)，只有 \(N\times J\) 二分作答矩阵时，怎样利用反应数据学习或校准 \(J\times K\) 的 Q？

## 三项方法贡献

### 1. 用 T-matrix 连接潜在结构与观测数据

给定候选 \(Q'\)、项目参数 \((\boldsymbol c,\boldsymbol g)\) 和属性分布 \(\boldsymbol p\)，论文构造

\[
T_{\boldsymbol c,\boldsymbol g}(Q')\boldsymbol p.
\]

这个向量包含模型预测的单题、题对以及更高阶题组联合答对率。样本中的同类比例组成 \(\boldsymbol\beta\)。

### 2. 把 Q 学习写成距离最小化

\[
S_{\boldsymbol c,\boldsymbol g,\boldsymbol p}(Q')
=
\left\|
T_{\boldsymbol c,\boldsymbol g}(Q')\boldsymbol p-\boldsymbol\beta
\right\|_2.
\]

参数未知时先剖面化或先用 MLE 估计，再比较候选 Q。

### 3. 用逐题整行搜索控制离散空间

完整搜索空间有

\[
2^{JK}
\]

个二进制矩阵。Algorithm 1 只考察当前 Q 的逐行邻域，每轮约评价 \(J2^K\) 个候选。

## 证据结构

论文全部经验结果来自模拟，没有真实数据分析。

| 实验 | 检查对象 |
| --- | --- |
| 一般 Q 恢复 | \(K=3,4,5\)，不同 \(N\) |
| 小样本早停 | 目标函数平坦时是否避免越过真 Q |
| 非均匀属性 | 属性相关与类别稀疏造成的有效样本量下降 |
| 部分已知 Q | 已知 \(2K\) 个锚题后校准一题 |

## 方法定位

论文中的属性数 \(K\) 已知，属性列的语义也由既有框架提供。算法搜索 q-vector 组合，无法单靠 0/1 作答为每一列自动生成内容名称。

算法还依赖初始 \(Q_0\) 接近真 Q。主模拟只把 20 道题中的 3 行故意设错。因此实验直接支持的是“近邻起点下的结构恢复”，对任意随机起点的表现没有给出证据。

## 与 2013 理论论文的边界

2012 文给出方法、算法、模拟和讨论，并在理论性质段引用 Liu、Xu 与 Ying 的理论工作。完整一致性理论属于后续单独发表的 *Theory of Self-learning Q-matrix*。本专题只解释 2012 文实际写出的理论摘要；下一篇再逐定理处理理论论文。
