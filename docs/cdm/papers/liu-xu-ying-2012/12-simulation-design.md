# 模拟实验共同设计与三个 Q

## 共同设置

| 因素 | 设置 |
| --- | --- |
| 生成模型 | DINA |
| 题数 | \(J=20\) |
| 属性数 | \(K=3,4,5\) |
| 属性分布 | 主实验均匀：\(p_{\boldsymbol\alpha}=2^{-K}\) |
| 项目参数 | 全部题 \(s_j=g_j=.2\)，即 \(c_j=.8\) |
| 样本量 | \(N=500,1000,2000,4000\) |
| 重复 | 每条件 100 份数据 |
| T-matrix | 正文写至多 4 题组合 |
| 起始误差 | 20 题中随机选 3 题，整行改错 |
| 搜索 | Algorithm 1 |
| 结果指标 | 完整 Q 是否逐格等于生成 Q |

## 起始 Q 的构造

从真 Q 随机抽 3 行。每一行从

\[
2^K-2
\]

个向量中均匀抽取替代值：

- 排除真 q-vector；
- 排除全零向量。

所以 \(Q_0\) 恰好有 3 道题的整行错误。每行内部可能错 1 到 \(K\) 个 entry。

## \(Q_1:20\times3\)

按原文式 (20)：

```text
100 010 001 100 010 001 100 010 001
110 101 101 011 101 011 110 011 101 011 111
```

它包含重复的单位向量，也包含二属性和三属性题。

## \(Q_2:20\times4\)

```text
1000 0100 0010 0001
1000 0100 0010 0001
1100 1010 1001 0110 0101 0011
1110 1101 1011 0111 1111 1111
```

## \(Q_3:20\times5\)

```text
10000 01000 00100 00010 00001
10000 01000 00100 00010 00001
11000 10100 10010 10001 01100
01010 01001 00110 00101 00011
```

\(Q_3\) 只有单属性和双属性题，没有更高阶组合。

## 难度随 K 增长的原因

属性类数量为

\[
2^K:
\quad
8,\ 16,\ 32.
\]

同样 \(N=500\) 时，每类平均人数从 62.5 降到 31.25，再降到 15.625。参数更多、类别更稀疏，联合矩的抽样误差也更大。

## 设计能回答的范围

这个实验检查从“仅错 3 行”的局部起点恢复真 Q。它没有操纵：

- 随机起点或大范围错误；
- \(K\) 未知；
- 模型错设；
- 题目参数异质性；
- 缺失作答；
- 真实内容约束。
