# Table 4：单道新题校准

## 设置

\[
Q=
\begin{pmatrix}
I_K\\I_K\\V_J
\end{pmatrix},
\qquad
J=2K+1.
\]

前 \(2K\) 行已知，只估计 \(V_J\)。每条件：

\[
s_j=g_j=.2,\qquad
p_{\boldsymbol\alpha}=2^{-K},
\]

## 规律一：需要的属性越多越难

DINA 是合取模型。均匀属性分布下，覆盖一个给定 \(r\) 属性要求的比例为

\[
2^{-r}.
\]

全 1 新题的理想掌握组非常小：

\[
K=5,\ r=5
\quad\Rightarrow\quad
\Pr(\xi=1)=1/32.
\]

估计 \(c_J\) 和辨别“需要四项”与“需要五项”都需要大量样本。

## 规律二：锚题大幅缩小问题

主实验要同时纠正完整 Q；这里前 \(2K\) 行固定，只比较 \(2^K\) 种新题 q-vector。因而低维、低属性数新题在较小 N 下已有很高恢复率。

## 规律三：总样本量需要随稀有掌握组增长

对 \(K=5,V_J=11111\)，即使 \(N=8000\)，100 次中仍有 12 次失败。设计校准样本时，除 \(2^K\) 类平均人数外，还要检查新题理想掌握组人数

\[
N\Pr(\xi_J=1).
\]
