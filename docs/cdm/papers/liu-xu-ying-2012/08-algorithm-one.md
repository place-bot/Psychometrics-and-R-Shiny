# Algorithm 1：逐行爬山搜索

## 邻域

对当前矩阵 \(Q'\)，定义

\[
U_j(Q')
\]

为所有“除第 \(j\) 行外均与 \(Q'\) 相同”的 \(J\times K\) 二进制矩阵。第 \(j\) 行有 \(2^K\) 种模式。

## 初始化

\[
Q^{(0)}=Q_0,
\]

\(Q_0\) 通常来自专家。论文预期它与真 Q 足够接近。

## 每轮三步

给定 \(Q^{(m-1)}\)：

### 第一步：每道题找自己最优的新行

\[
Q_j
=
\arg\inf_{
Q'\in U_j(Q^{(m-1)})
}
\widehat S(Q').
\tag{19}
\]

这一步对每道题分别穷举其 \(2^K\) 个 q-vector。

### 第二步：在 J 道题中选下降最多的一题

\[
j_*=\arg\inf_j\widehat S(Q_j).
\]

### 第三步：只接受这一行更新

\[
Q^{(m)}=Q_{j_*}.
\]

若

\[
Q^{(m)}=Q^{(m-1)},
\]

算法停止。

## 通俗流程

```text
当前 Q
  ├─ 假设只改题 1：找题 1 的最佳整行
  ├─ 假设只改题 2：找题 2 的最佳整行
  ├─ ...
  └─ 假设只改题 J：找题 J 的最佳整行
             ↓
      从 J 个局部赢家中选全局最优
             ↓
         当前 Q 只改这一行
```

## 每轮复杂度

候选评价次数约为

\[
J\times2^K.
\]

每次评价又包含：

- 一次固定 Q 的 DINA EM；
- 构造所选 T-matrix；
- 计算 \(\widehat S\)。

因此 \(J2^K\) 只是候选数量，实际运行时间还乘上 EM 和矩计算成本。

## 搜索性质

每次接受使目标下降的单行更新，所以目标路径单调不增。算法停在逐行邻域的局部最小值。它没有保证从任意 \(Q_0\) 找到全局最小值。

## 全零行

式 (19) 与“最多 \(2^K\) 次评价”在字面上包含全零 q-vector。主模拟构造 \(Q_0\) 时明确排除全零行，但正文没有说明后续搜索是否也排除。实践中通常应根据内容含义决定是否允许“不要求任何属性”的题，并记录这一实现选择。

## 平局

原文没有规定多个候选具有相同 \(\widehat S\) 时的 tie-breaking。代码复现需要固定候选顺序或显式采用最简性规则，结果才可重复。
