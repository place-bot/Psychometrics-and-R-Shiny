# 问题、对象与模型假设

## 论文希望解决的问题

传统单维 IRT 常给每个学生一个连续能力分数：

\[
\theta_i\in\mathbb R.
\]

这种分数适合排序和量尺。教学干预还需要更细的信息，例如学生已经掌握哪些技能、在哪些技能上需要补救。

DINA 使用一个二元属性向量：

\[
\boldsymbol\alpha_i
=
(\alpha_{i1},\ldots,\alpha_{iK})^\mathsf T,
\qquad
\alpha_{ik}\in\{0,1\}.
\]

- \(\alpha_{ik}=1\)：学生 \(i\) 掌握属性 \(k\)；
- \(\alpha_{ik}=0\)：尚未掌握。

论文把 skill、knowledge representation 和 cognitive process 统一称为 attribute。

## 观测数据

设

\[
X_{ij}\in\{0,1\},
\]

其中：

- \(i=1,\ldots,I\) 表示学生；
- \(j=1,\ldots,J\) 表示题目；
- \(X_{ij}=1\) 表示答对；
- \(X_{ij}=0\) 表示答错。

数据矩阵为

\[
X\in\{0,1\}^{I\times J}.
\]

## Q 矩阵

\[
Q=(q_{jk})\in\{0,1\}^{J\times K}.
\]

\(q_{jk}=1\) 表示题目 \(j\) 要求属性 \(k\)。第 \(j\) 行

\[
\boldsymbol q_j
=(q_{j1},\ldots,q_{jK})^\mathsf T
\]

是该题的认知要求。

原文以分数减法为例，五个属性为：

1. 基本分数相减；
2. 约分和化简；
3. 分离整数与分数部分；
4. 从整数部分借位；
5. 把整数转换成分数。

题目 \(7\frac35-4\frac45\) 要求属性 1、3、4，因此

\[
\boldsymbol q_j=(1,0,1,1,0)^\mathsf T.
\]

## 属性模式也是潜在类别

二元 \(K\) 属性共有

\[
L=2^K
\]

个可能模式：

\[
(0,\ldots,0),\ldots,(1,\ldots,1).
\]

所以 DINA 可以写成一个受限潜在类模型：

- 每个属性模式是一类；
- 类条件答对概率受 Q 矩阵、guess 和 slip 约束；
- 不同潜在类在某题上若具有相同理想状态，就共享同一个答对概率。

“受限”体现在 \(2^K\) 个类别没有各自独立的 \(J\) 个答对概率。

## 本文模型的主要假设

| 假设 | 作用 |
| --- | --- |
| 二元题目反应 | \(X_{ij}\in\{0,1\}\) |
| 二元属性掌握 | \(\alpha_{ik}\in\{0,1\}\) |
| Q 矩阵已知 | 题目要求哪些属性事先给定 |
| 连接规则为合取 | 一道题要求的属性必须全部掌握 |
| 给定属性模式后局部独立 | 一名学生的题目反应条件似然可相乘 |
| 每题两个噪声参数 | \(g_j\) 和 \(s_j\) |
| 属性模式分布需另外指定 | 饱和多项分布或 HO-DINA 高阶分布 |

## DINA 的强约束

对一道要求多个属性的题，所有“至少缺一个所需属性”的模式被压到同一个理想状态：

\[
\eta_{ij}=0.
\]

无论学生缺一个属性还是缺三个属性，答对概率都是 \(g_j\)。

所有所需属性都掌握时：

\[
\eta_{ij}=1,
\]

答对概率都是 \(1-s_j\)。

这带来简洁解释和低参数量，也会忽略部分掌握程度及属性间不同主效应。de la Torre (2011) 的 G-DINA 正是沿着这个限制继续一般化。
