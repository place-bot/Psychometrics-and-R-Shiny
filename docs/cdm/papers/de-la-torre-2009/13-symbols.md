# 符号表

## 人、题目和属性

| 符号 | 维度或范围 | 含义 |
| --- | --- | --- |
| \(I\) | 正整数 | 学生数 |
| \(J\) | 正整数 | 题目数 |
| \(K\) | 正整数 | 属性数 |
| \(i\) | \(1,\ldots,I\) | 学生索引 |
| \(j\) | \(1,\ldots,J\) | 题目索引 |
| \(k\) | \(1,\ldots,K\) | 属性索引 |
| \(X_{ij}\) | \(\{0,1\}\) | 学生 \(i\) 对题 \(j\) 的观测反应 |
| \(\boldsymbol X_i\) | \(\{0,1\}^J\) | 学生 \(i\) 的完整反应向量 |
| \(\alpha_{ik}\) | \(\{0,1\}\) | 学生 \(i\) 是否掌握属性 \(k\) |
| \(\boldsymbol\alpha_i\) | \(\{0,1\}^K\) | 学生属性模式 |

## Q 矩阵和理想反应

| 符号 | 维度或范围 | 含义 |
| --- | --- | --- |
| \(Q\) | \(J\times K\) | 题目—属性需求矩阵 |
| \(q_{jk}\) | \(\{0,1\}\) | 题 \(j\) 是否要求属性 \(k\) |
| \(\boldsymbol q_j\) | \(\{0,1\}^K\) | Q 的第 \(j\) 行转置 |
| \(Z_{ij}\) | \(\{0,1\}\) | 原文对理想反应的记号 |
| \(\eta_{ij}\) | \(\{0,1\}\) | 本专题和后续 CDM 常用的理想反应记号 |
| \(\eta_{ij}=\prod_k\alpha_{ik}^{q_{jk}}\) | 公式 | 全部所需属性掌握时为 1 |

## 项目参数

| 符号 | 范围 | 含义 |
| --- | --- | --- |
| \(g_j\) | \([0,1]\) | \(\eta=0\) 时答对概率 |
| \(s_j\) | \([0,1]\) | \(\eta=1\) 时答错概率 |
| \(1-s_j\) | \([0,1]\) | \(\eta=1\) 时答对概率 |
| \(P_j(\boldsymbol\alpha_l)\) | \([0,1]\) | 模式 \(l\) 在题 \(j\) 的答对概率 |
| \(\boldsymbol\beta\) | \(2J\) | 所有 \(g_j,s_j\) 的参数向量 |
| \(\beta_{j0}\) | 标量 | 附录记号，等于 \(g_j\) |
| \(\beta_{j1}\) | 标量 | 附录记号，等于 \(s_j\) |

## 潜在类与 EM

| 符号 | 含义 |
| --- | --- |
| \(L=2^K\) | 全部二元属性模式数 |
| \(l\) | 属性模式索引 |
| \(\boldsymbol\alpha_l\) | 第 \(l\) 个可能属性模式 |
| \(\pi_l\) 或 \(p(\boldsymbol\alpha_l)\) | 第 \(l\) 个模式的先验比例 |
| \(Z_{il}\) | 学生 \(i\) 是否属于模式 \(l\) 的类别指示变量 |
| \(w_{il}\) | \(P(\boldsymbol\alpha_l\mid\boldsymbol X_i)\)，E 步后验权重 |
| \(I_j^{(z)}\) | 题 \(j\) 的理想状态 \(z\) 期望人数 |
| \(R_j^{(z)}\) | 其中答对题 \(j\) 的期望人数 |
| \(\ell(X)\) | 边际对数似然 |
| \(\mathcal I(\widehat{\boldsymbol\beta})\) | 观测信息矩阵 |

## HO-DINA

| 符号 | 含义 |
| --- | --- |
| \(\theta_i\) | 学生 \(i\) 的高阶一般能力 |
| \(\theta_i\sim N(0,1)\) | 论文的高阶能力分布 |
| \(\lambda_{0k}\) | 属性 \(k\) 的 logistic 截距 |

| \(p_k(\theta_i)\) | 给定 \(\theta_i\) 时属性 \(k\) 的掌握概率 |
