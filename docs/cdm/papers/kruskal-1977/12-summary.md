# 总结与后续问题

## 这篇论文完成了什么

Kruskal (1977) 为三路数组建立了一套相连的语言：

1. 用 triad 定义三路数组秩；
2. 用 slab-space 和模式变换建立秩下界；
3. 用三重积 \([A,B,C]\) 统一表示秩一成分之和；
4. 用 Kruskal rank 描述“任意列子集”的独立性；
5. 用

   \[
   k_A+k_B+k_C\ge2R+2
   \]

   保证 \(R\) 项分解本质唯一；
6. 把张量秩连接到算术复杂度，把唯一性连接到三路统计模型。

## 需要牢牢记住的五点

1. 张量秩、普通矩阵秩和 Kruskal rank 是三个不同概念。
2. \(k\)-rank 要求任意指定规模的列子集都独立。
3. Kruskal 条件提供确定性的充分证书。
4. 条件失败以后，唯一性仍需其他定理或显式反例判断。
5. 总体分解唯一不自动保证有限样本估计稳定。

## 论文没有覆盖的任务

原文没有提供：

- 带噪张量的数值恢复误差界；
- 大规模 \(k\)-rank 的高效验证算法；
- CP 分解软件；
- 成分数 \(R\) 的数据驱动选择；
- CDM 中 Q 矩阵的恢复；
- 有限样本偏差、方差或覆盖率实验。

本站脚本只帮助检查小型精确例子。

## 后续理论怎样推进

后来的研究沿几条方向扩展：

- 更短、更透明的 Kruskal 定理证明；
- 比 \(k_A+k_B+k_C\ge2R+2\) 更弱的唯一性条件；
- \(N\) 路张量的唯一性；
- 近似唯一性与带噪稳定恢复；
- 可计算的代数分解算法；
- 潜在类、HMM、系统发育和 CDM 的泛可识别性。

Rhodes (2010) 处理证明可读性；Allman 等人 (2009) 把定理系统化地迁移到多观测变量潜在结构模型。

## 在本站 CDM 路线中的位置

\[
\text{Kruskal (1977)}
\longrightarrow
\text{Allman et al. (2009)}
\longrightarrow
\text{CDM 专门识别定理}.
\]

- Kruskal 给出三路分解唯一性工具；
- Allman 给出观测变量分块与泛满秩方法；
- CDM 论文加入 Q 矩阵、属性模式和具体反应函数约束。

这三层不能相互替代，但可以组成完整的可识别性证明链。
