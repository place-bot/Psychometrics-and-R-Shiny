# 问题与历史位置

## 从矩阵分解开始

一个秩为 \(R\) 的矩阵可以写成

\[
X=AB^\mathsf T
=\sum_{r=1}^{R}\boldsymbol a_r\boldsymbol b_r^\mathsf T.
\]

给定任意可逆矩阵 \(Q\)，还有

\[
X
=AQQ^{-1}B^\mathsf T
=(AQ)(BQ^{-\mathsf T})^\mathsf T.
\]

所以矩阵中的秩一成分通常可以被任意可逆线性变换混合。即使 \(X\) 完全已知，单独的 \(\boldsymbol a_r,\boldsymbol b_r\) 仍可能无法恢复。

## 第三个方向带来的约束

三路数组写成

\[
x_{ijk}
=\sum_{r=1}^{R}
a_{ir}b_{jr}c_{kr}.
\]

同一个成分编号 \(r\) 必须同时贯穿三个方向：

\[
\boldsymbol a_r
\longleftrightarrow
\boldsymbol b_r
\longleftrightarrow
\boldsymbol c_r.
\]

若尝试用一般可逆矩阵混合 \(A\) 和 \(B\) 的列，还要让第三个因子 \(C\) 同时保持逐成分相乘的结构。这个额外兼容条件大幅压缩了可能的变换。

Kruskal 的核心发现是：三个因子矩阵的列只要具有足够强的“任取若干列仍独立”性质，一般可逆混合会被排除，最终只剩：

- 对 \(R\) 个成分做同一个置换；
- 在三个方向上对同一成分缩放，且三个缩放量乘积为 1。

## 论文中的三个逻辑问题

### 问题一：最少需要多少个 triad

\[
\operatorname{rank}(\mathcal X)
=
\min\left\{
R:
\mathcal X
=\sum_{r=1}^{R}
\boldsymbol a_r\otimes\boldsymbol b_r\otimes\boldsymbol c_r
\right\}.
\]

这是张量秩问题。论文建立了若干下界，用来证明某个给定分解已经无法继续缩短。

### 问题二：给定长度的分解是否唯一

即使某个分解恰好使用最少的 \(R\) 项，也可能存在另一组三个因子矩阵产生同一个数组。唯一性问题比较

\[
[A,B,C]=[\bar A,\bar B,\bar C].
\]

### 问题三：统计参数能否识别

在潜在类模型中，三个因子矩阵可以由三组观测变量在各潜在类下的条件分布组成。若三重积分解本质唯一，再加入概率归一化，便可以恢复类别比例与条件分布，允许类别标签交换。

这一步还需要统计模型自身的结构：

- 因子列能否解释为概率向量；
- 缩放怎样由列和为 1 的约束固定；
- 置换后的潜在类怎样连接到属性模式；
- Q 矩阵或认知诊断参数化是否还引入新的等价关系。

因此，Kruskal 定理提供代数核心，完整 CDM 可识别性还需要后续桥接。

## 1977 论文的历史位置

论文把三个领域连在一起：

| 领域 | 三路数组中的对象 | 论文提供的作用 |
| --- | --- | --- |
| 多线性代数 | triad 之和 | 秩定义、秩下界和分解唯一性 |
| 算术复杂度 | 双线性计算方案 | 用张量秩刻画所需乘法次数 |
| 统计与心理计量 | 三路数据、潜在结构或 INDSCAL 类模型 | 解释因子什么时候可由总体数组确定 |

后来的 CANDECOMP/PARAFAC、潜在类识别、系统发育模型和 CDM 识别文献不断复用这条唯一性定理。

## 四个容易混淆的词

| 词 | 问的内容 |
| --- | --- |
| matrix rank | 一个矩阵的列空间维数 |
| tensor rank | 三路数组最少需要多少个秩一张量 |
| Kruskal rank | 一个因子矩阵任取多少列都保证独立 |
| identifiability | 观测分布能否唯一确定统计参数，允许事先声明的等价关系 |

全文最重要的阅读纪律是让这四个概念保持分离。
