# 模拟实验

## 研究问题

论文检验 A-CDM 的逐题 Wald test：

1. 数据由 A-CDM 生成时，拒绝率是否接近名义显著性水平；
2. 数据由 DINA 或 DINO 生成时，检验能否发现 A-CDM 不合适。

因此，模拟的 Type I error 对应 A-CDM 真模型；power 对应 DINA/DINO 真模型。

## 固定设计

| 条件 | 取值 |
| --- | ---: |
| 学生数 \(I\) | 2,000 |
| 项目数 \(J\) | 30 |
| 属性数 \(K\) | 5 |
| 每种生成模型的数据集数 | 1,000 |
| 生成模型 | A-CDM、DINA、DINO |
| 显著性水平 | 0.01、0.05、0.10 |

30 道题分为：

- 10 道单属性题；
- 10 道双属性题；
- 10 道三属性题。

论文没有在模拟段落中明确报告属性模式生成分布。复现时需要把该项作为额外假设注明。

## 参数设置

### A-CDM

所有题的最低与最高成功概率均为 0.20 和 0.80。

| 题型 | \(\delta_0\) | 主效应 |
| --- | ---: | ---: |
| 单属性 | 0.20 | \(\delta_1=0.60\) |
| 双属性 | 0.20 | 每个 \(\delta_k=0.30\) |
| 三属性 | 0.20 | 每个 \(\delta_k=0.20\) |

### DINA 与 DINO

\[
g=s=0.20.
\]

因此低成功组为 0.20，高成功组为 0.80。

## Type I error 结果

当 A-CDM 为真时：

| 名义水平 | 双属性题平均拒绝率 | 三属性题平均拒绝率 |
| ---: | ---: | ---: |
| 0.01 | 0.01 | 0.01 |
| 0.05 | 0.05 | 0.06 |
| 0.10 | 0.11 | 0.11 |

拒绝率总体接近名义水平；0.05 下三属性题略高，0.10 下两类题均为 0.11。

## power 结果

当 DINA 或 DINO 为真时，在全部三个显著性水平上：

\[
\text{power}=1.0.
\]

论文据此说明，在这一组高信号、较大样本的模拟条件下，Wald test 能稳定发现 A-CDM 的错误约化，同时没有明显抬高 Type I error。

## 结果不能外推到哪些条件

该实验没有改变：

- 样本量；
- 属性分布；
- 效应强度；
- 题长；
- \(K_j^*\) 的更大取值；
- Q 矩阵错误；
- 模式稀疏程度。

power 等于 1.0 反映的是当前参数分离度和 \(I=2000\) 的联合条件，不能解释为 Wald test 在一般条件下始终具有完全检验力。
