# 符号表

## 总体识别记号

| 符号 | 类型或维度 | 含义 |
| --- | --- | --- |
| \(\Theta\) | 参数空间 | 模型所有允许参数的集合 |
| \(\theta\) | 参数点 | 一组具体模型参数 |
| \(\Omega\) | 样本空间 | 可观测变量的取值空间 |
| \(\mathcal M_1(\Omega)\) | 概率测度集合 | \(\Omega\) 上所有概率分布 |
| \(\Psi(\theta)=P_\theta\) | 参数化映射 | 参数到观测分布的映射 |
| \(\mathcal V\) | 代数子簇 | 多项式方程共同零点集合 |

## 有限潜在类模型

| 符号 | 类型或维度 | 含义 |
| --- | --- | --- |
| \(Z\) | \(\{1,\ldots,r\}\) | 离散潜在类别 |
| \(r\) | 正整数，已知 | 潜在类别数 |
| \(\pi_i\) | 标量 | \(P(Z=i)\)，第 \(i\) 类比例 |
| \(\boldsymbol\pi\) | \(r\)-向量 | 类别比例向量，元素正且和为 1 |
| \(p\) | 正整数 | 观测变量个数 |
| \(X_j\) | 有限状态变量 | 第 \(j\) 个观测变量 |
| \(\kappa_j\) | 正整数 | \(X_j\) 的状态数 |
| \(p_{ij}(\ell)\) | 标量 | \(P(X_j=\ell\mid Z=i)\) |
| \(\boldsymbol p_{ij}\) | \(\kappa_j\)-向量 | 第 \(i\) 类下 \(X_j\) 的条件分布 |
| \(M_j\) | \(r\times\kappa_j\) | 第 \(j\) 个变量的类条件概率矩阵 |
| \(P_i\) | \(\kappa_1\times\cdots\times\kappa_p\) 表 | 第 \(i\) 类的乘积联合分布 |
| \(P\) | 联合概率表 | 总体混合分布 \(\sum_i\pi_iP_i\) |
| \(\mathcal M(r;\kappa_1,\ldots,\kappa_p)\) | 模型族 | \(r\) 类、\(p\) 特征有限潜在类模型 |

## 张量与秩

| 符号 | 类型或维度 | 含义 |
| --- | --- | --- |
| \(\otimes\) | 运算 | 向量外积或 Kronecker 积 |
| \(\otimes_{\mathrm{row}}\) | 运算 | 对同一行索引逐行做张量积 |

## 分块定理

| 符号 | 类型或维度 | 含义 |
| --- | --- | --- |
| \(S_1,S_2,S_3\) | 索引集合 | 三个非空、互不相交的观测变量块 |
| \(X_{S_a}\) | 复合变量 | 第 \(a\) 块内所有变量组成的联合变量 |
| \(K_a\) | 正整数 | 第 \(a\) 块状态数 \(\prod_{j\in S_a}\kappa_j\) |
| \(N_a\) | \(r\times K_a\) | 第 \(a\) 块的类条件概率矩阵 |
| \(k\) | 正整数 | Corollary 5 中 \(\lceil\log_2r\rceil\)，或 HMM 左右窗口长度 |

!!! note "原文记号差异"
    原文 Theorem 4 用 \(k_j\) 表示单变量状态数、用 \(\kappa_a\) 表示块状态数。本站统一用
    \(\kappa_j\) 表示单变量状态数、\(K_a\) 表示块状态数。

## 关键条件速查

\[
I_1+I_2+I_3\ge2r+2
\qquad
\text{三路张量点态唯一性}
\]

\[
\sum_{a=1}^{3}\min(r,K_a)\ge2r+2
\qquad
\text{多变量三块泛识别}
\]

\[
p\ge2\lceil\log_2r\rceil+1
\qquad
\text{\(r\) 类 Bernoulli 混合的充分变量数}
\]

\[
\binom{k+\kappa-1}{\kappa-1}\ge r
\qquad
\text{HMM 的连续观测窗口条件}
\]
