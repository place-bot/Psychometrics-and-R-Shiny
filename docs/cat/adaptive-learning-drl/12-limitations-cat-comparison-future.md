# 局限、CAT 接口与未来工作

## 1. 这篇论文与 CAT 的根本区别

两类系统都逐步决策，但动作改变的对象不同。

### 自适应学习

\[
\boldsymbol\theta_{t+1}
\sim
\mathcal P(
\cdot
\mid
\boldsymbol\theta_t,
a_t^{\text{material}}
).
\]

教学动作旨在改变真实能力。

### CAT

经典 CAT 常假设短测期间能力近似固定：

\[
\boldsymbol\theta_{t+1}
\approx
\boldsymbol\theta_t.
\]

题目 \(q_t\) 改变的是系统对能力的知识：

\[
p(\boldsymbol\theta\mid H_{t+1})
\propto
p(y_t\mid q_t,\boldsymbol\theta)
p(\boldsymbol\theta\mid H_t).
\]

因此：

- 自适应学习的环境状态发生教育性变化；
- CAT 的信息状态发生测量性变化。

## 2. 两层闭环怎样组合

一个完整智能学习系统可以写成：

```text
材料策略 π_material
    │ 选择学习材料
    ▼
学生真实能力发生变化
    │
    ▼
CAT 策略 π_item 逐题测量
    │ 估计新能力及不确定性
    ▼
材料策略再次决策
```

两层应分别评价：

| 层 | 主要目标 | 常见指标 |
|---|---|---|
| CAT 测量层 | 少题、准确估计 | bias、RMSE、coverage、长度 |
| 学习推荐层 | 有效、快速成长 | 学习增益、达标时间、负荷、退出 |

测量层的高准确率无法单独证明教学策略有效；教学策略的高模拟 reward 也无法证明能力估计无偏。

## 3. 与 NCAT 的比较

| 项目 | 本文 | NCAT |
|---|---|---|
| 状态 | 连续能力点估计 | 已选题及答对/答错历史 |
| 动作 | 学习材料 | 测试题 |
| reward | 未达标每步 \(-1\) | held-out query 预测损失的相反数 |
| 终点 | 能力达到目标 | 固定或给定测试长度 |
| 转移 | 学习造成能力变化 | 新作答写入历史 |
| 数据 | 人工模拟学生 | 真实历史作答日志 |
| 网络 | MLP DQN | 双通道 attention Q 网络 |

共同点是每一步都根据新反馈重新计算动作。两者学习的 Q 值语义不同。

## 4. 与 BOBCAT 的比较

| 项目 | 本文 | BOBCAT |
|---|---|---|
| 决策对象 | 学习材料 | 测试题 |
| 学习算法 | DQN 与 TD | 双层优化与 meta-gradient |
| 外部评价 | 到达目标的步数 | meta 题预测损失 |
| 学生参数 | 作为状态输入 | 内层适应得到局部参数 |
| 环境模型 | 可学习转移模型 | 历史反应矩阵提供选题反馈 |

BOBCAT 和 NCAT 的目标聚焦“测得准”；本文聚焦“学得快”。

## 5. 点估计状态的局限

论文状态为：

\[
s_t=\widehat{\boldsymbol\theta}_t.
\]

两个点估计相同的学生可能具有：

- 不同后验方差；
- 不同最近材料历史；
- 不同疲劳与动机；
- 不同先修知识结构。

这些差异会影响下一材料的收益。可扩展为：

\[
s_t
=
\left(
\widehat{\boldsymbol\theta}_t,
\operatorname{Cov}(\boldsymbol\theta_t\mid H_t),
h_t,
f_t
\right).
\tag{1}
\]

## 6. POMDP 表达

真实潜在能力不可直接观察时，可定义：

- 隐状态 \(S_t=\boldsymbol\theta_t\)；
- 动作 \(A_t\) 为学习材料；
- 观测 \(O_t\) 为作答、反应时与行为；
- 观测模型 \(\mathcal Z(o_t\mid s_t)\)；
- belief \(b_t(s)=\Pr(S_t=s\mid H_t)\)。

策略使用 belief：

\[
a_t=\pi(b_t).
\tag{2}
\]

作者在结论中明确把 POMDP 列为未来研究方向。

## 7. 不退步假设

\[
\theta_d^{(t+1)}
\ge
\theta_d^{(t)}
\]

简化了模拟，也排除了：

- 遗忘；
- 疲劳；
- 干扰；
- 长时间间隔；
- 测量回归。

可用带时间间隔的转移：

\[
\boldsymbol\theta_{t+1}
\sim
\mathcal P(
\cdot
\mid
\boldsymbol\theta_t,
a_t,
\Delta t_t
).
\tag{3}
\]

## 8. 群体同质性

论文将一组学习者视为共享同一个 MDP。现实中材料效应可受：

- 先前课程；
- 年龄与语言；
- 学习策略；
- 障碍与无障碍需求；
- 兴趣和偏好；
- 教师支持。

作者提出先将学习者分组，再为各组学习策略。更灵活的方案是层级转移模型或带个体 embedding 的策略。

## 9. 转移模型误差

一步预测指标：

\[
R^2,\quad\operatorname{RMSE}
\]

主要评价局部拟合。策略关心长轨迹和动作排序。还应评价：

- \(k\)-步 rollout error；
- policy value error；
- 动作条件校准；
- 不确定性覆盖；
- 分布外状态检测。

## 10. 只使用模拟数据

论文的两项实验均基于人工 Beta 转移。结果证明算法在该环境可行，尚缺：

- 真实日志外部验证；
- 在线学习增益；
- 教师和学生可接受性；
- 教育副作用；
- 长期保持与迁移。

作者把真实在线学习平台研究列为首要未来方向。

## 11. 奖励目标较窄

每步 \(-1\) 优化材料轮数。现实中一轮可能是 5 分钟练习，也可能是 90 分钟课程。更直接的时间成本为：

\[
r_t=-\operatorname{minutes}(a_t).
\tag{4}
\]

多目标版本可加入：

\[
r_t
=
-\text{time}
-\lambda_1\text{load}
-\lambda_2\text{dropout risk}
+\lambda_3\text{retention}.
\tag{5}
\]

权重需要教育价值判断与实证校准。

## 12. 离线日志与因果识别

历史日志中的材料由旧策略选择。观察到：

\[
(s_t,a_t,s_{t+1}),
\]

却看不到同一学生同一时刻选择其他材料的结果。转移模型学习的是有选择机制的数据。

需要检查：

\[
\mu(a\mid s)>0
\]

是否在目标策略会访问的状态动作区域成立。缺乏重叠时，神经网络只能外推。

后续方向包括：

- 保守离线 RL；
- 因果动态治疗规则；
- doubly robust off-policy evaluation；
- 随机探索或微随机试验；
- 教师约束下的安全策略改进。

## 13. 偏好与教育效用

论文结论提出将协同过滤、矩阵分解等推荐方法与 DRL 结合。可将价值拆成：

\[
Q_{\text{total}}
=
Q_{\text{learning}}
+\lambda Q_{\text{preference}}.
\tag{6}
\]

偏好有助于参与和坚持，但高偏好不一定带来高学习增益。多目标设计应同时报告二者。

## 14. 作者提出的未来工作

论文列出：

1. 在真实在线学习平台评价；
2. 直接从反应历史建模学习过程，减少独立能力估计器；
3. 先对学习者分组，再学习群组策略；
4. 融合协同过滤和矩阵分解，兼顾最优与偏好；
5. 在更多场景与约束下比较 DQN、启发式和随机策略；
6. 建立 POMDP；
7. 把已建模的学习路径纳入历史状态。

## 15. 面向生成式推荐的接口

生成模型可以提出候选学习路径或新材料组合，但实时系统仍需闭环执行：

\[
a_t
\sim
\pi_\phi(
\cdot
\mid
H_t,
\text{constraints}
),
\]

\[
H_{t+1}
=
H_t\cup
\{\text{本轮学习与测量反馈}\}.
\]

生成模型更适合承担：

- 状态编码；
- 候选动作生成；
- 长期计划草案；
- 内容语义与先修关系建模。

每轮反馈后的重新规划保证适应性。一次生成固定长序列时，应设计中途重规划点。

## 16. 对 CAT 研究的启发

这篇论文说明了序列推荐的关键对象是**策略函数**：

\[
\pi(\text{当前状态})\rightarrow\text{下一动作},
\]

而固定序列只是策略在某条反馈轨迹上的展开。

对生成式 CAT，可研究：

1. 模型生成下一题或候选题集合；
2. 作答后更新能力 posterior 与内容状态；
3. 每一步重新生成；
4. 用长期测量、内容平衡、曝光和公平性共同评价；
5. 用硬约束层保证每次动作可行。
