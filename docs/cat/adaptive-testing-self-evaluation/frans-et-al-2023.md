# Frans 等人（2023）：临床多级计分 CAT 中经验先验的收益与风险

## 文献身份

> Frans, N., Braeken, J., Veldkamp, B. P., & Paap, M. C. S. (2023). Empirical priors in polytomous computerized adaptive tests: Risks and rewards in clinical settings. *Applied Psychological Measurement, 47*(1), 48–63. [DOI](https://doi.org/10.1177/01466216221124091)

- 研究类型：两项固定精度计算机化自适应测验（Computerized Adaptive Testing, CAT）模拟研究
- 应用场景：临床患者报告结局与人格功能结构化访谈
- 题目模型：五级计分的分级反应模型（Graded Response Model, GRM）
- 能力估计：最大后验估计（Maximum A Posteriori, MAP）
- 选题规则：在当前 MAP 位置选择 Fisher 信息量最大的题
- 停止规则：\(SE(\widehat\theta_p)\leq 0.316\)，约对应局部信度 \(0.90\)
- 核心操纵：先验均值偏差与先验方差，以及最少施测题数

!!! abstract "一句话结论"
    正确而精确的个体化先验可以缩短固定精度临床 CAT；但真正带来题量收益的是较小的先验方差，而不仅是更合适的先验均值。先验越窄，一旦均值错了，就越可能出现“测得很久仍不收敛”或“很快停止但结果严重偏差”这两类失败。

!!! danger "本专题必须记住的反例"
    达到后验标准误阈值只说明模型内部认为估计已经精确，并不保证估计接近真实能力。如果一个错误先验很窄，CAT 可能只施测少量题目就停止；此时后验方差很小，但后验中心仍可能严重错误。

## 1. 为什么这篇与我们的研究直接相关

前几篇文献分别说明：辅助变量可以构造经验先验，经验先验可以持续进入逐题估计，而且受测者自己产生的信息也可以形成 prior。Frans 等人进一步追问一个更危险的问题：

> 如果个体化先验不是完全正确的，固定精度 CAT 会发生什么？

这篇论文与我们的方案有四个直接交点：

1. prior 同时影响当前能力估计和实际选题路径；
2. 使用与标准 CAT 相同的精度停止规则，可以直接比较题量；
3. 将先验方差设为 \(1.00\)、\(0.50\) 和 \(0.25\)，与我们准备操纵先验强度的设计非常接近；
4. 系统改变先验均值相对真实能力的偏差，直接展示自评错误时的风险。

它不研究受测者自评，也不研究只改变第一题。第一项研究中的“个体化 prior”是由真实 \(\theta\) 加上人为设定的偏差构造的，属于受控的 oracle 模拟；第二项研究则使用临床医生在正式访谈前给出的 global score 来模拟更现实的辅助信息。

## 2. 为什么先验方差会同时影响估计、选题和停止

对受测者 \(p\)，个体化正态先验写成：

\[
\theta_p\sim N(\mu_p,\sigma_p^2).
\]

其中：

- \(\mu_p\) 是辅助信息给出的初始位置；
- \(\sigma_p^2\) 表示该信息的不确定性；
- \(1/\sigma_p^2\) 是先验精度。

结合已观察到的逐题反应 \(\mathbf u_{p,1:t}\)，后验为：

\[
p(\theta_p\mid \mathbf u_{p,1:t})
\propto
\left[
\prod_{s=1}^{t}
P(U_{p i_s}=u_{p i_s}\mid\theta_p)
\right]
\phi(\theta_p;\mu_p,\sigma_p^2).
\]

论文使用后验众数作为当前能力估计：

\[
\widehat\theta_{p,t}^{\mathrm{MAP}}
=
\arg\max_{\theta}
p(\theta\mid \mathbf u_{p,1:t}).
\]

随后选择在该位置 Fisher 信息量最大的剩余题：

\[
i_{t+1}
=
\arg\max_{i\in\mathcal R_t}
I_i(\widehat\theta_{p,t}^{\mathrm{MAP}}).
\]

所以即使选题公式本身不变，改变 prior 仍会改变：

\[
\text{当前 MAP}
\longrightarrow
\text{下一题}
\longrightarrow
\text{新作答证据}
\longrightarrow
\text{后续整条路径}.
\]

### 先验为什么能让 CAT 更快停止

在后验近似正态的局部近似下：

\[
\operatorname{Var}(\theta_p\mid \mathbf u_{p,1:t})
\approx
\frac{1}{\sigma_p^{-2}+I_t(\theta_p)},
\]

其中 \(I_t\) 是已经施测题目提供的累计信息。先验越窄，\(\sigma_p^{-2}\) 越大，达到相同后验方差阈值所需的题目信息就越少。

这也解释了风险：停止规则把先验精度和题目证据一起计算。如果先验很精确但均值错误，系统仍可能以很小的后验标准误停止。

!!! note "为什么论文没有把先验方差设得更小"
    停止阈值对应的方差约为 \(0.316^2=0.0999\)。作者把最小先验方差设为 \(0.25\)，明确说明这是为了避免 CAT 在施测任何题目之前就已经满足停止条件。若我们的模拟要使用 \(\tau^2=0.10\)，它几乎恰好落在停止边界上，必须明确规定至少施测一题，或只在完成首题以后才检查停止规则。

## 3. 模拟研究一：把先验偏差和先验精度拆开

### 3.1 题库怎样生成

作者依据患者报告结局测量信息系统（Patient-Reported Outcomes Measurement Information System, PROMIS）题库的经验特征，分别模拟：

\[
100\text{ 个 }N=30\text{ 题库},
\qquad
100\text{ 个 }N=60\text{ 题库}.
\]

每道题有五个作答等级，并使用 GRM 标定。生成参数为：

- 第四个类别阈值来自均值 \(2.2\)、方差 \(0.16\) 的正态分布；
- 向其他阈值的逐级距离来自均值 \(0.75\)、方差 \(1.44\) 的对数正态分布；
- 区分度来自位置参数 \(3.5\)、尺度参数 \(1.0\) 的截断正态分布，限制在 \([1.5,5]\)。

平均题库信息在：

\[
\theta\approx1.1
\]

处最高。这符合临床题库主要在较高病理程度区域提供信息的特点。

### 3.2 受测者与完整反应数据

真实能力位于九个网格点：

\[
\theta_p\in
\{-1,-0.5,0,0.5,1,1.5,2,2.5,3\}.
\]

每个网格点模拟 100 人，因此每个题库共有：

\[
900\text{ 名模拟受测者}.
\]

作者先为每人生成对题库所有题目的完整反应，再让不同 prior 条件从同一组潜在作答中取题。这种受测者内比较减少了随机作答差异对条件比较的干扰。

### 3.3 三类先验

#### 默认标准正态先验

\[
\theta_p\sim N(0,1).
\]

#### 一般临床人群先验

\[
\theta_p\sim N(1,1).
\]

它的中心更接近题库信息量最高的位置。

#### 个体化先验

\[
\theta_p\sim N(\mu_p,\sigma_p^2),
\qquad
\mu_p=\theta_p+\operatorname{bias}_0.
\]

作者正交操纵：

\[
\operatorname{bias}_0
\in\{-2,-1,0,1,2\},
\]

以及：

\[
\sigma_p^2
\in\{1.00,0.50,0.25\}.
\]

这个设计把两个问题分开：

- prior 的中心是否正确；
- 系统对这个中心有多自信。

### 3.4 CAT 的共同规则

所有条件都使用相同的：

- 第一题选择：在 prior 均值处信息量最大；
- 后续选题：在当前 MAP 处信息量最大；
- 停止标准：\(SE(\widehat\theta_p)\leq0.316\)；
- 最少题数：分别设为 1、2、3 或 4 题。

因此，不同条件的题量差异主要来自 prior 对估计路径和累计精度的影响，而不是不同的停止门槛。

### 3.5 评价指标

作者报告：

1. 是否在耗尽题库前达到目标精度；
2. 绝对题量；
3. 相对题量：

\[
\frac{n_p^{(\mathrm{personalized})}}
{n_p^{(\mathrm{generic})}};
\]

4. 估计偏差：

\[
\operatorname{BIAS}(\widehat\theta_p)
=
\widehat\theta_p-\theta_p;
\]

5. 个体化 prior 与一般 prior 的绝对偏差差异。

## 4. 模拟研究一的结果

### 4.1 题库耗尽集中在“极端能力 + 同方向错误 prior”

对于 60 题题库，超过 \(99.9\%\) 的 CAT 达到目标精度。

对于 30 题题库，\(2.3\%\) 的 CAT 耗尽题库仍未达到目标；其中 \(89.8\%\) 出现在个体化 prior 条件。典型极端情形是：

\[
\theta_p=3,
\qquad
\operatorname{bias}_0=2,
\qquad
\mu_p=5.
\]

题库在 \(\theta=5\) 附近几乎没有足够信息。错误 prior 把估计和选题送入题库的信息尾部，CAT 需要很多题才能纠正，甚至把题全部用完。

### 4.2 仅把 prior 均值移到正确位置，并没有明显缩短测验

默认 \(N(0,1)\) prior 的平均题量为：

- 60 题库：2.6 题；
- 30 题库：2.9 题。

临床 \(N(1,1)\) prior 的平均题量为：

- 60 题库：2.8 题；
- 30 题库：3.1 题。

图 1 最关键的结果是：当个体化 prior 的均值完全正确、但方差仍为 \(1\) 时，相比标准正态 prior，题量并没有明显下降。

这说明：

> “起点更接近真实能力”与“固定精度 CAT 更早停止”不是同一件事。

前者主要减少走到合适难度区域的路程；后者还要求 prior 本身贡献足够多的精度。

### 4.3 真正的题量收益主要来自更小的先验方差

在 prior 均值无偏时，把方差从 \(1.00\) 减至 \(0.25\)，平均题量约缩短为原来的：

\[
\frac{1}{1.3}\approx0.77,
\]

即约减少 \(23\%\)。论文在讨论中将它概括为约 \(30\%\) 的题量下降。

这里应区分两种表述：原文结果部分说“缩短因子为 1.3”；严格换算成相对原长度的降幅约为 \(1-1/1.3\approx23\%\)。讨论部分使用的是较宽松的“30% reduction”概括。

### 4.4 prior 错误时，短测验不一定是好消息

当错误 prior 把起始估计推向题库信息不足的尾部时：

\[
\text{题目信息少}
\longrightarrow
\text{后验精度增长慢}
\longrightarrow
\text{测验变长或题库耗尽}.
\]

但当错误 prior 恰好把起始估计推向题库信息丰富的区域时：

\[
\text{题目信息多 + prior 很窄}
\longrightarrow
\text{很快达到停止阈值}
\longrightarrow
\text{没有足够作答纠正错误 prior}.
\]

于是会出现一种比“测验变长”更隐蔽的失败：**题量很短，但最终估计严重偏差。**

作者也观察到，估计偏差特别大的条件往往正是题量相对较短的条件。

### 4.5 无偏与有偏 prior 的估计结果

默认标准正态 prior 的平均估计偏差为：

\[
-0.09,
\]

论文正文把不同能力点的范围写成 \(-0.34\) 至 \(-0.13\)，但这与平均值 \(-0.09\) 在算术上不相容；第二个端点很可能存在符号或排印错误。可以安全保留的结论是：默认 prior 会使估计向中心 0 收缩，远离 0 的能力点偏差更明显；不宜未经原始结果核对就引用该范围。

临床 \(N(1,1)\) prior 的平均偏差为 \(0.00\)，不同能力点约在 \(-0.23\) 至 \(0.22\) 之间。

均值等于真实 \(\theta\) 的个体化 prior 几乎无偏，范围约为：

\[
-0.03\text{ 至 }0.02.
\]

但是，一旦 prior 均值有偏，方差越小，最终估计越强烈地被错误中心拉住。

## 5. 最少题数能不能解决问题

### 5.1 它确实降低偏差

表 1 把无最少题数限制与至少施测 2、3、4 题进行比较。以下个体化 prior 结果只汇总无偏条件，并跨三个先验方差聚合：

| 最少题数 | 默认 \(N(0,1)\)：平均题量 / 绝对偏差 | 临床 \(N(1,1)\)：平均题量 / 绝对偏差 | 无偏个体化 prior：平均题量 / 绝对偏差 |
|---:|---:|---:|---:|
| 1 | 2.61 / 0.132 | 2.84 / 0.112 | 2.26 / 0.012 |
| 2 | 2.61 / 0.132 | 2.84 / 0.112 | 2.38 / 0.009 |
| 3 | 3.26 / 0.104 | 3.45 / 0.090 | 3.21 / 0.004 |
| 4 | 4.13 / 0.080 | 4.26 / 0.071 | 4.15 / 0.003 |

随着最少题数增加，三种 prior 的题量和偏差差异都缩小。至少四题时，无偏个体化 prior 的题量优势基本消失。

### 5.2 它不能完全挽救很窄且严重错误的 prior

即使强制至少施测四题，表 2 中仍出现：

| prior 均值偏差 | 方差 \(1.00\)：绝对偏差 | 方差 \(0.50\)：绝对偏差 | 方差 \(0.25\)：绝对偏差 |
|---:|---:|---:|---:|
| \(-2\) | 0.111 | 0.216 | 0.403 |
| \(-1\) | 0.051 | 0.100 | 0.188 |
| \(0\) | 0.004 | 0.003 | 0.004 |
| \(1\) | 0.054 | 0.102 | 0.190 |
| \(2\) | 0.113 | 0.223 | 0.411 |

因此，至少四题是一个安全阀，却不是错误 prior 的完整修复方案。降低先验精度也能降低风险，但同样会消除大部分题量收益。

!!! warning "论文揭示的结构性权衡"
    个体化 prior 的效率收益和错误 prior 的危害都来自同一个来源：系统对辅助信息给予了多大权重。让 prior 更宽、强制更多题，都会增强稳健性；但这些保护措施也会削弱缩短测验的效果。

## 6. 模拟研究二：更现实的临床 global score

### 6.1 辅助信息是什么

第二项研究基于一项测量人格功能受损的结构化临床访谈。正式访谈前，临床医生通过若干筛查问题给出 0 至 4 的 global score，用来指导后续问题。

由于数据保护限制，作者没有直接使用真实患者反应，而是依据既有临床研究中的关系进行模拟。

### 6.2 题库与受测者

- 题库：12 道五级计分题；
- GRM 区分度范围：\(2.03\) 至 \(3.03\)，平均 \(2.47\)；
- 模拟受测者：\(N=5{,}000\)；
- 真实能力：\(\theta_p\sim N(0,1)\)；
- 题库能够在约 \([-1.96,2.64]\) 范围内支持目标精度。

### 6.3 global score 怎样变成 prior

作者先根据真实 \(\theta\) 四舍五入后的整数值，按照既有临床样本的条件频数模拟 global score，再为每个分数指定一个正态 prior：

| Global score | 期望人数 | prior 均值 \(\mu_p\) | prior 方差 \(\sigma_p^2\) |
|---:|---:|---:|---:|
| 0 | 105 | \(-2.4\) | 0.640 |
| 1 | 1,046 | \(-1.0\) | 0.359 |
| 2 | 2,343 | \(0.0\) | 0.339 |
| 3 | 1,464 | \(0.9\) | 0.597 |
| 4 | 42 | \(2.5\) | 0.250 |

因此，global score 同时决定 prior 的位置和强度。分数 1、2 和 4 对应较精确的 prior；分数 0 和 3 对应较宽的 prior。

比较条件只有：

\[
N(0,1)
\quad\text{vs.}\quad
N(\mu_{g_p},\sigma_{g_p}^2).
\]

两者使用相同的 MAP、最大信息量选题和固定精度停止规则；第二项研究没有再设置最少题数。

## 7. 模拟研究二的结果

### 7.1 达到目标精度

默认 prior 条件中：

- \(98\%\) 达到目标精度；
- 104 人耗尽 12 题仍未达到停止标准。

经验 prior 条件中：

- \(99\%\) 达到目标精度；
- 56 人耗尽题库；
- 其中 50 人也在默认 prior 条件下失败；
- 额外的 6 人都属于 global score 0，平均真实能力为 \(-2.7\)，范围为 \([-3.6,-1.8]\)。

分数 0 对应的 prior 中心是 \(-2.4\)，已接近或超出题库低端的信息支持范围，因此这一小组再次出现“prior 把 CAT 送往低信息区域”的问题。

### 7.2 题量

两种条件的题量范围均为 3 至 12 题，总体中位数为 5 题。

与默认 prior 相比，经验 prior 条件：

- \(68\%\) 的受测者题量更短；
- \(29\%\) 题量相同；
- \(3\%\) 题量更长。

个体差异从“多做 6 题”到“少做 8 题”。中位题量下降为：

\[
20\%=1\text{ 道题}.
\]

题量收益主要出现在 prior 较精确的 global score 1、2 和 4；分数 0 与 3 因 prior 较宽，收益较小。另有 5 名分数 0 的受测者在经验 prior 下明显变长。

### 7.3 估计偏差没有整体改善

默认 prior 条件：

\[
\operatorname{BIAS}\in[-1.10,1.22],
\qquad
\operatorname{median}=0.00,
\qquad
MAD=0.21.
\]

经验 prior 条件：

\[
\operatorname{BIAS}\in[-1.16,1.32],
\qquad
\operatorname{median}=-0.02,
\qquad
MAD=0.30.
\]

在 5,000 人中，经验 prior 对 \(51\%\) 的人产生更小的绝对偏差，默认 prior 对另外 \(49\%\) 更好。两条件绝对偏差差异的中位数为 0。

因此作者的准确结论是：经验 prior 在总体偏差近似不变的情况下，通常缩短了题量。不能把它写成“经验 prior 同时普遍提高准确性”。

## 8. 两项模拟合起来告诉了我们什么

| prior 情形 | 常见路径 | 表面结果 | 真正风险或收益 |
|---|---|---|---|
| 均值正确、方差较大 | 选题位置较好，但 prior 提供的精度有限 | 题量未必明显缩短 | 安全但收益小 |
| 均值正确、方差较小 | 很快积累到停止精度 | 题量明显缩短 | 理想收益 |
| 均值错误、指向低信息区 | 先选到不匹配或低信息题 | 测验很长、可能题库耗尽 | 易被发现的失败 |
| 均值错误、指向高信息区 | prior 和局部题目让后验迅速变窄 | 测验很短 | 隐蔽的严重偏差与过早停止 |

这张表解释了为什么不能只把“平均题量下降”当作方法成功。至少还要同时看：

- 最终偏差与均方根误差（root mean square error, RMSE）；
- 覆盖率；
- 错误 prior 条件下的过早停止率；
- 题库耗尽率与题量上尾；
- 按 prior 误差方向和题库信息区域分层的结果。

## 9. 证据边界：这篇没有证明什么

### 9.1 第一项研究的个体化 prior 是理想化构造

\[
\mu_p=\theta_p+\operatorname{bias}_0
\]

直接使用真实能力构造 prior。它非常适合识别机制，却不能证明现实中的自评、背景变量或临床判断可以达到相同质量。

### 9.2 第二项研究仍然不是实际患者 CAT 实验

global score 与 \(\theta\) 的关系来自既有临床数据，但作答、分数与 CAT 都是模拟的。论文不能据此声称患者真实施测中一定减少 20% 题量。

### 9.3 它没有研究受测者自评

第二项研究的信息来源是临床医生在正式访谈前给出的评分，不是受测者选择难度或报告自己的症状等级。它支持“带误差的辅助信息进入 prior”的方法论，却不是 self-evaluation 的行为证据。

### 9.4 它没有比较只改第一题

经验 prior 持续进入 MAP 估计，因此持续影响每一步选题和最终停止。它不能回答：如果 prior 只决定第一题、第一题后恢复标准正态估计，收益和风险会怎样变化。

### 9.5 评价指标仍不完整

论文重点报告题量、估计偏差和题库耗尽，没有系统报告：

- RMSE；
- 区间覆盖率；
- “标准误达标但绝对误差很大”的频率；
- 题目曝光与受测者之间的 test overlap；
- 不同群体的公平性。

这些正是我们的实验应补充的指标。

## 10. 对我们“自评进入 CAT”实验的直接启示

### 10.1 把先验位置和先验强度做成独立因素

不能只模拟“自评准确率”。更清晰的消融是：

\[
\mu_p=\theta_p+\delta_p,
\qquad
\delta_p\in\{0,\pm0.5,\pm1,\pm2\},
\]

并独立设置：

\[
\tau^2\in\{1,0.5,0.25,0.1\}.
\]

这样才能回答：同样的自评误差，在系统“相信程度”不同时会造成什么后果。

### 10.2 \(\tau^2=0.1\) 需要特殊处理

如果停止条件也是：

\[
\operatorname{Var}(\theta\mid\mathbf u)
\leq0.1,
\]

那么 \(\tau^2=0.1\) 的 prior 在尚无作答时已经接近达标。实验必须规定：

- 至少施测 1、2 或 3 题；或
- 第一道题后才允许检查停止；或
- 停止精度只计算题目提供的增量证据，而不是直接把 prior 方差当作完成测量的证据。

第三种会改变传统贝叶斯 stopping rule 的含义，需要单独论证，不能悄悄实施。

### 10.3 至少做四个基础条件

为了区分“改变估计”和“改变开头选题”的作用，可以保留四个基础条件：

| 条件 | 估计 prior | 首题/早期选题 |
|---|---|---|
| A 标准 CAT | \(N(0,1)\) | 当前估计处最大信息量 |
| B 仅个体化估计 | \(N(\mu_s,\tau_s^2)\) | 当前个体化后验处最大信息量 |
| C 仅自评路由 | \(N(0,1)\) | 先在自评对应的 \(b\) 区间抽题，再恢复标准 CAT |
| D 完整方法 | \(N(\mu_s,\tau_s^2)\) | 自评路由或按不确定性控制 \(a\) 层 |

其中 B 正是 Frans 等人所属的主要方法类别；C 与 D 才能识别我们额外设计的题目路由是否有独立贡献。

### 10.4 不能只报告平均题量

建议至少同时报告：

1. 平均题量、中位题量与 95% 题量分位数；
2. bias、绝对 bias、RMSE 和覆盖率；
3. 停止时 \(|\widehat\theta-\theta|\) 仍超过预设界值的比例；
4. 题库耗尽率；
5. prior 与早期作答冲突时的恢复题数；
6. 总体及按真实 \(\theta\)、自评等级分组的题目曝光；
7. test overlap。

### 10.5 安全机制也要逐步消融

可以依次增加：

1. 无保护的个体化 prior；
2. 最少题数约束；
3. 发现自评与早期作答冲突时扩大 prior 方差；
4. prior tempering，使辅助信息权重随题目证据逐步衰减；
5. 混合先验，例如：

\[
p_0(\theta\mid s)
=
\lambda N(\mu_s,\tau_s^2)
+
(1-\lambda)N(0,1).
\]

Frans 等人只检验了前两种保护思路中的固定最少题数与统一放宽先验。动态冲突检测、稳健混合 prior、只改变第一题及曝光控制仍是可以发展的部分。

## 11. 可以安全引用的中文转述

### 支持“经验先验可能缩短临床 CAT”

> Frans 等人（2023）的临床 CAT 模拟显示，在更现实的 global-score 条件下，经验先验使 68% 的受测者获得更短测验，中位题量减少 20%（1 题），而总体估计偏差与标准正态先验条件近似相当。

### 支持“先验精度是收益和风险的共同来源”

> Frans 等人（2023）发现，无偏个体化先验在方差仍为 1 时并未明显缩短固定精度 CAT；题量收益主要出现在先验方差更小时。但先验越精确，其均值错误所造成的最终估计偏差也越严重。

### 支持“最少题数是有代价的安全阀”

> 强制施测最少题数能够降低错误 prior 导致的偏差，但也会缩小甚至消除个体化 prior 的题量优势；因此稳健性与效率不能被当作两个彼此独立的目标。

### 不能这样引用

- 不能写成“经验先验总能同时缩短测验并提高准确性”；
- 不能写成“受测者自评已被证明可以安全形成临床 CAT prior”；
- 不能把模拟研究二的 20% 题量下降当作实际患者随机试验结果；
- 不能用达到 \(SE\leq0.316\) 证明估计一定准确无偏。

## 12. 关键参考文献及其作用

- **Bock & Mislevy（1982）**：CAT 中 Bayesian EAP/MAP 能力估计的经典依据。
- **van der Linden（1999）**：用辅助变量经验初始化潜在能力估计。
- **Matteucci & Veldkamp（2013）**：教育情境固定精度 CAT 中个体化经验 prior 的效率收益，是本文直接扩展和质疑的理想化基线。
- **Reise & Waller（2009）**：临床量表题库通常较小、题目区分度较高且集中测量病理区间的背景依据。
- **Babcock & Weiss（2012）**：固定精度 CAT 设置最少题数以防过早停止的依据。
- **Hummelen 等人（2021）**：模拟研究二的临床结构化访谈、题库和 global score 关系来源。
- **Paap 等人（2019）**：模拟研究一构造 PROMIS 风格多级题库时参考的题库特征。

## 13. 精读结论

这篇论文把本专题从“经验先验有没有收益”推进到了“收益以什么风险为代价”。最关键的结论不是一个平均缩短百分比，而是下面这条因果链：

\[
\text{更窄的 prior}
\longrightarrow
\text{更强收缩与更快达到后验精度}
\longrightarrow
\begin{cases}
\text{prior 正确：题量收益},\\
\text{prior 错误：偏差、过早停止或题库耗尽}.
\end{cases}
\]

因此，对我们的自评 CAT，真正的方法问题不是“要不要相信用户”，而是：**如何把自评可靠性转化为恰当的 prior 方差，并在早期作答与自评冲突时让系统及时撤回这种信任。**
