# Matteucci 与 Veldkamp（2009）：经验先验如何同时改变 CAT 估计与选题路径

## 文献身份

> Matteucci, M., & Veldkamp, B. P. (2009). *Computer Adaptive Testing with Empirical Prior Information: A Gibbs Sampler Approach for Ability Estimation*. [论文全文](https://amsacta.unibo.it/id/eprint/2659/1/matteucci_veldkamp_CAT_2009.pdf)

- 研究类型：方法论文与 Monte Carlo 模拟研究
- 反应模型：单维二参数正态卵形模型（two-parameter normal-ogive model, 2PNO）
- 核心方法：用背景变量构造个体化正态先验，再用 Gibbs sampler 完成逐题与最终能力估计
- 选题规则：始终使用当前能力估计处的最大信息量规则
- 重要限定：背景变量是模拟生成的协变量，不是受测者自评；测验全部采用固定长度

!!! abstract "一句话结论"
    这篇论文已经实现了“个体化 prior 同时进入初始化和逐题能力估计，并通过更新后的能力估计改变后续最大信息量选题路径”。在正确指定且预测力较强的先验下，它对 5 题短测验和极端能力尤其有利；但论文没有检验错误自评、先验方差敏感性、可变长度停止或题目曝光，因此不能据此断言真实自评一定能够缩短 CAT。

## 1. 它比 van der Linden（1999）多走了哪一步

[van der Linden（1999）](van-der-linden-1999.md)解决的是如何从“辅助变量 + 逐题反应”估计：

\[
\theta_i\mid X_i
\sim
N(X_i^\top\beta,\sigma^2).
\]

他的实际数据示例说明这一个体化条件分布可以被估计，但没有用它重新运行 CAT 并比较结果。

Matteucci 与 Veldkamp（2009）则把这个分布真正放进模拟 CAT：

1. 用条件均值初始化能力位置；
2. 在该位置选择第一题；
3. 每次作答后，用同一个个体化先验与当前作答似然更新能力；
4. 再在更新后的能力位置选择下一道最大信息量题；
5. 最终能力估计也保留这个先验。

因此，它已经不是“只改变第一题”的设计。即使最大信息量公式没有变化，进入公式的当前能力估计已经变化，实际题目序列也会随之改变。

| 问题 | van der Linden（1999） | Matteucci 与 Veldkamp（2009） |
|---|---|---|
| 个体化 prior 从哪里来 | 从真实逐题反应与辅助变量联合估计 | 在模拟中假定回归参数与先验方差已知 |
| 是否真正运行个体化 CAT | 否 | 是 |
| prior 是否进入逐题估计 | 提出两种可能用法 | 是，用 Gibbs sampler 更新 |
| 是否比较 CAT 表现 | 否 | 是，比较固定 5、10、15、20 题 |
| 是否检验错误 prior | 否 | 否 |

## 2. CAT 的反应模型与四个步骤

论文使用 2PNO。对题目 \(j\)：

\[
P(Y_j=1\mid\theta)
=
\Phi(\alpha_j\theta-\delta_j),
\]

其中：

- \(Y_j=1\) 表示答对；
- \(\alpha_j\) 是区分度；
- \(\delta_j\) 是难度参数；
- \(\Phi(\cdot)\) 是标准正态累积分布函数。

CAT 按照四步循环：

1. 初始化能力；
2. 选择题目；
3. 施测并记录反应；
4. 更新能力估计。

第 2 至第 4 步反复进行，直到达到停止规则。本文没有使用精度停止，而是分别固定为 5、10、15 或 20 题。

## 3. 背景变量怎样变成个体化 prior

作者假设能力与 \(P\) 个背景变量之间满足线性回归：

\[
\theta_i
=
\beta_0+\beta_1X_{i1}+\cdots+\beta_PX_{iP}+\varepsilon_i,
\qquad
\varepsilon_i\sim N(0,\sigma^2).
\]

于是：

\[
\theta_i\mid X_i
\sim
N(\mu_i,\sigma^2),
\qquad
\mu_i=X_i^\top\beta.
\]

这个条件分布承担两个角色。

### 角色一：初始化

对新受测者，初始能力设为：

\[
\widehat\theta_i^{(0)}=\mu_i=X_i^\top\widehat\beta.
\]

第一题在这个个体化位置选择，而不是所有人都从 \(0\) 开始。

### 角色二：逐题与最终估计

完整的：

\[
N(\mu_i,\sigma^2)
\]

被保留为 Bayesian prior。这里 \(\mu_i\) 决定先验中心，\(\sigma^2\) 决定系统应当多相信背景信息。

!!! important "为什么 prior 会自动改变选题"
    第 \(k\) 道题仍按当前能力估计处的最大信息量选择：

    \[
    j_k
    =
    \arg\max_{j\in R_k}
    I_j(\widehat\theta_{k-1}).
    \]

    个体化 prior 改变 \(\widehat\theta_{k-1}\)，所以即使 \(\arg\max I_j(\cdot)\) 这条规则原封不动，进入规则的能力位置与最终选出的题目也会改变。“没有修改选题公式”绝不等于“没有修改选题路径”。

## 4. Gibbs sampler 到底怎样更新能力

### 第一步：把二元反应写成潜在连续变量

2PNO 可通过数据增广表示。为每道已施测题引入潜在变量：

\[
Z_j\mid\theta
\sim
N(\alpha_j\theta-\delta_j,1),
\]

并令：

\[
Y_j=
\begin{cases}
1,&Z_j>0,\\
0,&Z_j\leq 0.
\end{cases}
\]

给定作答结果后，\(Z_j\) 的条件分布是截断正态：答对时截在 \(0\) 以上，答错时截在 \(0\) 以下。

### 第二步：给定 \(Z\) 时更新 \(\theta\)

由：

\[
Z_j+\delta_j
=
\alpha_j\theta+v_j,
\qquad
v_j\sim N(0,1),
\]

可以得到仅由当前作答贡献的正态似然：

\[
\theta\mid Z,\xi
\sim
N(\widehat\theta_L,v),
\]

其中：

\[
v
=
\left(\sum_{j\in S_k}\alpha_j^2\right)^{-1},
\qquad
\widehat\theta_L
=
\frac{
\sum_{j\in S_k}\alpha_j(Z_j+\delta_j)
}{
\sum_{j\in S_k}\alpha_j^2
}.
\]

再与个体化 prior：

\[
\theta\mid X_i\sim N(\mu_i,\sigma^2)
\]

结合，得到：

\[
\theta\mid Z,\xi,X_i
\sim
N(m_k,V_k),
\]

\[
V_k
=
\left(
\frac{1}{v}+
\frac{1}{\sigma^2}
\right)^{-1},
\qquad
m_k
=
V_k\left(
\frac{\widehat\theta_L}{v}
+
\frac{\mu_i}{\sigma^2}
\right).
\]

这个公式非常直观：后验均值是“作答证据”与“背景信息预测”的精度加权平均。

- 题目很少时，\(v\) 较大，prior 权重较高；
- 信息逐渐积累时，\(v\) 变小，作答证据权重增大；
- \(\sigma^2\) 越小，系统越相信背景信息；
- 如果 \(\mu_i\) 错得很远且 \(\sigma^2\) 又很小，错误 prior 也会更难被题目纠正。

### 第三步：交替抽样

每次能力更新时，算法交替执行：

1. 给定当前 \(\theta\) 和作答，从截断正态抽取所有 \(Z_j\)；
2. 给定 \(Z\)、题目参数和个体化 prior，从 \(N(m_k,V_k)\) 抽取新的 \(\theta\)；
3. 重复直到获得用于当前题后的能力后验样本。

题目参数 \(\xi\)、回归系数 \(\beta\) 与残差方差 \(\sigma^2\) 在 CAT 阶段全部视为已知，所以这里的 Gibbs sampler 只更新 \(Z\) 与 \(\theta\)。

!!! note "不要把 Gibbs sampler 当成效果来源"
    Gibbs sampler 是计算后验的工具。论文中经验条件优于标准条件的主要原因，是前者使用了与真实能力相关且正确指定的 prior；不是因为“MCMC 天生比其他能力估计方法更准确”。若用解析后验、数值积分或其他可靠 Bayesian 方法计算同一模型，也应得到相同目标后验。

## 5. 模拟怎样设置

| 设计要素 | 论文设置 |
|---|---|
| 题库 | 200 道二分题 |
| 区分度 | \(\alpha_j\sim U(0.7,2)\) |
| 难度参数 | \(\delta_j\sim U(-3,3)\) |
| 能力点 | \(-3,-2.5,-2,-1,0,1,2,2.5,3\) |
| 背景变量关系 | \(\theta=0.2+0.7X+\varepsilon\)，\(\varepsilon\sim N(0,0.3)\) |
| 测验长度 | 5、10、15、20 题 |
| 选题 | 两组均使用当前能力位置的最大信息量 |
| Gibbs chain | 5,000 次迭代，前 500 次作为 burn-in |
| 重复次数 | 每个条件 100 次 |
| 结果指标 | 后验均值、后验标准差、bias、均方根误差（root mean square error, RMSE） |

这是一个对经验先验有利的理想化模拟：生成数据所用的线性关系与分析时使用的先验模型一致，而且预测系数与先验方差被当作已知。论文没有模拟自评误差、回归失配、先验均值系统偏移或先验方差估错。

## 6. 三种比较条件分别改了什么

| 条件 | 初始能力 | 逐题与最终 prior | 最大信息量选题 |
|---|---|---|---|
| Standard | \(0\) | \(N(0,1)\) | 是 |
| Semi-empirical | \(\mu_i=X_i^\top\beta\) | 标准 prior，不继续使用背景信息 | 是 |
| Empirical | \(\mu_i=X_i^\top\beta\) | \(N(\mu_i,\sigma^2)\) | 是 |

第一项模拟只比较 Standard 与 Empirical，并改变固定题量。第二项固定为 5 题，再加入 Semi-empirical，用来区分“只改起点”与“让 prior 持续参与估计”。

这已经是一个很有用的消融，但并不是完整的 \(2\times2\) 因子设计。尤其没有单独设置“标准首题 + 个体化 prior”条件；也没有把先验均值准确性与先验方差分开操纵。

## 7. 不同题量下的主要结果

### 5 题：经验 prior 的优势最明显

下面摘取表 1 的三个代表性能力点：

| 真实 \(\theta\) | Empirical：估计 / bias / RMSE | Standard：估计 / bias / RMSE |
|---:|---:|---:|
| \(-3\) | \(-3.09/-0.09/0.42\) | \(-2.33/0.67/0.69\) |
| \(0\) | \(-0.08/-0.08/0.31\) | \(0.04/0.04/0.33\) |
| \(3\) | \(3.13/0.13/0.44\) | \(2.23/-0.77/0.78\) |

只有 5 题时，标准正态 prior 把极端能力明显向 \(0\) 拉回。正确的个体化 prior 能把中心移向个人真实位置，因此极端能力的 bias 和 RMSE 大幅下降。能力位于中心时，两种方法差别很小。

### 10 题：经验条件仍通常有较低 RMSE

作答信息增加后，Standard 的极端偏差明显缩小。Empirical 在多数能力点仍有更低 RMSE，但优势已经比 5 题时小。

### 15 与 20 题：先验优势减弱，bias 不再单向占优

随着题目增多，标准条件逐渐追上。作者也承认 Standard 在若干位置的 posterior mean 与 bias 会略优于 Empirical。

更重要的是，论文讨论部分声称 Empirical 的标准差和 RMSE 始终较好，但表 4 并不完全支持这一概括。例如 20 题时：

| 真实 \(\theta\) | Empirical RMSE | Standard RMSE | 更低者 |
|---:|---:|---:|---|
| \(-3\) | 0.38 | 0.27 | Standard |
| \(0\) | 0.15 | 0.16 | Empirical，差异很小 |
| \(3\) | 0.33 | 0.28 | Standard |

因此，最安全的总结是：**正确的经验先验在极短测验中优势明显；题量增加后优势缩小，且并非每个能力点和每个指标都保持占优。**

## 8. “只改起点”与“完整 prior”的消融结果

表 5 固定为 5 题，比较三种条件。以 RMSE 为例：

| 真实 \(\theta\) | Empirical | Semi-empirical | Standard |
|---:|---:|---:|---:|
| \(-3\) | 0.42 | 0.71 | 0.69 |
| \(0\) | 0.31 | 0.29 | 0.33 |
| \(3\) | 0.44 | 0.72 | 0.78 |

总体上，完整 Empirical 条件在远离 \(0\) 时最稳定；但 Semi-empirical 并非机械地处于另外两者之间：

- 在 \(\theta=-3\) 时，Semi-empirical 的 RMSE 甚至略高于 Standard；
- 在 \(\theta=0\) 时，Semi-empirical 的 RMSE 最低；
- 在 \(\theta=3\) 时，它才清楚地位于 Empirical 与 Standard 之间。

这并不推翻完整 prior 对极短测验的总体优势，却说明“只改起点一定产生居中的效果”不是逐点成立的规律。每个条件只有 100 次重复，部分小差异也可能包含 Monte Carlo 波动。

## 9. MCMC 收敛检查做了什么

作者在 \(\theta=0\)、5 题条件下比较 1,000、2,000、5,000 与 10,000 次迭代，并采用：

- trace plot；
- autocorrelation plot；
- Monte Carlo standard error；
- “Monte Carlo error 小于后验标准差的 5%”这一经验标准。

1,000 次迭代没有达到该标准；2,000 次勉强达到；5,000 和 10,000 次均满足。因此正式模拟采用 5,000 次迭代、500 次 burn-in。

这一部分只能说明所检查的简单单维条件下，5,000 次抽样的 Monte Carlo error 较小。它使用单条链、单个能力点和单一题量，没有报告多链 \(\widehat R\)、有效样本量或所有极端条件的诊断，所以不能被引用为“该算法在任何 CAT 中均已证明收敛”。

## 10. 论文真正证明了什么

论文直接支持：

1. 个体化经验 prior 可以同时用于 CAT 初始化、逐题估计和最终估计；
2. 先验改变当前能力估计后，即使选题仍用经典最大信息量规则，实际选题路径也会改变；
3. 在正确指定、预测力较强的 prior 下，5 题短测验和极端能力点可以获得明显的 bias 或 RMSE 改善；
4. 只在开头使用辅助信息，通常不如让辅助信息持续进入后验估计有效。

论文没有直接支持：

- 受测者自评能够准确产生这个 prior；
- 个体化 prior 会在同一精度停止规则下减少题量；
- 先验均值错误时算法仍然安全；
- 某个固定先验方差在不同人群中都合适；
- 经验初始化一定降低首题或总体曝光；
- Gibbs sampler 本身比 EAP、MAP 或数值积分更准确；
- 结果能够直接推广到多维、分级计分、内容约束或临床 CAT。

!!! warning "固定题长不能回答是否更早停止"
    四种测试长度是分别运行的固定长度条件，并不是同一场 CAT 根据后验标准误自行停止。因此本文只能比较“做完相同题数以后谁更准确”，不能比较“达到相同精度需要多少题”。

## 11. 对我们研究新颖性的诚实判断

这篇论文使下面的说法不能再作为新颖性：

> 首次让个体化先验同时影响 CAT 能力估计和实际选题路径。

因为本文已经通过：

\[
X_i
\longrightarrow
N(\mu_i,\sigma^2)
\longrightarrow
\widehat\theta_{i,k}
\longrightarrow
\arg\max_j I_j(\widehat\theta_{i,k})
\]

完成了这条链条。

但它仍给我们的研究留下了清楚空间：

| Matteucci 与 Veldkamp 没有研究 | 我们可以直接检验 |
|---|---|
| 背景变量不是自评或主动难度选择 | 自评等级究竟有多少真实信号 |
| prior 完全正确指定 | 均值偏移、分档错误与系统性高估/低估 |
| 先验方差基本固定 | \(\tau^2\in\{0.1,0.25,0.5,1\}\) 等敏感性分析 |
| 固定题长 | 在相同 posterior variance 或标准误阈值下比较题量 |
| 没有题目曝光结果 | 首题曝光、总体曝光、条件曝光与 test overlap |
| 从第一题起最大信息量，可能立即使用高 \(a\) 题 | prior 可靠性与 \(a\)-stratified 或 posterior-variance gating 的交互 |
| 没有单独控制 \(b\)-matching 候选集 | 在匹配 \(b\) 的题目集合内随机化或按 \(a\) 层选择 |

最有价值的问题不再是“prior 能否进入 CAT”，而是：

> 当 prior 来自可能出错的自评时，怎样同时控制先验强度、早期题目区分度和候选题随机化，使 CAT 在缩短题量的同时不增加偏差、错误提前停止和局部曝光？

## 12. 对后续消融设计的直接启示

最低限度应当保留以下三组，以复现本文的核心对照：

1. Standard：\(N(0,1)\) 初始化与更新；
2. Start-only：自评只改变初始位置，后续恢复标准估计；
3. Full prior：自评同时决定 \(\mu_i\) 与 \(\tau_i^2\)，并持续进入更新。

然后再逐步增加我们自己的机制：

4. Full prior + 起始候选集内随机化，用于分散首题曝光；
5. Full prior + 低 \(a\) 起步或基于后验方差的 \(a\) 层门控；
6. Full prior + 候选集随机化 + \(a\) 层门控。

所有方法应当使用同一题库、同一内容约束和同一 stopping rule，并同时报告：

- bias、RMSE 与区间覆盖率；
- 平均和尾部测验长度；
- 错误提前停止率；
- 总体及按真实能力、自评分组的条件曝光率；
- test overlap；
- 自评准确度与先验方差之间的交互。

## 13. 可以安全写进论文的中文转述

### 经验先验与实际选题路径

> 个体化经验先验即使不改变最大信息量选题公式，也会通过改变逐题能力估计而改变实际题目选择路径（Matteucci & Veldkamp, 2009）。

### 极短测验中的收益

> 在先验模型正确指定的模拟中，将辅助变量同时用于初始化和能力估计，主要改善了极短测验及极端能力位置的估计精度；随着题量增加，经验先验相对于标准先验的优势减弱（Matteucci & Veldkamp, 2009）。

### 只改起点与完整 prior

> 对 5 题 CAT 的模拟显示，只用辅助信息初始化通常不如让个体化先验持续进入逐题和最终能力估计；不过各能力点的逐项结果并非都呈严格的中间关系（Matteucci & Veldkamp, 2009）。

### 证据边界

> 该研究采用固定题长和正确指定的模拟先验，因而没有直接证明真实自评能够缩短可变长度 CAT，也没有评估错误先验与题目曝光风险（Matteucci & Veldkamp, 2009）。

## 14. 精读后的结论

这篇论文与本专题非常接近，但它回答的是一个理想条件下的问题：**如果我们已经拥有正确而有预测力的个体化 prior，让它持续进入 CAT 是否有利？**答案是在极短测验和极端能力处往往有利。

我们真正尚未解决的是更困难、也更现实的问题：**当 prior 来自受测者自己、可能偏差很大时，怎样控制它的强度，并怎样安排最前面的题，才能在效率、准确性和曝光之间取得可验证的平衡。**
