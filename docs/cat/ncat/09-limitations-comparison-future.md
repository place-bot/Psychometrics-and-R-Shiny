# 局限、方法比较与未来工作

## 1. NCAT、BOBCAT 与传统 CAT

| 维度 | 传统信息型 CAT | BOBCAT | NCAT |
|---|---|---|---|
| 选题依据 | Fisher/KL/后验方差等预设 criterion | meta question loss 的双层优化 | query loss reward 的长期 Q 值 |
| 决策频率 | 每答一题重新选择 | 每答一题重新运行策略 | 每答一题重新运行 Q 网络 |
| 学习来源 | 响应模型和人工推导 | 历史学生作答 | 历史学生作答 |
| 训练方法 | 通常无策略训练 | meta-gradient / 近似梯度 | Q-learning |
| 状态表示 | 当前能力及不确定性 | 作答状态向量 | 答对/答错双通道 attention |
| 长期组合价值 | criterion 多为局部一步 | 外层目标评价整组已选题 | Bellman 回报显式表示未来 |
| 响应模型 | 常与 IRT 紧密结合 | 可接 IRT 或神经模型 | 可接 IRT 或神经模型 |
| 主要解释性 | 高 | 中等 | 较低 |
| 主要工程风险 | 模型失配 | meta-gradient 与近似偏差 | 离线 RL、训练稳定性与表示泄漏 |

更细的 BOBCAT 目标和算法见[双层优化](../bobcat/02-bilevel.md)与[Framework 与算法](../bobcat/03-framework.md)。

若动作改为学习材料、状态改为学习后的连续能力，Q-learning 对应外层教学推荐。完整模型、转移估计器与模拟证据见 [Deep RL 自适应学习](../adaptive-learning-drl/index.md)。

## 2. 与推荐系统“生成序列”的关键差异

推荐页面常能同时展示多个商品，用户可能点击其中一个，也可能不点击。CAT 每一步通常只呈现一道题，而且这道题的答案是更新测量状态的关键观测。

因此，CAT 的核心对象应写成闭环策略：

\[
\pi:
s_t
\longmapsto
q_t,
\]

而一条真实测验路径是策略与学生共同生成的：

\[
q_1,a_1,q_2(a_1),a_2,\ldots,q_T(a_{1:T-1}).
\]

若一次输出固定序列

\[
(q_1,q_2,\ldots,q_T),
\]

后面的题没有使用学生中途答案，便失去了逐题分叉。一个“生成式 CAT”要保持 adaptive，可以生成：

- 下一题 token，收到答案后重新生成；
- 条件策略树；
- 随状态滚动重规划的短 horizon；
- 含合法性约束的 action distribution。

NCAT 属于第一类：每次输出下一道题。

## 3. 历史日志的支持域

离线环境只能读取历史上真实发生的答案。若旧系统从未向某类学生呈现题 \(q\)，数据中没有“此状态下选 \(q\)”的结果。

随机 support/query 切分仍然在旧 logging policy 的支持域内。策略可能：

- 偏爱旧系统常呈现的题；
- 把呈现偏差误当作题目价值；
- 对新题、低频题和新内容不稳定；
- 在离线评价中受益于模拟环境与旧日志的重合。

未来应记录

\[
\mu(q_t\mid s_t),
\]

即旧策略在当时状态选择该题的概率，并研究 IPS、doubly robust、FQE 或保守离线 RL。无共同支持的动作仍无法凭统计修正恢复。

## 4. query 预测只是测量 proxy

NCAT 用

\[
\mathcal L_M(\mathcal D_i^u,\widehat\theta_i)
\]

替代不可观察的真实能力误差。这个 proxy 会继承响应模型 \(M\) 的假设：

- IRT 维度设错；
- NCDM 校准不足；
- 题目参数漂移；
- 局部独立不成立；
- query 与目标测量蓝图不一致。

未来实验应同时报告：

- query BCE、ACC、AUC；
- 模拟条件下的能力参数恢复；
- 标准误、覆盖率与校准；
- mastery 分类准确率和决策一致性；
- 下游教学决策效用。

## 5. reward 设计与训练近似

论文外层目标对每一步 query loss 等权；DQN 使用 \(\gamma<1\) 时会偏向早期表现。绝对负损失 reward 还会产生强相关、整体为负的反馈。

可比较：

\[
r_t^{\mathrm{absolute}}=-L_t,
\]

\[
r_t^{\mathrm{gain}}=L_{t-1}-L_t,
\]

\[
r_t^{\mathrm{risk}}
=
-\mathbb E
\left[
\text{decision loss after step }t
\right],
\]

以及直接使用后验熵、参数误差或多目标 reward。每种 reward 对应不同的测验效用，不能只根据训练曲线挑选。

## 6. 内容、题型与组卷约束

论文观察到较高知识点覆盖，但没有保证内容蓝图。正式考试还可能包含：

- 各内容类别题数上下限；
- 题型和认知层次比例；
- 题组完整性；
- 敌题不能同卷；
- 阅读材料先于从属题；
- 反应时间预算；
- 题目曝光上限；
- 无障碍与语言版本要求。

令 \(z_j\in\{0,1\}\) 表示题 \(j\) 是否进入当前 shadow test，可求解：

\[
\max_{\mathbf z}
\sum_{j\in\mathcal J}
z_jQ_\phi(s_t,q_j)
\]

满足

\[
L_k
\le
\sum_{j:c(j)=k}z_j
\le
U_k,
\qquad
\sum_jz_j=H,
\]

再从最优 shadow test 中呈现第一道题。每次得到新答案后重新求解，仍保持闭环自适应。

## 7. 曝光与安全

温度采样降低论文中的平均曝光率，但随机化只提供软性分散。正式控制可使用：

- Sympson-Hetter 等接受/拒绝机制；
- 每题实时最大曝光配额；
- 题库分层与轮换；
- 约束 MDP；
- 将曝光状态纳入 \(s_t\)；
- 在合法动作 mask 中屏蔽已超配额题。

公平性评估应分群体检查曝光、测量误差、停止长度和内容覆盖，防止总体平均掩盖局部差异。

## 8. 状态和学生是否真的静态

论文采用短时测验中能力稳定、顺序不重要的假设，并用 pooling 聚合历史。教育练习场景中可能同时存在：

- 学习效应；
- 疲劳；
- 热身；
- 速度-准确权衡；
- 反馈导致的策略改变；
- 时间间隔导致的遗忘。

若过程跨越较长时间，可把时间、顺序和反馈加入状态，使用带位置/时间编码的序列模型，并把知识追踪和测量模型区分清楚。

## 9. 新题和题库变化

原 NCAT policy head 为

\[
\mathbb R^{4d}\to\mathbb R^{|\mathcal J|},
\]

输出维度绑定训练题库。加入新题后，最后一层没有相应输出单元，embedding 也没有训练。

更可迁移的形式是学习状态-题目打分器：

\[
Q_\phi(s_t,q)
=
f_\phi
\left(
h_\phi(s_t),
e_\psi(q)
\right),
\]

其中题目表示 \(e_\psi(q)\) 可来自参数、知识点、题干语义、解题步骤和多模态内容。这样才能把策略推广到训练期未见题目，并为生成新题后的校准建立接口。

## 10. 可解释性与审计

attention score 可以作为诊断线索，但不应直接当作因果解释。可增加：

- 反事实：移除某条作答后下一题怎样变化；
- 动作价值分解：测量、内容、曝光、时间分别贡献多少；
- 与 Fisher 信息、后验方差的局部对照；
- 对输入答案翻转、题目交换、padding 的敏感性测试；
- 题目级和群体级策略卡。

## 11. 建议的研究路线

### 路线 A：先复现闭环收益

1. 固定 IRT/NCDM 和论文切分；
2. 复现随机、MFI/KLI、MAAT、BOBCAT、NCAT；
3. 统一合法候选集和随机种子；
4. 同时报 query 预测、能力恢复和题数-精度曲线；
5. 对代码差异逐项消融。

### 路线 B：把内容平衡写进策略

比较三种方案：

1. Q 值后处理的 hard mask；
2. reward 中的内容偏差惩罚；
3. NCAT Q 值与 shadow test 组合优化。

关键指标包括每份测验的蓝图可行率、测量误差、覆盖、最大曝光和求解时间。

### 路线 C：离线到在线

1. 记录 logging probability 与 available set；
2. 在有共同支持的范围做 OPE；
3. 用保守策略改进限制偏离旧策略；
4. 小流量安全上线；
5. 监控能力校准、异常曝光和群体差异。

### 路线 D：生成式、可迁移题目表示

把题目 ID head 改成状态-题目匹配器，用题干语义、IRT/CDM 参数和知识点共同编码候选题。LLM 可负责生成或表征题目，CAT controller 仍在每次真实作答后重新规划，并通过校准、内容、曝光和安全层筛选。

## 12. 本专题结论

NCAT 证明了一个重要可能性：逐题选题规则可以从历史作答中学习，并用长期测量表现训练。它同时保留 CAT 最关键的交互结构——一道题、一个实时答案、一次状态更新、再做下一次决策。

论文当前证据覆盖离线 support/query 预测、概念覆盖、合成噪声和平均曝光。把方法用于正式测验，还需要对历史策略偏差、硬约束、题库变化、测量校准和在线安全进行系统扩展。
