# 实验设计、完整结果与结果分析

本页按论文的四个研究问题组织实验：

- RQ1：NCAT 的测量效率是否超过现有选题算法？
- RQ2：NCAT 会选择什么样的题，知识点覆盖怎样变化？
- RQ3：双通道网络能否捕捉复杂反应关系和猜测/失误扰动？
- RQ4：Performance Learning、Contradiction Learning 和温度随机化各自有什么作用？

## 1. 数据集

论文使用三个真实教育数据集：

| 数据集 | 来源与内容 |
|---|---|
| ASSIST | ASSISTments 在线辅导系统中的数学练习日志及题目知识点 |
| EXAM | 在线作业、考试与评价系统中的初中数学作答 |
| NIPS-EDU | NeurIPS 2020 Education Challenge 中 Eedi 平台的学生答题数据 |

论文正文没有报告三个预处理后数据集的学生数、题目数和交互数，因此这些数量不能从主文结果表反推。公开仓库随附的 ASSIST 预处理元数据记录了一个代码快照：

| 统计量 | 仓库 `assist1213/info_filtered.yml` |
|---|---:|
| 学生数 | 20,785 |
| 题目数 | 15,069 |
| 知识点数 | 163 |
| 去重后作答数 | 1,915,861 |
| 每生平均题数 | 92.18 |

这组数值用于理解仓库数据规模；它不构成论文三个数据集的完整统计表。

## 2. 数据划分与评价流程

论文进行 5 折交叉验证。每折中：

1. 学生按 60%/20%/20% 分为训练、验证、测试；
2. 每名学生的作答按 70%/30% 分为 support/query；
3. 训练 epoch 内重新随机划分 support/query；
4. 选题算法只从 support 候选题中逐题选择；
5. 响应模型用已选题及对应答案更新学生参数；
6. 在 query 题上预测反应；
7. 在第 5、10、20 步报告 ACC 与 AUC。

响应模型包括：

- IRT；
- NCDM。

MFI 和 KLI 依赖 IRT，因此在 NCDM 列没有结果。

## 3. 比较方法

| 方法 | 核心 criterion | 依赖响应模型 |
|---|---|---|
| RAND | 随机选题 | 模型无关 |
| MFI | 最大 Fisher 信息 | IRT |
| KLI | 相邻能力后验的 KL 信息 | IRT |
| MAAT | 预期模型变化与多样性 | 模型无关 |
| BOBCAT | 双层优化学习选题策略 | 模型无关 |
| NCAT | Q-learning 与双通道 attention | 模型无关 |

### RQ1 结果怎样读

1. NCAT 在三个数据集、两个响应模型和三个测试长度下都取得最高的表中 ACC/AUC。
2. 第 5 步已有提升，说明优势不只来自较长轨迹。
3. BOBCAT 通常优于手工 criterion，支持“从历史数据学习选题”这一方向。
4. NCAT 相对 BOBCAT 的差距普遍存在，但绝对幅度多为千分位到百分位；实际意义需要结合题数节省、误差成本和复现实验判断。
5. ACC/AUC 衡量 query 反应预测，属于能力估计的 proxy。它们没有直接给出参数恢复误差、分类一致性或决策风险。

## 7. RQ2：知识点覆盖

设全部知识点为

\[
\mathcal K=\{k_1,\ldots,k_{|\mathcal K|}\},
\]

前 \(t\) 步已选题集合为 \(\mathcal J_t\)。论文定义：

\[
\operatorname{Cov}_t(\pi)
=
\frac{1}{|\mathcal K|}
\sum_{k\in\mathcal K}
\mathbb I
\left(
k\text{ 被 }\mathcal J_t\text{ 中至少一道题覆盖}
\right).
\tag{1}
\]

论文图 3 显示，在 ASSIST 上，NCAT 的概念覆盖曲线在 IRT 和 NCDM 环境中均增长较快并趋近 1。论文据此分析：RL 的探索与题目组合多样性有助于形成更全面的测量。

这项结果是经验涌现现象。NCAT 的 reward 没有直接包含内容蓝图，式 (1) 也只统计“至少出现一次”，没有保证各内容比例、下限、上限或测量精度。

## 8. RQ3：反应矛盾与噪声稳健性

### contradiction score 可视化

论文在 EXAM 中展示一名学生前 7 个反应的 contradiction score matrix，并同时列出题目难度和知识点。

其中一对“较难题答对、相关的较易题答错”得到较高分，而难度关系类似但知识点相关性较低的题对得分较小。作者将其解释为网络同时利用难度关系和语义/知识点联系识别潜在 guess/slip。

该可视化展示了一个个案中的内部注意力结构，不能单独证明 attention 分数就是可识别的猜测概率。

### 模拟 guess/slip

论文在 EXAM 的 IRT 环境进行能力恢复模拟：

- 用全数据估计的能力参数作为 ground truth；
- 生成反应；
- 对原本错误反应，以 25% 概率翻成正确，模拟 guess；
- 对原本正确反应，以 5% 概率翻成错误，模拟 slip；
- 用

\[
\operatorname{MSE}
=
\mathbb E
\left[
\left\|
\widehat\theta-\theta^0
\right\|^2
\right]
\tag{2}
\]

比较不同选题算法随测试步变化的能力误差。

论文图 4(b) 报告 NCAT 的 MSE 曲线在这些扰动下表现良好，据此支持其噪声稳健性。主文未给出曲线的逐点数值和区间。

## 9. RQ4：消融实验

消融在 IRT、\(T=20\) 下比较 ACC：

| 结构 | ASSIST | NIPS-EDU | EXAM |
|---|---:|---:|---:|
| Default NCAT | 0.7562 | 0.7321 | 0.8516 |
| NCAT-C：仅 Contradiction Learning | 0.7415 | 0.7059 | 0.8351 |
| NCAT-P：仅 Performance Learning | 0.7508 | 0.7235 | 0.8417 |
| \(\nu\to0\)：确定性 argmax | 0.7586 | 0.7329 | 0.8530 |

两个模块单独使用都降低 ACC，完整双通道结构表现更好。确定性策略的 ACC 略高于默认温度策略，说明随机化付出了一点预测精度代价。

## 10. 曝光率结果

论文在 ASSIST 模拟中报告平均题目曝光率：

| 方法 | 平均曝光率 |
|---|---:|
| MFI | 14.4% |
| MAAT | 13.9% |
| BOBCAT | 16.3% |
| **NCAT，\(\nu_t=2^{-0.1t}\)** | **5.2%** |
| NCAT，\(\nu\to0\) | 15.1% |

默认温度采样显著降低表中平均曝光率，而确定性 argmax 接近其他方法。结合消融 ACC 可看到精度与曝光之间的经验折中。

平均曝光率仍不足以描述题库安全。正式评估还应报告：

- 最大题目曝光率；
- 曝光分布的分位数或 Gini 系数；
- 按群体和内容类别分层的曝光；
- 重复施测中的题目泄露风险；
- 强制最大曝光率约束后的精度。

## 11. 论文实验支持的结论边界

论文提供了三类证据：

1. 在历史日志的 support/query 模拟中，NCAT 改善 query ACC/AUC；
2. 概念覆盖和平均曝光结果显示其轨迹具有更高多样性；
3. 合成 guess/slip 扰动与模块消融支持双通道结构的作用。

仍待补充的证据包括：

- 新策略改变题目呈现分布后的在线效果；
- 题库外或新题冷启动；
- 内容蓝图、敌题、时间和最大曝光硬约束；
- 能力参数与分类决策的校准、公平性和不确定性；
- 多随机种子、完整误差条与现代 DQN 稳定化的消融；
- 与旧 logging policy 偏差相关的 OPE。

代码怎样把这些公式落地，见[官方代码精读与最小实现](08-implementation.md)。
